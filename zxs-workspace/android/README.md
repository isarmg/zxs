# Android 工作区

## 远程容器提交（开发中）

Android 端已定义单文件全量保存的三种请求：创建容器的 `main` 首节点、在选定分支头追加、从 `main` 的选定历史节点创建分支。按原操作号查询时，只有精确匹配容器、操作、基点、新节点、正文长度和 SHA-256 的回执才能确认；只有精确的查询未找到结果才表示缺少该回执。

Android 可把已停止编辑的完整正文和原提交决定留在独立的应用私有目录（目前与本机文本编辑器相同，上限 256 KiB）。同步和读回完成才返回；重开需使用同一操作号、已选服务器身份和账户，复核原证、整条记录及正文摘要。不在本机 ZIP 快照中写远端记录，不保存密码或授权头。失败时保留已确认的原件，不自动改选、覆盖或上传。

另有独立记录保存首次可能发送的精确决定和已确认的原回执。只有发送标记完成同步和读回后，后续传输才能首次发送。即使冻结正文无法再读取，也能凭标记重查原操作；没有回执和写入中断是不同结果。若中断留有暂存或双链接无法核验，保留本机材料并报告原操作号，不自动清除、换号或重发。

提交控制区分只查、首次发送和显式同号重发。只在原目标精确查无回执且本机材料仍完整时发一次完整正文；丢答时不重发，重新确认同号后才可能继续。已编写仅接受 HTTPS/HTTP/2 的传输适配器，使用 Android 系统信任和固定的 Apache HttpCore H2 5.4.4；同一 TLS 引擎确认 `h2` 后才允许认证头进入 HTTP/2 写入流程。每次请求使用单独的连接，不跟随跳转、不使用代理、不回退到 HTTP/1.1。回复必须完整且长度和媒体类型清楚。从首页「远程文件」进入。在指定 HTTPS 地址和账号下，新建一个文本文件；确认页显示服务器、账号、全文长度、摘要和原操作号，选择「提交一次」才发请求。离开页面会停止接收该次结果；服务器若已收到提交，重启后可以输入原操作号，在同一地址和账号下选择只查回执，或者在原决定仍可核验且服务器查无时明确同号继续。可以从「从本机选择原操作」按原服务器和账号找回本机决定，不必记住操作号。此列表不用密码、不连接服务器、不读取正文；选中后仍需核验原决定并另行确认。若完整正文无法核验，只能在已有原发送标记时查询回执；不能把列表项当成可发送的凭据。每页最多 24 个，同一私有目录最多检查 4096 个名称，超过时仍可输入已知原操作号。点「浏览已有远程文件」可翻页选择当前服务器中的容器。应用固定所选修订和分支节点，确认后只下载该节点的正文，完整长度、SHA-256 和 UTF-8 全部通过才打开编辑。暂只支持 256 KiB 内的普通文本。提交修改前需再次输入原账号密码；只向所选分支头提交修改后的全文，不改名，也不会在其他人已推进 `main` 时改选新头或自动分叉。没有修改，不创建版本。选择「查看 main 历史」可沿同一原头翻页，读到已选历史节点后，用户确认提交修改时才在该原节点建立新分支；读历史和编辑不会写远端。沿系统返回键或关闭入口退出前，已更改且尚未留在本机的正文会提示是否放弃；没有改动可直接离开。回执核验成功后可以开始另一个操作，本机仍保留原提交和回执。Android 不建立虚拟磁盘。未在手机或模拟器运行。

## 新建本机工作区

点「新建本机工作区」，输入文件名和正文，再点「提交快照」并确认。首版只编辑一个文本文件，提交生成一个应用私有的第 1 代 `.zxs`；不改已选归档、不自动保存或备份，也不导出。

写入后从同一原件核验，再以无覆盖方式发布并同步目录。只有确认完成才显示「已提交」；结果不明时不重试。Android 设备上的提交尚待验收。

返回首页点「打开本机已提交快照」可列出本机快照，重开应用后也能使用。选择一份快照，核验后只读翻看原文本；不改归档、不导出，也不调用系统选档。

## 只读浏览 ZIP

从「选择本机 .zxs 或 Store ZIP」进入系统文件选择器，在**主共享存储**中选择一份文件。点击目录进入下一级；可看空目录、返回上一级，每页最多 100 项。文件后面是 ZIP 中声明的字节数。点一个普通文件后，会先显示完整成员路径及将读取的**全部字节数**。选择并确认「只核验 CRC」「核验后看全文」「完整核验后预览前部」或「完整核验后按页跳读全文」才开始；较大文件也不会自动读取，核验可以取消，结果不会写入磁盘。重新选档、窗口离开前台或旋转都会结束原文件会话，之后需要重新选择。

**目录声明和单项核验是不同结果。** 浏览只解析受限中央目录。文件末端的定位窗口可能覆盖最后一个成员的一部分，但浏览不会主动逐项读正文。单项核验另从本次尚未关闭的原文件句柄读取：先确认目录与原本地头中的精确名字、方法、标志、长度和物理边界，再从同一打开文件分块读满这一项；每次原生读至多 64 KiB。对流式 ZIP，数据描述符必须自正文末尾恰好延伸至下一项的本地头或中央目录；本地头或中央目录用 ZIP64 表示成员长度时，只核对 64 位长度。若只有中央目录里的位置偏移用 ZIP64，则按完整物理区间接受 32 位或 64 位长度（均可带或不带签名）。带额外填充或字段宽度不明确的变体不做单项核验，不猜边界。只有原授权、文件观测值与目录/头信息在最后复核仍相符，才显示声明和实读 CRC-32；读不完、位置不明或头部矛盾不返回部分 CRC。

CRC 相符仅表示这次读出的这一个成员与包内给出的校验码相符。正文和 CRC 都可能被修改；它不是数字签名，不证明整个文件一直未变，也不核验其他成员、整树摘要、版本或分支头。

已选带规范标记的 `.zxs` 可在「核验原归档」中另选「核验 .zxs 整树」。确认先列原文件、节点和全部正文读取量，可取消；后台仍用本次原 PFD 和临时授权。核每个实际成员的布局、长度、CRC 和文件 SHA-256，再按完整路径计算包括空目录和隐式祖先的整树摘要，与原注释标记比较。通过只说明本次读出的逻辑树和包内标记一致，不等于签名、作者认证、原始 ZIP 外部摘要、仓库槽或分支头。普通 ZIP 不自动进入该操作；不会提取、写入或上传。换档、退后台和授权失效均不交迟到结果。

**核对原包 SHA-256** 是另一项可明确选择的只读操作，已选的 `.zxs` 和普通 Store ZIP 都可用。先列包括 ZIP 头和注释在内的实际全包字节数，不因选档或整树核验而自动多读。只从原 PFD 用最多 64 KiB 的缓冲顺序读取，检查实际末尾、临时授权及原文件观察后才显示全摘要，可人工与另一份副本比对；它不核对包内整树声明或认证来源。关闭、取消、换档或失权不保留结果，不自动保存或写剪贴板。

整份核验和单项 CRC／核验后预览都会显示本次已处理的正文与声明总量。计数来自同一次分块处理，不算 ZIP 元数据或已经打开的预览页，不会为了计数重读。达到总量仍不代表核验成功：还可能在核对末尾、原文件和授权，或得出 CRC 不符。不再显示已取消、已换档或已离开前台任务的计数。

### 按名称查找并定位

打开一份归档后，可点「按名称查找」并输入名称片段。查找只在本次已读取的目录记录中按文件或目录的**单个名称**匹配，区分大小写；不按完整路径、通配符、正则或文件正文查找。每页最多 100 条，显示完整路径来区分不同目录下的同名项；空目录和归档推导出的目录也可找到。输入上限为 128 个 UTF-16 单元。

点一条匹配，只跳到它所在的目录和实际页，并将该条目定位到列表内；没有打开文件或进入匹配的子目录。要核验或预览文本，须在普通目录页再点该文件并确认。选「返回目录」可不跳转，回到查找前的目录与页。可取消查找；换档或离开前台会丢弃原查询、匹配和迟到结果。应用不借新文件句柄、不询问文件提供方、不保存搜索词或结果，也不发网络请求。它请求键盘不要学习输入，不能保证第三方键盘行为。

### 只读文本预览

- **全文：** 合格的 **0 至 256 KiB 原始字节**（包括超过旧 32 KiB 上限的内容）可在核验后完整翻页。0 字节标为空文本。
- **前部：** 更大时可另选「完整核验后预览前部」。这不是快速跳过 CRC：界面先展示整项的实际读取量，可能要读很多 GiB，能在后台核验时取消；不含正文的普通浏览或定位不触发它。同一次读取只保留开头最多 256 KiB，另有最多 3 字节判断边界。若边界切过一个已核合法的 UTF-8 字符或 CRLF，会将这一个边界单位留在未显示部分。窗口标出本项全部已核字节及实际显示的原始字节，不判断后文是否为文本。
- **大文件跳读全文：** 单独选择后才开始一次整项读取，同时校验完整 CRC 和严格 UTF-8，并为每个 1 MiB 原始正文块记 SHA-256、页码和至多 3 字节的切缝信息（单项 128 GiB 时表约 4.625 MiB，另有固定工作缓冲）。临时缓冲按块处理，会话只保留索引和当前页，不留存全文，也不写到磁盘。完成后可输入任意页码，也可以前后翻页；每次只重核并读取这一页所需的一至两个原正文块，同时复核该成员的原目录记录、归档末尾与本地头/描述符，不再扫描整项。跨块的 UTF-8 字符与 CRLF 都分到下一段，因此段末可能有较短的页；只向界面交一页。选「关闭」可取消在途页读。任何不符都关闭当次跳读，不会用旧索引重开别的文件。
- **正文不完整不显示：** 完整 CRC、原文件状态和授权、头与目录复核任一步失败，连前部也不显示。CRC 不符、无法完成核验、CRC 相符但所选显示范围不符合 UTF-8 规则分别提示；大文件后半不是文本时仍可另行选择明确的前部模式，不会自动降级。

仅接受严格有效的 UTF-8。允许制表符、换行和 CRLF；只在显示时将 CRLF 转成换行。不接受单独的回车、其他控制/方向/默认可忽略字符、私用或未分配码位；例如带 BOM 的文本或含零宽连接符的表情序列也可能拒绝。HTML、网址和代码只按原文显示，不渲染、不激活链接、不交给别的应用。每页至多 8,192 个 UTF-16 单元和 256 个换行，不拆代理对。只有当前页进显示控件；小全文和有界前部的上一页/下一页不重读正文，跳读全文只回读该页所需块。在每次显示前核对本次临时读权和原持有文件的状态。块摘要只绑定此前从原句柄读取的字节，不认证文件来源或整个 ZIP。不会生成预览文件、保存正文、上传或写入剪贴板；点「关闭」、换选、检测到原件或授权失效、离开前台后清除原预览。

### 第一版接受什么

- Android 15+ 的系统 SAF 单文件临时读取权。只接受系统签名、符合 AOSP ExternalStorageProvider 约定的主共享存储普通文件，后缀为 `.zxs` 或 `.zip`；**不要从“最近”中的云或下载提供方选，直接进入主存储**。仅打开原 URI 一次，不转为磁盘路径。不接受虚拟文件、部分下载、多选、树授权、管道、不可定位或读取期间已观测到变化的文件。
- 单卷、未加密、Store 方法的 ZIP 与标准固定大小 ZIP64 结束记录。只接受 ASCII 或明确标为 UTF-8 的可移植名称；不兼容的格式、特殊成员、歧义名字、重复或父子冲突会拒绝整份预览。手机上限：中央目录 2 MiB、8,192 条显式记录、12,288 个含隐式目录的节点、累计名字 512 KiB、48 层；单成员最多 128 GiB、声明正文合计最多 256 GiB。不降级成显示部分目录。
- 本机预览流程不发网络请求，不请求广域存储权限，不查询别的文档、不申请持久 URI 授权。核验只借用同一打开文件的只读描述符，不再按 URI 挑选同名文件；退出前台或换选即放弃旧结果。已选归档无写入、缓存、上传或解包入口。系统选择器和提供方由系统管理；主存储可被模拟，不能把 URI 或可定位句柄当作物理闪存或全系统不联网的证明。

### 构建与验收状态

本目录是独立 Gradle 根。参见[版本化 APK 候选与签名前核对](RELEASE.md)：在已备妥的 JDK 17 / Gradle 8.13 环境，只提取当前 release 的一份 APK，按真实版本命名并记录 SHA-256。本机查看与编辑使用 Android/Java 平台 API；待接入的远程传输使用 Apache HttpCore H2。AndroidX Runner 与 JUnit 仅供 `src/androidTest`。主线已通过 API 36 的 release Java 源码编译。尚未生成或安装 APK，也未运行设备测试。

整份核验的合成源例包含空树、完整路径排序、BMP 与补充字符、CRC 已重算但与整树标记不符、尾部原证变化和可取消；还需实际 Android 设备检查同一原授权、用户取消和读量，再用项目生成的 `.zxs` 对照结果。发行前须在干净环境构建、核查许可并签名；在实际 Android 15+ 设备验证主存储选档/授权撤销、取消与旋转、受限提供方、空目录/多页、超过 4 GiB 的 Store/ZIP64，逐项校验的破损正文、本地头与描述符不一致、取消后迟到和授权撤回，文本的 32 KiB+1、256 KiB、显式大文件前部和跳读全文的整项核验量、末尾 CRC 损坏、跨 1 MiB 的四字节 UTF-8 / CRLF、末页直跳与后半非文本、改动未展示块字节、密集换行与大字号/无障碍、换选或失权后的延迟翻页，以及文件变化和资源上限的拒绝。查找另验：两目录内同名（至少一项在所在目录第 2 页）、长路径与大字体、点击只定位、返回保持页码；搜索行点按后若先返回目录、切页或换档，延迟送达的旧点按不能作用，也不能在新页面弹核验确认。换档不显示旧查询结果，再点原文件才出现核验确认。没有实机证据时不承诺支持某家文件管理器、云盘、可移除盘或下载目录提供方。
