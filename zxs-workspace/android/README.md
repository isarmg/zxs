# Android：在手机上看 ZIP 目录

从「选择本机 .zxs 或 Store ZIP」进入系统文件选择器，在**主共享存储**中选择一份文件。点击目录进入下一级；可看空目录、返回上一级，每页最多 100 项。文件后面是 ZIP 中声明的字节数。点一个普通文件后，会先显示完整成员路径及将读取的**全部字节数**。确认「只核验 CRC」「核验后看全文」或「完整核验后预览前部」才开始；较大文件也不会自动读取，核验可以取消，结果不会写入磁盘。重新选档、窗口离开前台或旋转都会结束原文件会话，之后需要重新选择。

**目录声明和单项核验是不同结果。** 浏览只解析受限中央目录。文件末端的定位窗口可能覆盖最后一个成员的一部分，但浏览不会主动逐项读正文。单项核验另从本次尚未关闭的原文件句柄读取：先确认目录与原本地头中的精确名字、方法、标志、长度和物理边界，再用固定 64 KiB 缓冲读满这一项。对流式 ZIP，数据描述符必须自正文末尾恰好延伸至下一项的本地头或中央目录；本地头或中央目录用 ZIP64 表示成员长度时，只核对 64 位长度。若只有中央目录里的位置偏移用 ZIP64，则按完整物理区间接受 32 位或 64 位长度（均可带或不带签名）。带额外填充或字段宽度不明确的变体不做单项核验，不猜边界。只有原授权、文件观测值与目录/头信息在最后复核仍相符，才显示声明和实读 CRC-32；读不完、位置不明或头部矛盾不返回部分 CRC。

CRC 相符仅表示这次读出的这一个成员与包内给出的校验码相符。正文和 CRC 都可能被修改；它不是数字签名，不证明整个文件一直未变，也不核验其他成员、整树摘要、版本或分支头。

### 按名称查找并定位

打开一份归档后，可点「按名称查找」并输入名称片段。查找只在本次已读取的目录记录中按文件或目录的**单个名称**匹配，区分大小写；不按完整路径、通配符、正则或文件正文查找。每页最多 100 条，显示完整路径来区分不同目录下的同名项；空目录和归档推导出的目录也可找到。输入上限为 128 个 UTF-16 单元。

点一条匹配，只跳到它所在的目录和实际页，并将该条目定位到列表内；没有打开文件或进入匹配的子目录。要核验或预览文本，须在普通目录页再点该文件并确认。选「返回目录」可不跳转，回到查找前的目录与页。可取消查找；换档或离开前台会丢弃原查询、匹配和迟到结果。应用不借新文件句柄、不询问文件提供方、不保存搜索词或结果，也不发网络请求。它请求键盘不要学习输入，不能保证第三方键盘行为。

### 只读文本预览

- **全文：** 合格的 **0 至 256 KiB 原始字节**（包括超过旧 32 KiB 上限的内容）可在核验后完整翻页。0 字节标为空文本。
- **前部：** 更大时可另选「完整核验后预览前部」。这不是快速跳过 CRC：界面先展示整项的实际读取量，可能要读很多 GiB，能在后台核验时取消；不含正文的普通浏览或定位不触发它。同一次读取只保留开头最多 256 KiB，另有最多 3 字节判断边界。若边界切过一个已核合法的 UTF-8 字符或 CRLF，会将这一个边界单位留在未显示部分。窗口标出本项全部已核字节及实际显示的原始字节，不判断后文是否为文本。
- **正文不完整不显示：** 完整 CRC、原文件状态和授权、头与目录复核任一步失败，连前部也不显示。CRC 不符、无法完成核验、CRC 相符但所选显示范围不符合 UTF-8 规则分别提示。

仅接受严格有效的 UTF-8。允许制表符、换行和 CRLF；只在显示时将 CRLF 转成换行。不接受单独的回车、其他控制/方向/默认可忽略字符、私用或未分配码位；例如带 BOM 的文本或含零宽连接符的表情序列也可能拒绝。HTML、网址和代码只按原文显示，不渲染、不激活链接、不交给别的应用。每页至多 8,192 个 UTF-16 单元和 256 个换行，不拆代理对。只有当前页进显示控件，上一页/下一页不重读正文；在每次显示前核对本次临时读权和原持有文件的状态。不会生成预览文件、保存正文、上传或写入剪贴板；点「关闭」、换选、检测到原件或授权失效、离开前台后清除原预览。

### 第一版接受什么

- Android 15+ 的系统 SAF 单文件临时读取权。只接受系统签名、符合 AOSP ExternalStorageProvider 约定的主共享存储普通文件，后缀为 `.zxs` 或 `.zip`；**不要从“最近”中的云或下载提供方选，直接进入主存储**。仅打开原 URI 一次，不转为磁盘路径。不接受虚拟文件、部分下载、多选、树授权、管道、不可定位或读取期间已观测到变化的文件。
- 单卷、未加密、Store 方法的 ZIP 与标准固定大小 ZIP64 结束记录。只接受 ASCII 或明确标为 UTF-8 的可移植名称；不兼容的格式、特殊成员、歧义名字、重复或父子冲突会拒绝整份预览。手机上限：中央目录 2 MiB、8,192 条显式记录、12,288 个含隐式目录的节点、累计名字 512 KiB、48 层；单成员最多 128 GiB、声明正文合计最多 256 GiB。不降级成显示部分目录。
- 不请求网络或广域存储权限，不查询别的文档、不申请持久 URI 授权。核验只借用同一打开文件的只读描述符，不再按 URI 挑选同名文件；退出前台或换选即放弃旧结果。无缓存文件、上传、解包或写入入口。系统选择器和提供方由系统管理；主存储可被模拟，不能把 URI 或可定位句柄当作物理闪存或全系统不联网的证明。

### 构建与验收状态

本目录是独立 Gradle 根。参见[版本化 APK 候选与签名前核对](RELEASE.md)：在已备妥的 JDK 17 / Gradle 8.13 环境，只提取当前 release 的一份 APK，按真实版本命名并记录 SHA-256。产品源码仅用 Android/Java 平台 API；AndroidX Runner 与 JUnit 仅供 `src/androidTest`。没有生成或安装 APK，没有运行编译、签名或测试。

发行前须在干净环境构建、核查许可并签名；在实际 Android 15+ 设备验证主存储选档/授权撤销、取消与旋转、受限提供方、空目录/多页、超过 4 GiB 的 Store/ZIP64，逐项校验的破损正文、本地头与描述符不一致、取消后迟到和授权撤回，文本的 32 KiB+1、256 KiB、显式大文件前部与整项核验量、末尾 CRC 损坏、跨界四字节 UTF-8 / CRLF、密集换行与大字号/无障碍翻至最后页、换选或失权后的延迟翻页，以及文件变化和资源上限的拒绝。查找另验：两目录内同名（至少一项在所在目录第 2 页）、长路径与大字体、点击只定位、返回保持页码；搜索行点按后若先返回目录、切页或换档，延迟送达的旧点按不能作用，也不能在新页面弹核验确认。换档不显示旧查询结果，再点原文件才出现核验确认。没有实机证据时不承诺支持某家文件管理器、云盘、可移除盘或下载目录提供方。

设计依据：[Android 系统文件选择](https://developer.android.com/training/data-storage/shared/documents-files)、[AOSP ExternalStorageProvider](https://android.googlesource.com/platform/frameworks/base/+/master/packages/ExternalStorageProvider/)、[PKWARE ZIP 规范](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)、[Android Gradle Plugin 8.13](https://developer.android.com/build/releases/agp-8-13-0-release-notes)。
