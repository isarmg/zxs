# ZIP Workspace 交付清单

本表只记录本项目，范围依据 [架构](ARCHITECTURE.md)。源码完成、在真实系统上验证、签名发行是不同阶段。

| 工作流 | 当前状态 | 下一道验收 |
| --- | --- | --- |
| 整目录标准 Store ZIP/ZIP64、历史与独立工作树 CLI | 已有实现；原 Linux/Python 3.12 验证范围见 [README](README.md#平台与发行状态)。迁入后未据此宣称重测。 | 非覆盖发布、断线、单成员 4 GiB、峰值占用和真实 SMB 分别验证。 |
| CLI 新提交冻结（Linux） | 源码改为真实匿名句柄，按有界区间将原代数据打包，不递归清理具名目录；不支持的私有状态卷在打开 SQLite 前拒绝，未运行。 | 在符合条件的本机卷验证原目录与原包实物、无名文件释放、短写/截断、空间不足、切换目录、超大文件和冷恢复；不能外推其他 OS、网络设备或安全擦除。 |
| 桌面浏览原快照、目录分页、分支与历史 | Qt Widgets 可选依赖、真实窗口和选择绑定已接入源码；首次浏览保留完整成员核验，不再为显示额外遍历原 ZIP。未运行，无实测耗时。 | 各桌面系统实际打开、键盘导航、空目录、缺失祖先、同名替换、耗时核验和窗口关闭。 |
| 快照与本机文件夹的只读比较 | 源码已接入：比较已核验快照与用户所选目录的实际内容，列出新增、修改、缺少及空目录；不登记工作树，未运行。 | 实机核对路径替换、变化检测、差异分页及不支持的平台；这不是工作树状态或提交能力。 |
| Windows 本机文件夹只读比较 | 未实现。现有比较器要求 POSIX 目录文件描述符；能打开归档不代表能比较文件夹。 | 从选择到完成持有原目录句柄；[从父句柄逐级打开子项](https://learn.microsoft.com/en-us/windows/win32/api/winternl/nf-winternl-ntcreatefile)，不跟随重解析点。对照[目录清单](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_id_extd_dir_info)与实际句柄的卷标识、128 位文件 ID 和类型，核验内容后复查清单和原目录名。替名、内容变化或无法证明身份时拒绝，不退回按路径扫描；不授予写入能力。 |
| 普通 ZIP 预览 / 提取 | 桌面和命令行保留只读核验；当前所有目标都拒绝普通 ZIP 写入。尚无与目标同一文件系统且应用独占的可信暂存来源。 | 先证明独占暂存区、原目录身份、无覆盖改名及两个真实父目录的同步；首个成员写入前、改名前后被替换、冲突和断线均不得误写或误报。实机验收前不恢复写入。 |
| 桌面工作树 | 登记、签出、提交/分叉、原操作恢复及隐藏/恢复仍未开放。 | 私有状态要在原生 SQLite 锁和恢复协议下，绑定已选择的实际目录；不能只按路径打开另一个数据库或写入私有快照。完成后再验各桌面工作流。 |
| Windows 原生写入 | 现有核心不声称具备。 | 先证明实际卷上的句柄身份、同目录不可覆盖改名、目录耐久、冲突恢复，再验 Windows 完整工作流。Linux、macOS 分别实测。 |
| Linux / macOS / Windows 虚拟挂载 | 未发行；普通目录签出不能替代挂载。 | 真实编辑、写句柄排空、显式提交、权限、卸载及重开。 |
| iOS / Android | 尚无客户端。 | 实机文档选择及权限撤销、受控私有副本、历史读取及相应写能力。 |
| 各平台独立构建和发行 | 只有项目自身的打包清单，没有已验收的安装包。 | 独立移动、清洁安装、许可、签名/公证、卸载，每目标分别留证。 |
