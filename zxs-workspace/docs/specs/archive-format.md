# 本地 .zxs 归档格式

这里定义旧版 Workspace 的本地目录快照，不是远程容器协议；也不是新 Rust 客户端的 Deflate 代码包。可用[快速上手](../guides/quickstart.md)生成或检查一份示例。

## 标准 ZIP 包装

- 快照是一个未加密的标准 ZIP，普通文件用 Store（方法 0），按需使用 ZIP64。空目录是普通目录项。
- 不写自定义前缀、隐藏元数据成员或必要伴随文件。仓库标记只写 ZIP 的归档注释。
- 要用普通工具取正文，可操作改成 `.zip` 的副本。普通 ZIP 须走独立核验入口，不因后缀或目录相同成为快照。

## 标记、槽名与摘要

归档注释最多 1,024 字节。先写 ASCII `zip-workspace/1` 和换行，再写严格 UTF-8 JSON。JSON 键排序、无额外空白，按原字节重新编码比对；未知或重复字段拒绝。

| JSON 字段 | 值 |
| --- | --- |
| `repo`、`branch`、`operation` | 32 个小写十六进制字符，各自标识仓库、分支和原操作。 |
| `generation` | 1 至 2⁶³−1 的整数；正式槽名为 `<repo>.<branch>.<16 位小写十六进制代>.zxs`。 |
| `parent` | 另一个操作 ID 或 `null`；第 2 代起非空，不能指向自己。第 1 代分叉可带原父。 |
| `tree` | 64 个小写十六进制字符的整树 SHA-256。 |

整树 SHA-256 从 ASCII `zip-workspace tree 1` 加一个 NUL 起算。按相对路径的 Unicode 码点顺序，对每一项追加「4 字节大端长度 + 紧凑 UTF-8 JSON 行」。行是 `[路径,"d" 或 "f",字节数,正文 SHA-256 或 null]`，包含隐式父目录。

整树摘要不是签名或授权，也不是整个 ZIP 文件的摘要。选定同一逻辑版本仍可能有不同的 ZIP 原字节。签出登记、发布与恢复须另核完整原始 ZIP 及所持原实物。

能够核验的松散文件可单独浏览或签出。只有 STORE 的原槽名、归档标记、原操作和完整父链互相吻合时，才可当作相应分支头；不会用松散包补齐缺槽。

## 准入与预算

| 项 | 当前上限 |
| --- | --- |
| 条目、中央目录 | 最多 150,000 项，中央目录 32 MiB。含隐式父目录的树也受项数限制。 |
| 正文 | 单项 128 GiB，总计 256 GiB；这不是 4 GiB 单成员或峰值性能的通过证明。 |
| 名称 | 整个路径最多 1,024 UTF-8 字节，单段最多 240 字节，深度最多 48。 |

名称须是精确的相对路径和 NFC。拒绝点段、保留设备名、大小写别名、冲突的文件与子目录、链接及特殊项；不作清洗或重命名。ZIP 本地头、中央目录、流式描述符、实际字节和 CRC 必须相符。

桌面和 CLI 的完整归档视图在通过整树校验后才列目录，每页最多 256 项。目录名区分大小写，游标只属于同一逻辑提交和目录，不是读取权限。移动端的中央目录声明不等于这个完整视图。
