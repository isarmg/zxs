# Workspace：管理远程文件容器

给使用现有 Workspace 桌面「存储容器」页的人。先备好可信 HTTPS/HTTP/2 的 ZXS 入口和账号。本页不创建 `.zxs` 归档，也不是新版 Rust 客户端的用法。

[CI通过] [隔离客机的 TLS/HTTP/2、整文件写入及读回阶段](https://github.com/isarmg/zxs/actions/runs/45322511258/job/138204176887)通过；真实桌面、挂载和发行的范围见[交付状态](../../TASKS.md)。

## 连接所选服务器

1. 打开桌面端的「存储容器」页，点「连接…」。
2. 填写 HTTPS 地址、登录账号和口令，再点「连接并读取列表」。
3. 选容器并打开信息，然后选分支和节点。打开只查元数据，不下载正文、不挂载、不写入。

服务入口必须在同一条已核验证书的 TLS 连接协商 HTTP/2。只支持 HTTP/1.1 的入口不能连接。需要[锁定的传输组件](../../packaging/network-r3/README.md)；不跳转到浏览器，也不用其他地址代替。

断开时清除当前窗口的口令、列表和选择。已经开始的请求不能撤销；旧连接的迟到结果不会恢复界面。

## 另存所选节点（Linux）

[仅静态] 选定分支和具体节点，点「另存所选节点…」。选择本人所有的本机 ext4/XFS 目录和全新的文件名，核对服务器、原节点、长度及 SHA-256 后确认。可选历史节点，不会改成后来出现的头。

完整核验、读回和同步后才公布新文件，不覆盖已有同名。Linux 普通连接即可另存，不需要 WORK、STATE 或挂载；若正在处理原编辑卷，请先结束当次编辑。

远程显示名按原拼写匹配。若本机卷不区分大小写，`Report.txt` 与 `report.txt` 可能占用同一个名字；请改选本机新名，不会改远程文件名。

## 常见明确操作

- 当本次能力允许时，可以重命名、整组替换标签或确认移入专用回收盘。列表里不再出现不等于回收成功；没有永久删除入口。
- 在已接入写入权限时，可用「从所选节点新建分支…」建立继承该节点的分支，不上传正文。与「从历史 `main` 分叉并保存新正文」是两种动作。
- 需要编辑和全量提交，见[Linux 远程编辑与提交](linux-remote-edit.md)；其他平台按各自[发行门槛](../../TASKS.md)。失答走[原号回执与冷重开](../invariants/remote-recovery.md)。
