# iOS R3 HTTPS 传输

此独立 Swift 模块为 App 的明确远程提交提供单请求发送接口。App 的本地预览与草稿不会创建连接。

连接使用系统 TLS 信任及主机校验、只提供 `h2` ALPN。只在同一活动连接的 TLS 元数据确认 `h2` 后，才安装 SwiftNIO HTTP/2 处理器。没有协议或协议不同则关闭；无 HTTP/1.1 回退。HTTP/2 服务端推送关闭，连接建立超时 10 秒。原生路径待以后验收。

工具链源要求 Swift 6.1 或更新，部署目标保持 iOS/iPadOS 16。精确直接及传递版本写入 `Package.swift` 和 `Package.resolved`，使用上游 Apache-2.0 软件包及其随包许可证。选择兼容 iOS 16 的 System 和 Swift 6.1 的 Collections；不要用更新锁文件来代替验证部署目标。签发时随实际分发件核定全部许可和声明。

内部传输只接受 R3 的原号查询与全量 SAVE，检查规范路径、唯一标头及整份正文长度和 SHA-256；凭据提供方只在同一通道确认 HTTP/2、且请求形状复核后调用，不索引凭据。每个请求用一条新连接；不跟重定向、不重发。回执需唯一长度、完整结束、未压缩且无尾标头，正文最多 2048 字节。接入应用前还需完成身份、可取消交互、原请求记录同步和明确提交的业务流。原生验收另验 HTTP/1.1、没有 ALPN、无效证书、断开及非预期流均不会发送业务请求；源码中的纯判定 XCTest 不能替代这些用例。未运行 Xcode、编译或测试。
