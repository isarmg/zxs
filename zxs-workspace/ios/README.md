# iOS：预览一份归档的目录

打开应用，点「选择 .zxs 或 Store ZIP」，在系统文件选择器里选一份文件。点目录看下一级，文件下方显示 ZIP 声明的字节数。每页最多 100 项，可查看空目录、翻页和返回。要核验正文，点普通文件，核对成员和首行给出的全部读取字节数，再选「只核验 CRC」「核验后看全文」或「完整核验后预览前部」。只有这次确认才逐块读取；选档、浏览和定位都不触发正文读取。较大文件可能耗时，读时可取消。

**目录预览与单项 CRC 是两种不同的结果。** 浏览只看中央目录、层级、条目类型和必要物理范围；正文损坏仍可能列出原来的名称与大小，尾部定位窗口也可能物理覆盖最后一项的一部分。明确核验单项时，程序重核目录、所点成员的精确名、本地头、大小与数据边界，并通过系统 zlib 以 64 KiB 缓冲逐块核对 CRC-32。对流式 ZIP，描述符必须从正文末尾恰好延伸到下一物理本地头或中央目录，本地头或中央目录以 ZIP64 表示成员长度时，描述符须用 64 位长度。若只有中央目录里的位置偏移用 ZIP64，则按完整物理区间接受 32 位或 64 位长度（均可带或不带签名）；歧义、填充等其他变体拒绝核验。读不完或发现变动时不会返回部分结果。

相符只说明本次读出的单项数据与归档给出的 CRC-32 对得上，不是签名；正文和校验值都可能被改。这不保证文件始终未变，不验证其他成员、完整快照、归档注释中的身份或分支头。

- **位置和授权：** 只通过系统单文件选择器原地打开，不创建副本。在前台对本次选择保留临时安全作用域、文件展示器和一个普通可定位文件的原只读句柄。读目录和读成员分别经过系统文件协调；等待用户决定时不占协调读取。再次核验仍使用原句柄，按协调访问器给出的名字核对实际身份和文件状态，不按名字打开另一份文件。外部移动、写入让渡、删除、换选、取消正在进行的读取或退至后台都会结束原会话；在途读取退出后释放句柄和作用域。文件提供方请求回收本地副本时结束会话；不能证明句柄已全关时回报暂忙，而不是承诺此刻即可回收。不保存外部 URL、书签或目录清单文件。
- **网络与取消：** 应用没有网络客户端、上传、成员提取、缓存或归档写入功能。iCloud Drive 或其他文件提供方可能因系统选择或协调而自行下载、物化或缓存文件，不能保证选档完全离线。取消会撤回当前界面请求，通知协调器并在读取间检查；不保证系统已开始的下载或单次阻塞读取立即停止。
- **支持的声明：** 只读单卷、未加密、Store 的 ZIP 和固定标准结束记录的 ZIP64。名称须为 ASCII 或明确标为 UTF-8 的规范可移植名称；重名/别名、特殊文件、必然重叠的成员范围、未知格式或超限均拒绝整份目录，不显示部分结果。中央目录最多 2 MiB、8,192 条显式记录、12,288 个含隐式目录的节点、累计名称 512 KiB、48 层；单文件声明 128 GiB、合计 256 GiB。

## 按名称查找并定位

打开一份归档后，点「按名称查找」，输入文件或目录的名称片段并点「查找」。只匹配本次已读取的目录记录中的单个名称，区分大小写和实际字符写法，不隔目录搜索路径、不按正则、不读正文。提交上限为 128 个 UTF-16 单元，须先完成输入法组合。结果用可滚动的列表显示完整路径，可分辨同名项，也能找到空目录和归档推导的目录；没有匹配时保留原页。

点结果只到该条目**所在目录的实际页**并滚至该条，不打开成员或进入匹配的子目录。在普通目录页再次点文件并确认，才核验 CRC 或看文本。「返回目录」不改变原来目录与页；「取消查找」也不关闭已选归档。换档、退后台或原文件访问失效会移除搜索词、结果及迟到回调。查找不再取得授权，不调用文件提供方，不另开或读取文件，不保存所输内容和结果。键盘属于系统；应用不主动联网。

## 分页预览纯文本

- **全文：** 符合规则的 **0 至 256 KiB 原始字节**可核验后完整翻页。0 字节标为空文本。
- **前部：** 对更大的成员，只有明确选择「完整核验后预览前部」，才从原文件一次读完这项计算 CRC；不为看开头悄悄开始长任务。只保留开头最多 256 KiB，另有至多 3 字节用于判断边界。若边界确实切过合法的 UTF-8 字符或 CRLF，显示到该单位之前。窗口写清本项完整核验量和实际显示量，不声称后文也是文本。
- 两种预览都必须读完，由原文件状态、授权、头和目录复核、完整 CRC 共同过关，再按严格 UTF-8 规则判断所显示的范围。末尾 CRC 损坏也不显示前部。CRC 不符、未读完、不是可显示文本分别提示。

普通文字、制表、换行可显示；CRLF 只在显示时转为换行。孤立回车、方向或其他控制与默认可忽略字符、私用或未分配码位均拒绝，不静默替换；因此带 BOM 或含零宽连接符的文本也可能不显示。每页至多 8,192 个 UTF-16 单元和 256 个换行，不拆代理对。原生纯文本视图只显示当前一页、在屏幕剩余高度内纵向滚动。翻页先核对原安全作用域/展示器和已持有文件的状态，不重新取授权、协调读或重读正文。不编辑、选字、拖出、保存或分享；网址、HTML 和代码只当文字，不点开、不执行。关闭、换选、退后台、文件展示器要求让出访问或发现原件变化均清除正文。文件提供方仍可能因第一次明确的协调校验自行下载。

## 工程与发行

独立打开 `ZipPreview.xcodeproj`，应用及 XCTest 源目标均包含在 `ZipPreview` 方案内。最低系统为 iOS / iPadOS 16；源码使用 UIKit、Foundation、Uniform Type Identifiers、Darwin 和系统 SDK 自带的 libz（仅取 CRC-32），不下载第三方包。工程不预设开发团队、证书、云容器或发布账户。 参见[版本化本地归档候选与签发门槛](RELEASE.md)：当前 App 目标已有共享版本、独立图标和原选档文件元数据的隐私清单；不注册外部文件处理。

**本次只编写/静审：** 没有用 Xcode 构建、运行测试、安装到设备或生成签名包。可发行前须在获准的 macOS/Xcode 环境独立构建并签名，在真实 iPhone/iPad 上验证本机和外部文件提供方、无授权/失联/等待下载、取消/换选/转入后台、外部改名/删除/占用、目录导航、读不完和 CRC 不符、文本的 32 KiB+1、256 KiB、真实大文件前部/全量读提示、未展示尾部 CRC 失败、跨边界四字节 UTF-8/CRLF、大字号下翻至密集换行后的最后标记、VoiceOver 阅读、关闭或失效后旧正文与旧页按钮均不再作用，以及超过 4 GiB 的 ZIP64。查找另验同名跨目录（其中一个在第 2 页）、输入法组合与长路径/大字号、返回保留原页、结果页关闭动画期间换档/权限失效不能装入旧结果、旧目录表点按不能作用以及再次点文件才出现确认；另核图标、隐私披露与发行配置。

设计依据：[Apple 文档选择器](https://developer.apple.com/documentation/uikit/uidocumentpickerviewcontroller)、[安全作用域](https://developer.apple.com/documentation/foundation/url/startaccessingsecurityscopedresource())、[文件协调和取消](https://developer.apple.com/documentation/foundation/nsfilecoordinator/cancel())、[PKWARE ZIP 规范](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)。
