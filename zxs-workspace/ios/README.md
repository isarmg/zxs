# iOS：预览一份归档的目录

打开应用，点「选择 .zxs 或 Store ZIP」，在系统文件选择器里选一份文件。点目录看下一级，文件下方显示 ZIP 声明的字节数。每页最多 100 项，可查看空目录、翻页和返回。要核验正文，点普通文件，核对成员和首行给出的全部读取字节数，再选「只核验 CRC」「核验后看全文」「完整核验后预览前部」或「完整核验后按页跳读全文」。只有这次确认才逐块读取；选档、浏览和定位都不触发正文读取。较大文件可能耗时，读时可取消。

**目录预览与单项 CRC 是两种不同的结果。** 浏览只看中央目录、层级、条目类型和必要物理范围；正文损坏仍可能列出原来的名称与大小，尾部定位窗口也可能物理覆盖最后一项的一部分。明确核验单项时，程序重核目录、所点成员的精确名、本地头、大小与数据边界，并通过系统 zlib 分块核对 CRC-32；每次底层原句柄读取不超过 64 KiB。对流式 ZIP，描述符必须从正文末尾恰好延伸到下一物理本地头或中央目录，本地头或中央目录以 ZIP64 表示成员长度时，描述符须用 64 位长度。若只有中央目录里的位置偏移用 ZIP64，则按完整物理区间接受 32 位或 64 位长度（均可带或不带签名）；歧义、填充等其他变体拒绝核验。读不完或发现变动时不会返回部分结果。

相符只说明本次读出的单项数据与归档给出的 CRC-32 对得上，不是签名；正文和校验值都可能被改。只核单项不验证其他成员、整树标记、身份或分支头。

- **位置和授权：** 只通过系统单文件选择器原地打开，不创建副本。在前台对本次选择保留临时安全作用域、文件展示器和一个普通可定位文件的原只读句柄。读目录和读成员分别经过系统文件协调；等待用户决定时不占协调读取。再次核验仍使用原句柄，按协调访问器给出的名字核对实际身份和文件状态，不按名字打开另一份文件。外部移动、写入让渡、删除、换选、取消正在进行的读取或退至后台都会结束原会话；在途读取退出后释放句柄和作用域。文件提供方请求回收本地副本时结束会话；不能证明句柄已全关时回报暂忙，而不是承诺此刻即可回收。不保存外部 URL、书签或目录清单文件。
- **网络与取消：** 应用没有网络客户端、上传、成员提取、缓存或归档写入功能。iCloud Drive 或其他文件提供方可能因系统选择或协调而自行下载、物化或缓存文件，不能保证选档完全离线。取消会撤回当前界面请求，通知协调器并在读取间检查；不保证系统已开始的下载或单次阻塞读取立即停止。
- **支持的声明：** 只读单卷、未加密、Store 的 ZIP 和固定标准结束记录的 ZIP64。名称须为 ASCII 或明确标为 UTF-8 的规范可移植名称；重名/别名、特殊文件、必然重叠的成员范围、未知格式或超限均拒绝整份目录，不显示部分结果。中央目录最多 2 MiB、8,192 条显式记录、12,288 个含隐式目录的节点、累计名称 512 KiB、48 层；单文件声明 128 GiB、合计 256 GiB。

## 核验整份 .zxs 的内容

在浏览 `.zxs` 时，可另点「核验整个 .zxs」。确认页显示所选文件、包内节点和**全部成员正文总字节数**，另需读取 ZIP 元数据，较大归档可能耗时且可取消。不自动随选档启动，不用于没有规范快照标记的普通 ZIP。只使用本次原安全作用域和原 FD，校验全部显式成员的本地布局、长度与 CRC；逐块同遍计算每个文件的 SHA-256。将文件与目录（含空目录和隐式祖先）按完整路径纳入整树摘要，要求与原 ZIP 注释中的规范标记一致；任一不符都不报告通过。

通过只说明**本次读出的逻辑树与这一份文件自带的标记一致**。标记没有签名，不认证发布者，不证明规范仓库槽、分支头、祖先或归档逐字节不变。关闭、换档、退后台或失去原授权后不显示迟到结果，不保留校验文件、也不解包。仍限下文说明的 Store / ZIP64 范围和目录预算。

整份核验与单项 CRC／核验后预览都会显示已处理正文和声明总量；计数来自同一次分块处理，不含 ZIP 元数据或之后的文本翻页，也不是系统提供方的下载进度。达到总量后仍可能在复核末尾、原文件和授权，或得出内容不符。取消、换档或失去前台访问后，不再更新旧任务进度。

## 按名称查找并定位

打开一份归档后，点「按名称查找」，输入文件或目录的名称片段并点「查找」。只匹配本次已读取的目录记录中的单个名称，区分大小写和实际字符写法，不隔目录搜索路径、不按正则、不读正文。提交上限为 128 个 UTF-16 单元，须先完成输入法组合。结果用可滚动的列表显示完整路径，可分辨同名项，也能找到空目录和归档推导的目录；没有匹配时保留原页。

点结果只到该条目**所在目录的实际页**并滚至该条，不打开成员或进入匹配的子目录。在普通目录页再次点文件并确认，才核验 CRC 或看文本。「返回目录」不改变原来目录与页；「取消查找」也不关闭已选归档。换档、退后台或原文件访问失效会移除搜索词、结果及迟到回调。查找不再取得授权，不调用文件提供方，不另开或读取文件，不保存所输内容和结果。键盘属于系统；应用不主动联网。

## 分页预览纯文本

- **全文：** 符合规则的 **0 至 256 KiB 原始字节**可核验后完整翻页。0 字节标为空文本。
- **前部：** 对更大的成员，只有明确选择「完整核验后预览前部」，才从原文件一次读完这项计算 CRC；不为看开头悄悄开始长任务。只保留开头最多 256 KiB，另有至多 3 字节用于判断边界。若边界确实切过合法的 UTF-8 字符或 CRLF，显示到该单位之前。窗口写清本项完整核验量和实际显示量，不声称后文也是文本。
- **大文件跳读全文：** 主动选择后才开始一次整项读取，同时计算 CRC、按显示规则核验全部 UTF-8，并对每个 1 MiB 原始正文块建立 SHA-256、段首页码和至多 3 个跨界字节的信息。单项 128 GiB 时这张表约 4.625 MiB，另有有界工作缓冲。核验后可输入任意页码或连续翻页；每次重新协调本次所选文件，用同一原只读 FD 复核该页的一至两个正文块、原目录记录、归档末尾、本地头及描述符。不会重扫全部正文，也不保留全文；段末可能较短，跨块的 UTF-8 字符或 CRLF 不拆开。点「关闭文本」可取消在途查页，复核不符只能重新选择，不重开同名文件或沿用旧索引。
- 三种文本动作都要求原文件状态、授权、头与目录复核、完整 CRC 过关；所选显示范围还要符合严格 UTF-8 规则。未展示尾部 CRC 损坏也不显示正文。CRC 不符、未读完、不是可显示文本分别提示，不自动从全文退回前部。

普通文字、制表、换行可显示；CRLF 只在显示时转为换行。孤立回车、方向或其他控制与默认可忽略字符、私用或未分配码位均拒绝，不静默替换；因此带 BOM 或含零宽连接符的文本也可能不显示。每页至多 8,192 个 UTF-16 单元和 256 个换行，不拆代理对。原生纯文本视图只显示当前一页、在屏幕剩余高度内纵向滚动。翻页和实际展示前核对原安全作用域/展示器和已持有文件的状态。小全文与明确前部翻页不协调、不重读；大文件跳读按上面的有界方式复核，不重新取授权。块摘要只绑定该次读取，不验证来源或整包。不编辑、选字、拖出、保存或分享；网址、HTML 和代码只当文字，不点开、不执行。关闭、换选、退后台、文件展示器要求让出访问或发现原件变化均使当次界面失效；先清正文和页码，再等待协调或句柄退出。文件提供方仍可能因选择或协调读取自行下载。

## 工程与发行

独立打开 `ZipPreview.xcodeproj`，应用及 XCTest 源目标均包含在 `ZipPreview` 方案内。最低系统为 iOS / iPadOS 16；源码使用 UIKit、Foundation、Uniform Type Identifiers、Darwin、系统 CryptoKit（SHA-256）和 SDK 自带的 libz（仅取 CRC-32），不下载第三方包。工程不预设开发团队、证书、云容器或发布账户。 参见[版本化本地归档候选与签发门槛](RELEASE.md)：当前 App 目标已有共享版本、独立图标和原选档文件元数据的隐私清单；不注册外部文件处理。

**本次只编写/静审：** 没有用 Xcode 构建、运行测试、安装到设备或生成签名包。可发行前须在获准的 macOS/Xcode 环境独立构建并签名，在真实 iPhone/iPad 上验证本机和外部文件提供方、无授权/失联/等待下载、取消/换选/转入后台、外部改名/删除/占用、目录导航、读不完和 CRC 不符、文本的 32 KiB+1、256 KiB、真实大文件的前部及全文跳读确认、整项读量与取消、末页直达/多段读量/跨块四字节 UTF-8 与 CRLF、未展示尾部 CRC 或触块摘要失败、大字号密集换行下实际翻到末页、页码输入和 VoiceOver、协调等待时关闭或失效须能先撤下旧正文，迟到页不作用，以及超过 4 GiB 的 ZIP64。查找另验同名跨目录（其中一个在第 2 页）、输入法组合与长路径/大字号、返回保留原页、结果页关闭动画期间换档/权限失效不能装入旧结果、旧目录表点按不能作用以及再次点文件才出现确认；整包检查另验项目实际生成的 .zxs（含空目录、两个代数和可移植 UTF-8 名），修改正文并重算 CRC、替换标记或提供方撤权都不能报通过；取消后不显示旧结果。另核图标、隐私披露与发行配置。
