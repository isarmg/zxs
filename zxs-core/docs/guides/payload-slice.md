# 显式读取原节点的一段正文

[仅静态] Linux 客户端源码新增独立的区间入口，服务器须支持[原节点正文与单段读取](../../../zxs/docs/specs/payload-range.md)。既有 Basic 另存、提交和回执专用模式不变；这里不验真实 HTTPS/2 或安装。

选择已经有确认基线的普通工作区路径、一个字节区间和从未使用的新输出名：

```sh
zxs-client --payload-session HTTPS地址 账号 /绝对/私用目录 slice /绝对/已绑定文件 1024 512 /绝对/新片段
```

读的是原基线的不可变服务器节点，不读取所选本机路径当前的正文。每次最多读取一段 8 MiB，不限制整个文件大小。登录只授权该项明确选择，不能沿用到另一节点、区间或输出名。

只在原状态库处于干净的回滚日志模式时才打开。发现日志、WAL 或 SHM 文件就停止，不读其内容，也不修复；登录和另存前发现状态库有变化时，请重新选择。核对原账号、证书、HTTPS/2 和原目录身份后才登录。

- 只有已核对的单段 `206` 能发布；超出文件尾的有效区间可截到原文件尾。`416` 不写入。
- 如果返回整份 `200`、版本或区间对不上、短读或目标名后来被占用，不另存或覆盖；不会自动改用旧接口。
- 成功只另存片段并报告片段摘要。它不是整文件 SHA-256 的证明。不改映射、原回执、服务器或现有本机文件。
