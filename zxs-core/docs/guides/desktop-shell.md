# 可选 Linux 桌面窗口

[仅静态] 此窗口是 `zxs-core` 的可选独立构建入口，尚未运行窗口或真实服务验收。默认 Linux CLI、其锁文件、手动 HTTPS/2 作业、旧 Workspace 和旧文件均不变。当前需已有登记的本机私用目录；本窗口不做首次登记，不调用终端口令。

## 窗口内操作

1. 选原私用目录，输入当初登记的 HTTPS 地址和账号。在只读确认页核对，再验证 HTTPS/2。只有通过证书、名字、工作区和 HTTP/2 检查才出现受保护口令页；首个带口令的请求等到原 HTTP/2 发送端就绪才核对最终同意，已撤销便不发送。只有服务返回已授权清单才显示在线。
2. 选容器和已返回的分支头，输入普通目录下确切的新文件名，核对原节点、完整长度和摘要后另存。换头、换目录或同名不能静默替换。
3. 窗口显示普通文件路径，用自己的编辑器打开。编辑器保存不会上传。回到窗口核对完整内容，先冻结，再在另一张确认页核对并提交同一原操作。
4. 关闭、断线或失去回执时保留本机文件和原号。重开旧操作只查原回执；未知或冲突不自动重试。关窗或失焦所在的界面帧不能确认操作；已接受的提交不会被说成未发送。

## 当前边界

- 可选包位于 `zxs-core/desktop/`，自有 Cargo 锁、Rust 1.100.0。提供原生窗口的 eframe 使用 Glow，默认特性关闭；实际支持的显示平台、系统显卡和可访问性尚未验收。
- 口令页不是普通文本框。按键和文本未交给界面控件或撤销历史，原生剪贴板后端与快捷键禁用。本切片使用短期清零内存，仅接受直接键盘输入，不接受粘贴、输入法或显示原文。收到离焦、最小化、关窗或取消信号时，清掉窗口内尚未交出的输入，并撤销尚未发出首请求的登录。已发出的请求不能撤回。口令不保存；不控制操作系统输入通道和临时内存。
- 文件须通过现有 Linux 普通目录约束。详情显示已有接口返回的第一页分支，待决区只列前 32 条；没有虚拟盘、同步守护、ZIP、本地历史、恢复写入、其他平台文件适配或新网络入口。
- Linux 窗口、实际输入事件、CJK 字形/输入和真实 HTTPS/2 是另外的验收，未由源码或编译结果证明。依赖发行前须记录准确许可和随附字体许可（OFL-1.1 与 Ubuntu Font License 等）。

## 构建检查

已用锁定 Rust 1.100.0 在 Linux x86-64 离线通过 `cargo check --locked --offline --all-targets`、格式和严格 Clippy；未执行测试或启动窗口。以下从仓库根目录检查：

```sh
cargo +1.100.0 check --locked --manifest-path zxs-core/desktop/Cargo.toml --all-targets
```

独立锁的 SHA-256 为 `c1de29ff652cb3a59db6939dffa40d71adf02198abd40c67a23361547455fbac`。所查 Linux 活跃依赖无原生剪贴板、外部链接、持久化、截图或 WGPU；锁中其他平台或备用项不代表启用。
