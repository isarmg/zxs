# 可选 Linux 桌面窗口

此窗口是 `zxs-core` 的可选 Linux 桌面入口。[验收状态](../../TASKS.md)。可以直接新建或打开私用工作区，不调用终端。默认 Linux CLI、旧 Workspace 和旧数据不变。

## 窗口内操作

1. **新建：** 请选择一个本机普通父目录，输入 HTTPS 地址和账号，点「Create new workspace」。核对新路径并验证 HTTPS/2，再在保护页登录。获得授权清单后才新建仅本人可读写的 `zxs-workspace` 子目录；无需提前建私用目录。见[首次设置](#首次设置与取消)。
2. **打开已有：** 选择原私用目录，点「Open existing」。填原 HTTPS 地址和账号并核对；通过原证书、主机名及 HTTP/2 检查后才提示口令。打开不会创建。
3. 选容器和分支头，再选择输出文件夹并补上新文件名。核对原节点、完整长度和摘要后另存。选择器只填路径，不打开文件或确认传输；检出不覆盖。
4. 用自己的编辑器打开普通文件。编辑器保存不会上传。回到窗口选择已映射文件，经核对后冻结，再单独确认提交原操作。
5. 首次上传：选尚未映射的普通文件，填写远端名称，核对文件路径、完整长度和摘要，再点击一次「Submit new file」。客户端内部先封存原文、登记原号，再按原号查询并提交。无需单独冻结确认；确切回执到达即显示。远端清单可另行刷新。
6. 断线或丢回执时保留本机编辑和原号。重开后可在本机待决项翻页核对原回执，不发送正文。已接受的提交不能因为关窗被说成未发送。

**重开后处理尚未发送的整文件封存。** 在「Pending originals」按原号找到明确未登记发送尝试的整文件封存。登录后点「Review full-file submit」，核对原号、目标、长度和摘要，另点确认才可尝试发送同一份封存；发送前必须确认原回执不存在。也可离线点「Review discard freeze」并确认，只移除本机封存，不改工作文件或原映射。发生过尝试、状态不明或冲突的整文件不能从此处重发。

**大文件可选分块。** 在同一文件和远端名称下点「Review resumable upload」，核对预览后只需确认一次。普通首版按钮和 Enter 仍走原整文件路径。中断后在「Pending originals」按原号查回执，确要续传才点该行的分块预览并确认，不需复制编号到终端。见[约束与状态](resumable-upload.md)。

**已记录的冲突。** 「Pending originals」只为已记录的冲突显示「Review archive conflict」。可离线核对原号、路径、目标和摘要，再点「Archive this conflict」。归档保留原号、旧文件、封存和映射，不撤销远端操作，也不会自动重发或合并。离线不会查询；在同一窗口登录后，结果区才显示原号的回执查询入口。

继续原容器前，先签出已核定的当前分支头到新文件，再手动合并。首次新建冲突则先查原回执和远端清单。旧客户端不能打开第一次归档后的私用状态目录；普通文件不受影响。见[归档与原回执](conflict-archive.md)。

## 首次设置与取消

父目录须为自己的本机 ext4/XFS 普通目录，组和其他用户不可写。普通 0755 主目录可用。发现同名对象时不采用、不覆盖、不改权限；请选择其它父目录，或用「Open existing」打开已有工作区。

口令仍只在受保护页输入。验证失败或建立子目录前取消，不创建。已开始本机创建但未确认时，检查原位置或尝试「Open existing」；不要覆盖、删除或自动重试。

新建只在持有的父目录中独占占用原名；随后核对同一个子目录和新数据库。与普通工作区一样，这不隔离使用同一 Linux 账号的其他进程。

## 输入、焦点与本机限制

- 普通字段支持系统中文输入和复制、剪切、粘贴快捷键；Enter 打开或核对当前字段，不替你批准操作。系统字体回退使用已安装的字体，未装对应中文字形时仍可能缺字。
- 口令支持直接键入、输入法最终提交和在受保护页点名使用 Ctrl+V，内容不进入普通控件、撤销历史、日志或配置。输入法确认候选字和同一批 Enter 不会登录；用下一次 Enter 或点击确认。系统输入法、剪贴板管理器及原生工具包的临时传递缓冲不由本应用控制。
- 短暂切窗、遮挡或最小化保留已输入草稿与预览，但不接收后台输入。恢复到前台后，尚未接受的文件确认需重新点；已经在前台确认的登录继续，不用重输。明确取消、关窗、锁定、换工作区或已验证登录到期会清空密钥或待确认输入。首请求只能在最终 HTTP/2 放行前撤销。
- Linux 选择器优先使用本机 XDG 门户；库可调用本机 Zenity 作为后备。取消或后端不可用时可直接输入绝对路径。

## 构建检查

可选包有独立 Cargo 锁，使用 Rust 1.100.0。以下从仓库根目录检查，不启动窗口：

```sh
cargo +1.100.0 check --locked --manifest-path zxs-core/desktop/Cargo.toml --all-targets
```

活跃依赖限定为 eframe 0.37.0 的 Glow、系统字体提供器、系统剪贴板和原生窗口，以及 rfd 0.17.2 门户；不启用外链、持久化、截图或 WGPU。发行前需要核对其他依赖和随附字体许可（含 OFL-1.1 与 Ubuntu Font License）。
