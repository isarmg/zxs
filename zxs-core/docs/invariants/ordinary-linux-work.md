# Linux 普通编辑路径与私有状态

[仅静态] 本页只说明普通文件的权限边界，不增加文件系统或网络协议资格。现有试验仍只对明确的 ext4 临时目录分别取证；不据此声明 XFS、Btrfs 或安装包通过。

- 普通工作目录和嵌套目录须归当前普通账号所有。接受同组可写的 `0775`，以及用户自己的单链接普通编辑文件 `0664`，例如在 `umask 0002` 下产生的文件。仍不接受其他人可写、符号链接、设备、FIFO 或跨挂载访问。
- 编辑器可用临时文件原子替换；原核对凭据随之失效，要重新核对当前文件。另存只发布到新名，匿名暂存保留原 `0600`，不会因为父目录同组可写而改成 `0664`。已占用名称保持不动。
- 私用状态仍要求 `0700`，数据库、租约和封存的权限不放宽，不保存到普通工作路径。代码包扫描普通来源目录时用相同的权限与身份规则；不读私用数据库、普通树之外或忽略的成员。

需要确认原目录和当前 inode，不能把同一拼写当作同一个对象。这是对协同编辑和可检查换件的保护，不是对同组写入者在最终核对之后的隔离承诺。
