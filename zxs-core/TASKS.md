# 第一条真实资格线

已执行官方锁解析、格式/类型检查和 4 个纯内存单测。没有执行客户端和真实服务的端到端资格。必须用孤立源码（无同仓其他项目）、真实 Linux 普通用户、实际本机 ext4/XFS、明确受信的隔离 TLS/H2 环境。构建、来源与运行证据分开记录。

1. [单独锁定和构建见证](docs/guides/locked-build.md)：审过完整锁和许可证后，再编独立安装包。
2. 先在专用普通目录签出；使用原普通文件的原子替换保存方式编辑，封存后进一步编辑本机文件。服务端实际写入后丢首次响应，另起进程和同一私用目录核对。必须只 GET 原号，不发第二笔 POST，基线为确切已提交字节，真实本机第二次编辑还显示未提交。正文遗失仍可查回执但不能发；错账号/目的地、空 503、错误 404、假回执、非 H2 不能授权上传。
3. 以独立 ZIP 工具检查空目录、真实文件 Deflate method 8、CRC 及 ZIP32。对不同创建顺序、mtime 和普通模式的同内容树逐字节比较；核对忽略、差异清单、符号链接、特殊文件和后期同名冲突。冻结或发送不能跟进已换名的来源。
4. 未完成：发布构建、隔离安装和真实端到端运行；已冻结的未来 Bearer/Range/断点契约和所有上层壳须单独审查。不得为本候选删除旧史或改现有验收。
