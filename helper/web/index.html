准备安装根与运行互斥

只在缺少时原子创建 root 所有、0755 的 /zxs，已有安全目录只核验并同步，不改已有权限或内容。当前 ZXS 可执行程序启动前独占该目录的 OS 租约，直到所有运行时工作结束。准备此空根不代表账户、磁盘或系统已经初始化。

不会停止或启动任何服务。旧二进制、第三方进程、Samba/passdb 和其他设备写入者不受此协议自动约束，仍须单独停服。这里的成功回执不证明当前没有其他进程运行。


      
      

    

    

      
安装内置 ZXS 程序

      
只将匹配版本可执行文件放到 /usr/local/bin/zxs，已有不同内容、链接或不安全权限一律拒绝，不覆盖数据、配置或凭据。相同文件可重新核验并同步持久化。本片不会安装依赖、设置 systemd/SMB、初始化系统或启动 ZXS。

首次初始化前：服务私有目录

      
为已存在的本机非 root 服务账户准备 /zxs/data/{state,management,disks}。从安全的本机 /etc/passwd 核对准确 UID / 主组 GID，创建整棵 0700 空目录树，不改现有目录权限，也不清空任何数据。

      

        

        
此步骤不创建 Unix/管理员/SMB 账户，不初始化数据库或磁盘，不表示系统可以正常启动。当前 daemon 运行时会拒绝准备；旧版和第三方写者仍须单独停止。

        
      

      

      
      

    

    

      
首次初始化：只创建系统管理员

      
在前一步准备的准确空 /zxs/data/{state,management,disks} 中创建唯一 ZXS 管理员。必须已有正确的本机服务账户。原子写入当前管理凭据、管理初始化意图和系统管理权威标记，不创建 Unix/Samba 账户，不初始化磁盘或存储数据库。

      

        

          
          
        

        
        
        
      

      

      
      

        

          
          
        

        
        
这是管理账户阶段，不是完整系统初始化。首批空盘可在下一节继续初始化；完整就绪交接仍未提供；不要把这里的成功当作可以启动完整存储服务。无认证且明文 HTTP，只能在可信隔离网络使用。密码不进 URL、日志或回执，提交即清空输入框。

        
      

      

    

    

      
首次存储：整批初始化现有空目录

      
先完成管理员，再由你在工具外准备和挂载正确的持久存储目录。填写 /zxs/data/disks 下的全部直接子目录，一行一个；必须已有准确服务 UID/GID 与 0700。额外、缺失、外来、非空或不安全内容会拒绝，不格式化设备、不创建挂载点、不修改已有权限。每个选择成为独立一级盘，不按顺序建立备份链。

      

        
        
        
        
        
      

      

      
      

        
        
实际存储初始化由同一二进制的非 root 服务账户工作进程完成，使用当前核心发布协议，并在完成前发布凭据灾备快照和核验系统/逐盘派生库。不启动服务，不是全新逐盘权威协议迁移。失败可能已经写入部分或全部初始化材料，只保留原请求续作，绝不能清盘重试；过早中断或损坏未必能自动恢复。

        
      

      

      
本阶段不是完整安装就绪：仍缺最终干净启动门禁、运行目录/依赖/VFS 与实际 systemd/SMB 激活。不要把首批存储回执当作所有首次安装步骤已完成。

    

    

      
准备与安装 systemd / SMB 配置文件

      
生成与内置版本绑定的未激活配置包，存于已存在、root 所有且其他用户不可写的 /zxs/.zxs-helper-deployment-摘要/。不会写入 /etc、合并现有 Samba 共享、创建账户、设置密码，或执行服务 reload / start / enable。

      

        

          
          
          
        

        
        

          
          
        

        
UID 0 只适用于已经验证桥接在 Samba root 身份下连接的主机。这些账户名只做语法约束，尚未核实系统账户、UID、VFS ABI、依赖、路径权限或初次初始化。准备期间与当前 ZXS 可执行程序互斥，但不证明旧版或 Samba 已停。原样准备不是配置生效。

        
        
      

      

      
      

      
安装到固定系统路径，不启动服务

      
此操作另行核对本机服务账户、主组、独立 Samba 账户，以及已经安装的准确内置 ZXS 程序。只新建或核验 /etc/systemd/system/zxs.service 和可选 /etc/samba/zxs.conf，不覆盖不同文件，不改默认 smb.conf，也不创建父目录。

      
安装会让 unit 文件出现在 systemd 的搜索路径，但不运行 reload / start / enable、不接管 Samba 配置和 passdb。配置与意图记录不是完整系统初始化或可以启动的证明。当前 ZXS 租约能互斥；旧二进制、外部配置管理者和 Samba 仍须另行停止，不能并发编辑或加载配置。

      

      
      
      

    

    

      
重置已存在的 ZXS 管理员密码

      
仅重置固定 /zxs/data/management/management-auth.json 中已存在的管理员，必须已有真实管理权威和正确服务所有权。撤销全部 ZXS 登录会话，但不更改 Samba 密码、不创建新管理员或初始化系统，也不启动服务。

      

        
        
        
        
      

      

      
      

        

          
          
        

        
        
无登录且明文 HTTP，网络可达者也能重置密码。只在可信隔离网络操作。密码不放入 URL、命令行、日志或回执；提交后输入框立即清空。灾备凭据副本本片不更新，未来显式灾难恢复不能把旧副本当最新密码。若结果不确定，保留当前计划并重新输入同一个新密码来续作，不换请求或删除材料。

        
      

      

    

    

      
重置已存在的本地 Samba 密码

      
先在上方配置表中填写与已安装文件完全一致的 ZXS 服务账户、主组、监听地址和独立 Samba 账户。本入口仅支持当前独立 /etc/samba/zxs.conf、既有本地 tdbsam 及 /var/lib/samba/private/passdb.tdb；不创建 Samba/Unix 账户，不更改 ZXS 管理员或 Unix 密码，不启用服务。

      

        
        
      

      

      
      

        

          
          
        

        
会通过已核验的本机 smbpasswd 执行真实密码变更。无登录、明文 HTTP，只在可信隔离网络使用；密码只经请求正文和子进程 stdin，不放入 URL、argv、日志或回执。账户必须已存在，禁用状态不会被主动启用。不会撤销已有 SMB 会话，也不验证一次真实网络登录。

        
      

      

        
        
      

      

      
Samba 外部命令没有本工具的幂等令牌。响应丢失、断电或非零退出后密码可能已经改变，原请求不自动重放、不回滚整个 passdb。先查询并保留证据；确需再次重置时重新预览和手动确认新请求。完成回执只证明当时命令成功、目标账户读回和数据库同步，不保证现在的密码或服务状态。

    

    

      
选择准确的独立磁盘

      
使用 independent-disk-journal 的磁盘选择 JSON，必须包含绝对路径、来源身份、incarnation 和可选检查点。不自动发现或接纳陌生盘，也不把在线池格式当作此协议。

      

        
        
        
        
        
这是操作人的确认，不是已取得主服务停服锁。本片不打开在线 Engine，不改变来源盘；读取仍受当前 root 身份、权限、路径固定和完整性边界限制，不能绕过服务账户所有权。
