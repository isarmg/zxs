首次初始化前：服务私有目录

      
为已存在的本机非 root 服务账户准备 /zxs/data/{state,management,disks}。从安全的本机 /etc/passwd 核对准确 UID / 主组 GID，创建整棵 0700 空目录树，不改现有目录权限，也不清空任何数据。

      
原请求中断可保留同一账户与摘要后续作：只交接原 root pending 中尚属 root 的 0700 空子目录。未知内容或权限不匹配仍拒绝，不清理 pending，不改已发布的数据树。

      

        

        
此步骤不创建 Unix/管理员/SMB 账户，不初始化数据库或磁盘，不表示系统可以正常启动。当前 daemon 运行时会拒绝准备；旧版和第三方写者仍须单独停止。

        
      

      

      
      

    

    

      
首次安装：运行目录与空 SMB 导出

      
仅为已存在的本机服务账户准备 /zxs/{cache,config,home,log,run,tmp}，均为该 UID / 主 GID 的 0700 空目录；另建 root:root、0755 的空 /zxs/smb-export。不接管已使用的运行目录，不清理日志、socket、缓存或导出内容。

      

        

        
      

      

      
      
      

      
此步骤不创建账户、密码或数据库，不加载 VFS，不修改 systemd/Samba 配置，也不启动或启用任何服务。完成回执不是整体安装 ready。服务使用这些目录后，此首装入口将明确拒绝，不会重置为新空目录。

    

    

      
首次初始化：只创建系统管理员

      
在前一步准备的准确空 /zxs/data/{state,management,disks} 中创建唯一 ZXS 管理员。必须已有正确的本机服务账户。原子写入当前管理凭据、管理初始化意图和系统管理权威标记，不创建 Unix/Samba 账户，不初始化磁盘或存储数据库。

      

        

          
          
        

        
        
        
      

      

      
      

        

          
          
        

        
        
这是管理账户阶段，不是完整系统初始化。首批空盘可在下一节继续初始化；完整就绪交接仍未提供；不要把这里的成功当作可以启动完整存储服务。无认证且明文 HTTP，只能在可信隔离网络使用。密码不进 URL、日志或回执，提交即清空输入框。

        
      

      

    

    

      
首次存储：整批初始化现有空目录

      
先完成管理员，再由你在工具外准备和挂载正确的持久存储目录。填写 /zxs/data/disks 下的全部直接子目录，一行一个；必须已有准确服务 UID/GID 与 0700。额外、缺失、外来、非空或不安全内容会拒绝，不格式化设备、不创建挂载点、不修改已有权限。每个选择成为独立一级盘，不按顺序建立备份链。

      

        
        
        
        
        
      

      

      
      

        
        
实际存储初始化由同一二进制的非 root 服务账户工作进程完成，使用当前核心发布协议，并在完成前发布凭据灾备快照和核验系统/逐盘派生库。不启动服务，不是全新逐盘权威协议迁移。失败可能已经写入部分或全部初始化材料，只保留原请求续作，绝不能清盘重试；过早中断或损坏未必能自动恢复。

        
      

      

      
本阶段不是完整安装就绪：仍缺最终干净启动门禁、运行目录/依赖/VFS 与实际 systemd/SMB 激活。不要把首批存储回执当作所有首次安装步骤已完成。

    

    

      
已有池：添加并初始化准确的空目录批次

      
只针对已初始化的 production 池与现有 /zxs/data/{state,management,disks} 布局。所有原盘和新目录必须在 disks 下，已有服务 UID/GID 与 0700；原盘和整批新目录须覆盖实际全部直接子目录。新目录必须为空，不接纳外来历史、不格式化设备，不修改原盘内容来冒充空盘。

      

        
        
        
高级备份关系必须同批设置完整低级链，不能填虚拟占位以后再补。这里仅添加真正空目录，绝不表示外来备份盘已经接纳。原有不可用/已注销盘不会被隐藏或自动重用。

        
        
        
        
      

      

      
      

        
        
      

      

      
共享原生 fence、控制归档、joint 和 activation 协议，成功仅以准确永久回执为准；中断可能已部分或全部发布，不删盘、不回滚或换编号重试。此片没有注销/移除、新计划下线、外来接纳、新逐盘权威迁移或完整系统就绪认证。可查询原操作，不能保证损坏介质可恢复。

    

    

      
外来高级盘：同批准备全部低级盘材料

      
实际检查一个外来二级或三级盘，必须同时列出全部低级真实空目录。二级需要一级；三级需要一级和二级。来源、已有池及所有低级目录都须是 /zxs/data/disks 的不同直接子目录，具备服务 UID/GID 与 0700。目标会得到完整独立的原始材料副本，原历史身份和缺失正文记录保持不变。

      
这是实际复制和可恢复的材料准备，不是正式加入。不会先接纳高级盘、先初始化低级盘或启动 writer。完整 State／数据库／共同接纳协议尚未闭合，完成后仍不能把这些目录交给普通 Add 或作为活动盘使用。

      

        
        
        
        
        
        
        
        
        
        
        
      

      

      
      

        
        
      

      

      
正式接纳前：核对原完整 State 与三范围数据库

      
先核对已完成的整批原材料，再从每个低级目标自身的原生发布链重建原 SYSTEM、原盘 current/history、FILE/目录库。必须保留完整 operations/principals/events，所有目标独立一致，不能拿健康同伴补缺。此阶段仍保留来源旧身份，不安装新链身份数据库，不授予外来成员资格。

      
      

      
      

        
        
      

      

      
      

      
      
正式接纳前：完整对象命名与原 State 绑定

      
每个低级盘从自身完整原生 State 和已验证三范围库独立推导同一对象 ID 映射，绑定现池完整 State 与所有新登记根。历史操作、作者和计划只进入外来审计命名空间，不变成现池账户、权限或幂等回执。此片只准备映射材料，尚不改写对象记录、不生成联合 State，也不正式纳入。

      
      

      
      

        
        
      

      

      
新身份提案必须建立在全部原三范围库独立验证完成之上，只绑定现池、来源身份、所有真实根及新 ID；尚不映射联合 State、不安装目标身份数据库、不建立共同发布或启动服务。

      
原计划在写入前持久保存，真实胶囊只读查询不补造材料。各目标可能分步准备，但只在全部原目标完成且同步后记录整批材料完成；任何中断都不授予成员身份。缺件、损坏、未知内容或身份改变保留拒绝。每个原始一级来源单独保留历史映射，不以名称合并历史。当前仅支持所有既有成员仍启用的 production 池，来源须来自其他池且保持原地不变。

    

    

      
已有池：注销 / 移除成员

      
保留磁盘物理字节和历史，不格式化、不擦除、不卸载。不保证剩余池仍能访问目标盘的全部内容：注销会改变当前成员及归属视图，可能使独有文件、历史或路径不可访问。重要内容请先另行备份。注销最后一个元数据成员会结束活动存储并进入只具管理权威的终态，必须另行确认；不会自动补入新盘或重新初始化。不提供计划下线。

      

        
        
        
        
        
        
        
      

      

      
登记 Enabled / Disabled 是意图状态，不是设备健康或在线证明。真实读取失败原样报告，不伪装成空池；已注销盘不会仅为查询状态而重新打开。

      

      
      

        
        
        
      

      

      
只有原生 D3 与永久回执核验后才返回 Completed。失败或断连可能已部分或全部发布，在结果不明时不要拔盘、删证据或换编号重做。只能继续原操作；终态下可核对原永久回执，检查剩余登记的准确 authority/registry 边界。下方单独提供逐笔终态后继，不自动恢复活动存储。检查摘要不是操作或准入令牌，不创建注销意图。本片没有失败自动回滚、外来完整链接纳或完整系统就绪证明。

    

    

      
终态管理：逐笔剩余登记移除

      
每笔必须基于上一笔已完成的精确 registry/永久结果，先在上方重新读取并选择实际剩余登记。已 Stop 的 Disabled 绑定必须同时验证原固定权威、Stop 操作和当前生命周期，单独标志不能证明安全。每笔完成还必须由原冻结历史和前笔投影验证完整可见项移除掩码，缺页或损坏不能自动补空。完成后可以另行预览下一登记，但掩码准备态仍不是元数据或活动存储恢复。不要用此操作替代外来盘接纳、擦盘或完整迁移。

      
      
      
      

      
      

        
        
        
      

      

      
保存完整终态移除链检查点

      
只有当前全部逐笔移除均已完成，才导出完整原选择、Stop 快照、永久回执和命名空间 mask；未决/缺失/损坏时拒绝，不导出前缀冒充最新。需要同时保留原完整控制归档，并把显示的摘要另存于可信位置。此文件不是 readmission 或外来盘接纳令牌，不携带可跨进程生效的 I/O 排除，也不恢复服务。

      
      

      
生成终态移除链后的原元数据恢复提案

      
按上方选中的仍登记 Disabled 原元数据盘，重放完整终态移除链，生成精确单盘恢复 registry 和完整继承命名空间提案。低级祖先必须仍有 Enabled 登记；历史 Config 中的已移除或停用祖先不能替代。此阶段不会打开目标/祖先目录、保留操作、写入新决定或恢复活动存储，下载文件不能用作执行令牌。目标决定和首笔输入须在下方单独确认准备；真实首笔发布和冻结 Current 读取已另有独立入口；活动 Current、writer 和 locator 仍未接通，不能把提案或读取报告当成重新接纳成功。

      
      

      

        准备原目标的真实决定，仍不恢复活动存储
        
这是有持久影响的准备阶段：会保留准确原请求、阻止新的终态移除，打开并锁住所选原目录，安装完整控制归档和独立目标决定。它不能完成 readmission、启用 writer 或启动服务；当前没有取消或换盘接口。若只需保存材料，请不要执行此步。中断后只能查询并续作同一请求，不删除证据或换编号重做。

        
        

          
          
        

        

        
        
此检查会持有所选原盘锁，读取实际三帧日志、两根完整快照及全链继承命名空间。它只返回已发布冻结视图的统计，不修复缺损材料、不读取文件正文，也不消费 Stop、分配新 epoch 或启用运行态 writer；不是重新接纳完成。

        

          
继续准备首笔原生输入，不执行发布

          
此步只用于上面已有原决定的同一请求。在 SYSTEM 和原目标各保留完整 core、State、registry、历史页及首笔 Candidate，独立读回；每根另需完整材料空间。编码中的预期 PUBLISHED 回执还没有真正提交，不表示接纳或可启动服务。中断后只能续作原请求，完成材料缺损不会自动重建。

          
          
        

        

          
选择准确新 epoch 和 Stop 后继计划，仍不启用活动存储

          
仅在真实首笔 Publication 和完整冻结 Current 可读后，为同一原盘选择唯一新 I/O epoch 及精确 bootstrap 后继记录，绑定旧 Stop、前次 epoch、物理身份及实际 seal。只保存 SYSTEM 计划，不更新 locator/head、不消费原 Stop，也不启用 writer 或启动服务。

          
          
        

        

          
在原盘作出准确 epoch 决定，尚不启用活动存储

          
本步不只是保存计划。将重读原目标实际日志及完整已发布材料，把已选 epoch/Stop 后继计划和真实不可改写的原生决定保存在原盘及 SYSTEM。无取消、换盘或另选 epoch；中断可能已经决定，只能按原请求续作。仍不改 locator/head、不消费 Stop、不启用 writer 或启动服务。

          
          
        

        

          
安装原生 generation 日志及元数据，仍不启用 writer

          
仅在原目标 epoch 真实决定完成后，将原实际三帧日志逐字节保留到对应 generation 目录，并将完整 State/registry/history/Publication 写入普通不可变对象地址、重新读回冻结 Current。不替换活动代际指针、盘 seal 或数据库，不消费 Stop；还不能启动服务。中断只续作原请求，完成后缺件不自动重建。

          
          
        

        

          
选择原准确 generation 并保留冷恢复依据，仍不启用 writer

          
仅接受上一步已完成的原目标日志、全部实际原生对象及原 epoch 决定。在 SYSTEM 和准确 generation 目录写不可覆盖的同一选择，再从实际安装字节打开冻结 Current。不会写普通活动 generation.json、更新盘 seal/数据库/locator 或消费 Stop；不能启动服务，也不是外来盘接纳。

          
          
        

        
        

          
写入真实首笔 Publication，仍不激活服务

          
只有原两根完整首笔输入才可执行。将在原目标专属首槽写入真实 ACCEPT、FINALIZE、Publication 并保存两根 seal/证据。这不是可撤销预览；无取消或换盘，错误也可能已经发布。当前仍不接纳活动 Current/writer，不消费 Stop、不启动服务，不能据此宣布重新接纳完成。

          
          
        

      

    

    

      
终态管理：重新接纳保留的原元数据目录

      
仅支持仍登记为 Disabled、具有完整原 Stop/历史元数据角色证明的原盘，并且没有开始任何逐笔终态移除。先在上方读取并选择准确终态登记。已注销、外来盘、替换目录、缺失证明或已有终态移除链均拒绝。此操作会核验并重新打开原目录，签发新 I/O epoch、提交真实元数据恢复决定；不会启动 ZXS 或保证全池健康，也不是新“计划下线”功能。

      
      
      
      

      
      

        
        
      

      

      
只有原生永久 disk-readmit 回执、新 epoch 和准确原决定核验后才返回完成。中断或失败可能已写入，先用原摘要查询，不删除原证据、清盘或另建操作。查询不代替显式续作，不主动打开待接纳目标，也不激活待完成的恢复。服务始终保持停止，须另行确认启动门禁和健康情况。

    

    

      
准备与安装 systemd / SMB 配置文件

      
生成与内置版本绑定的未激活配置包，存于已存在、root 所有且其他用户不可写的 /zxs/.zxs-helper-deployment-摘要/。不会写入 /etc、合并现有 Samba 共享、创建账户、设置密码，或执行服务 reload / start / enable。

      

        

          
          
          
        

        
        

          
          
        

        
UID 0 只适用于已经验证桥接在 Samba root 身份下连接的主机。这些账户名只做语法约束，尚未核实系统账户、UID、VFS ABI、依赖、路径权限或初次初始化。准备期间与当前 ZXS 可执行程序互斥，但不证明旧版或 Samba 已停。原样准备不是配置生效。

        
        
      

      

      
      

      
安装到固定系统路径，不启动服务

      
此操作另行核对本机服务账户、主组、独立 Samba 账户，以及已经安装的准确内置 ZXS 程序。只新建或核验 /etc/systemd/system/zxs.service 和可选 /etc/samba/zxs.conf，不覆盖不同文件，不改默认 smb.conf，也不创建父目录。

      
安装会让 unit 文件出现在 systemd 的搜索路径，但不运行 reload / start / enable、不接管 Samba 配置和 passdb。配置与意图记录不是完整系统初始化或可以启动的证明。当前 ZXS 租约能互斥；旧二进制、外部配置管理者和 Samba 仍须另行停止，不能并发编辑或加载配置。

断开页面后只需原摘要，不必重新猜填账户、监听或 SMB 参数。读取主机保留的原请求并核对当前准确身份；此入口不接收新配置、替换目标或启动服务。旧格式、缺失/损坏记录及完成后缺件均保留并拒绝。

      

        
        
      

      

      
      

        
        
      

      

    

    

      
重置已存在的 ZXS 管理员密码

      
仅重置固定 /zxs/data/management/management-auth.json 中已存在的管理员，必须已有真实管理权威和正确服务所有权。撤销全部 ZXS 登录会话，但不更改 Samba 密码、不创建新管理员或初始化系统，也不启动服务。

      

        
        
        
        
      

      

      
      

        

          
          
        

        
        
无登录且明文 HTTP，网络可达者也能重置密码。只在可信隔离网络操作。密码不放入 URL、命令行、日志或回执；提交后输入框立即清空。灾备凭据副本本片不更新，未来显式灾难恢复不能把旧副本当最新密码。若结果不确定，保留当前计划并重新输入同一个新密码来续作，不换请求或删除材料。

        
      

      

    

    

      
重置已存在的本地 Samba 密码

      
先在上方配置表中填写与已安装文件完全一致的 ZXS 服务账户、主组、监听地址和独立 Samba 账户。本入口仅支持当前独立 /etc/samba/zxs.conf、既有本地 tdbsam 及 /var/lib/samba/private/passdb.tdb；不创建 Samba/Unix 账户，不更改 ZXS 管理员或 Unix 密码，不启用服务。

      

        
        
      

      

      
      

        

          
          
        

        
会通过已核验的本机 smbpasswd 执行真实密码变更。无登录、明文 HTTP，只在可信隔离网络使用；密码只经请求正文和子进程 stdin，不放入 URL、argv、日志或回执。账户必须已存在，禁用状态不会被主动启用。不会撤销已有 SMB 会话，也不验证一次真实网络登录。

        
      

      

        
        
      

      

      
Samba 外部命令没有本工具的幂等令牌。响应丢失、断电或非零退出后密码可能已经改变，原请求不自动重放、不回滚整个 passdb。先查询并保留证据；确需再次重置时重新预览和手动确认新请求。完成回执只证明当时命令成功、目标账户读回和数据库同步，不保证现在的密码或服务状态。
