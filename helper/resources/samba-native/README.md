# 专用 Samba 账号库的维护侧原生复核

这里是独立 helper 的原生复核源，不提供独立客户端命令；仅供本机 v7 的受控首设与重置。固定上游为 [Debian Samba 2:4.22.11+dfsg-0+deb13u1](https://sources.debian.org/src/samba/2%3A4.22.11%2Bdfsg-0%2Bdeb13u1/) 随附 libtdb 1.4.13。今后只能由本次独立受信、受限的离线进程调用。不得在发行时换为系统中任意较新库、stock `pdbedit` 或可导出凭据的工具。

- 调用前须正面核定本实例的实际本地域、维护范围和主管拥有的两把原目录 EX；凭据原父和原文件仅投射给本次原生进程，观察阶段均实际只读。固定进程、签章外的本地准许、终端和原 SQL 交接见宿主维护说明。此组件不从标记找宿主路径。真 procfs 的受核描述符路径使 libtdb 从打开时的第一字节就只读已持有的原文件，前后还能重新核固定名、挂载、原件/属性。未知或需恢复时不转为可写打开。
- 用上游的 `tdb_check` 回调完整认物理在用记录，再独立用 `tdb_traverse_read` 验从原索引可达的同一结果。TDB 上限 64 MiB，单个 SAMU 行上限 1 MiB。严格只接 4/0 两个版本键、唯一 `USER_` 和与之双向相符的 `RID_000003e8`；任一额外/孤立项、错误/短遍历皆未知。不会从变化的专用库读到临时密码，亦不以“能列出用户”当唯一性。
- SAMU v4 的当前固定账号形状按上游公开源码验证准确数据跨度。只比较公开登录名、固定本地 SAM 名、普通用户名/组 RID、正常启用账户位、固定无到期的账户时间与原生明确 154 字节的描述；不可选字段不得带入外部脚本/路径，不能设 LM 或密码历史。不在复核代码读取、计算、导出或比较实际秘密字节；对 NT 字段只验证存在的固定长度。密码是否过期和原生登录政策仍由实际 Samba 另核。角色实际认证材料由原生 TDB C 库在受限进程内短暂读入，未来发行必须禁内核转储/持久换页及 libtdb trace。库在 O_RDONLY 会关闭自身字节锁，故不能省略离线两把原锁。
- 结果只区分精确前驱、目标、无法确认。不能发出审批、证明密码质量/能登录或把观察当作已同步。若中断后重见目标，从原库及其原父重新实际同步，且在独立重新打开后再验证真实结果，才有资格去完成同一笔 SQL。这里没有发密码、写 TDB、同步、改 schema 或启动服务的入口。

### 固定原生维护发行的写入与恢复

`HELPER_ACCOUNT_ISSUER` 分支仅编入独立签发、一次性维护角色的 Waf 目标；未实际组包、签发或执行。只有实际审批原单、持两把原 EX、已经提交并重读同一 SQL PENDING、且证实专属真实机器域/路径的调用者有资格。派生值靠原受限进程独立的已准许成熟提供者产生，不从命令行、文件、父进程或 SQL 接收。固定的 Samba 打包函数取同一正式 Samba 源，不接系统任意库。

- 首设只在这一获准进程内通过已持原父下 **实际** `O_CREAT|O_EXCL` 创建一个新库，共一原生事务直接写固定 4/0、唯一 USER 与 RID1000 四键。重置只能对原前驱的真实原 TDB：先是独立的只读核验，之后从持有的原 O_PATH 开既有库，绝无 CREATE、转换、临时备份或重取账号。原事务中确认同一准确前驱；只在已核正常原条目改 NT 固定字段、原代号和实际设密时间，其他原字段原样。固定组 RID 513，原时间字段含无到期及无强制改密的 0x7fffffff。受限 worker 只把同一原文件的 O_PATH 交回；不回传密码等价物。
- 这个候选的冷完成只接受可用的准确原目标；独立只读核验之后同步实际原 passdb 和原 accountdb 父，再关原始同步描述符、独立原生重开同一 inode，重查完整四键及目标。看到目标不需要再录口令。缺、只见前驱、未知、库热恢复、I/O/COMMIT 可疑或持锁/权限证据不足均不给完成；尤其不从受限读失败自动改开写恢复。仍须受控主管复核原子进程、原授权和完整 SQL 条件完成及最终 COMMIT/readback；此叶无发布权。
- 尚未编译或运行；夹具只有合成字段。正式交接前需独立核定发行签章、进程作用域、锁、凭据现场输入、故障保留及无副本保证。
