# helper 任务清单

本清单区分**已有源码**和**尚未实现的工作**；“已审”只指静态审查，不表示运行通过。命令和使用前提见[使用说明](README.md)，职责分界见[架构](ARCHITECTURE.md)。

当前格式由 [离线首设与密码重置](docs/headless-offline.md)维护。旧 SQLite 装机、账户和迁移流程不再交付。宿主诊断独立运行。

## 源码已审待验证


- H04 本机回环[磁盘面板](docs/disk-web.md)源码：终端一次配对，页面按需调用同一设备/挂载、被动速率与工具槽观察。仅当终端显式预选一份 FAT32、exFAT、ext4、XFS、NTFS 或 Btrfs 镜像后，页面可在预览确认后执行同一上游只读检查并查回同单结果。ext4/XFS/NTFS/Btrfs 只在确认后读取、验证摘要并持只读租约，不封存或延长会话；没有 Web 路径、参数、修复或写权。待实际验证配对、重复提交仅一次、退出收尾和完整结果；未启动或执行。
- H04 在线宿主观察：ZXS 运行时，`disks --rates`、`storage-status`、`hardware` 和回环面板的相应按钮不等待停机或离线 SYSTEM 锁。CPU/内存走同一组有界、只读 procfs 采样，不启用后台任务，不检查 ZXS 吞吐、注册或设备健康。定向源码夹具覆盖计数回退、缺值/真零、解析限额、面板拒绝跨源/未配对/有参数请求，以及用临时目录演示容量观察与原 SYSTEM 排他不相干。真实并行运行、主机可见数据和面板现场验收另验；停机核查与工作副本复修的准入未改变。
- H07/H08 发行端新增 [Debian 13 amd64 离线工具材料配方](packaging/debian13-amd64/README.md)：六种上游工具、隔离启动器、闭合运行库与对应源码；已接 FAT32、exFAT、ext4、XFS、NTFS 和单设备 Btrfs 各自的固定只读镜像动作，其余文件系统未接执行。实际归档、安装/安全更新/检查与 Web 状态验收都未运行。

在将来获准运行时，以下项目才可记录实际结果。正向文件用例只在受支持文件系统上的专用临时目录创建自己的数据；没有合格位置要记录先决条件不足，不能记通过。

| H04 ext4 镜像检查 | [`check-ext4-copy`](docs/ext4-copy-check.md)持真实本地普通副本的原只读 FD/原读租约，核全量摘要和起止范围，再隔离调用固定 e2fsck；无外部日志、重放或 128 MiB 硬门。 | 正常较大镜像、跳过恢复、全阶段与实际退出、名称/挂载被替换或请求写入等需在获准的独立环境验证；未运行。 |
| H04 XFS 镜像检查 | [`check-xfs-copy`](docs/xfs-copy-check.md)复用真实只读租约及全 SHA，对固定 xfs_repair 的本次无修改检查严格判读；不接受外部日志/实时设备，不重放或修复。 | 正常单卷与已知脏日志/早退夹具、原件未改、私有有界临时区、配对同票和实际退出均待验。 |
| H04 NTFS 有限观察 | [`check-ntfs-copy`](docs/ntfs-copy-check.md)用独立原副本、租约、全摘要和固定 `ntfsfix -n` 观察部分 MFT、镜像和备用启动扇区；不挂载、不重放日志、不代替 chkdsk。 | 独立合格副本、错末扇区/早退、只读路径、配对一次和实回执待验；不将有限结果当日志、休眠或完整性证明。 |
| H04 Btrfs 只读结构检查 | [`check-btrfs-copy`](docs/btrfs-copy-check.md)以原只读租约、全摘要和固定 `btrfs check --readonly` 检查完整单设备副本；不把一个成员当成整组，不给宿主设备或修复选项。 | 单设备阳性、少成员/seed/转储/准入或日志与部分输出、不完整收尾均需在独立环境验证，未运行。 |
| H01 操作者和资源 | 无默认服务；显式命令、有限输入和输出。目录最多 16 个、120 对关系、32 KiB 报告，最多占用 18 个目录描述符。 | 无参数或非法参数无观察结果；实核边界值和超限拒绝、无目录扫描及无持久任务。 |
| H02 目录和挂载 | `inspect-dirs` 观察路径实体与可见祖先；保留叶描述符，报告前重新解析原路径。 | 同一目录、兄弟、父子、链接、变换路径分别核对；即使叶仍是同一 inode，原父目录被替换也不得给出原观察。设备号不是物理盘证明。 |
| H03 陌生输入 | 比较前，两端都须通过原始描述符的设备/文件系统、实体、类型、链接数与容量检查；未知文件系统不读取。 | 纯分类用例与生产调用顺序已在源码中；它们不是在网络、虚拟或恶意挂载上实测过。合规文件的阳性对照与被拒输入均须单独记录。 |
| H04 观察状态 | 目录关系是数据；比较的相同、不同、无法完成分别返回 0、1、2。 | 断言实际退出码及输出；首块已不同但后续读取失败或终点意外增长时，不能报“不同”。 |
| H04 选定存储根的挂载与容量 | `storage-status` 受理 1–256 分量的原始选择路径（两个通用命令仍为 128）；对显式 SYSTEM/回收/数据候选分别报告内核挂载 ID、可获挂载根标记、只读标志及以字节计的总/空闲/可用量；末端重核路径与挂载。尚未运行。 | 核对真实观察和部分拒绝的输出，区分 ID 缺失/路径替换/无权限与 0 可用空间。角色是用户所选，不证明已登记、健康或可写。 |
| H04 普通块设备与分区 | `disks [--device MAJOR:MINOR] [--rates]` 源码按持有的 sysfs 原件列内核设备号、容量与分区父盘；列本挂载命名空间的直接匹配 ID。可取得的型号和 udev 别名带来源，不读原始设备。速率需同盘世代、同分区原件/几何及两个实际计数；整盘、分区/叠加设备不相加。 | 待在有界专用环境核物理/虚拟盘、热插拔、分区重建、计数复位、bind、多重/缺失的别名和权限不足。未运行，不是健康、占用或可修复证明。 |
| H04 七种格式的检查工具 | `fs-tools [格式 [--sha256 摘要]]` 展示固定安装位置、元数据、[只读方案和范围](docs/filesystem-tools.md)，可比对单个受保护普通程序的完整字节。没有工具启动、设备检查或修复。 | 待实测安装槽缺失/异物/变动、实配工具与可信摘要；以后另核实际版本、目标充分隔离和工具退出语义，再接只读检查。写修复需单独批准。 |
| H05 离线字节检查 | `compare-files` 从两个固定的普通文件完整分块读取，检查各自实际终点，末尾重核原位置与属性。 | 验证独立短读、受中断的终点读取，以及同一 inode 上的等长改写/新增硬链接；区分真正内容不同与不能完成。 |
| H06 身份与权限 | 只用当前 OS 身份，读取需可信的本进程描述符表和 `O_NOATIME` 权限，不提供隐式提权或换路径回退。 | 在受控环境验证权限不足或无法建立可信描述符时不读取、不返回成功；不为验收修改实际用户文件、凭据、挂载或服务。 |

## 当前格式：已写完待测试

- 首设：验证对专用空目录写入角色标记并发布账户；指向异物或中止时保留原件。
- 密码重置：运行时拒绝重置；停机重置后，原用户名可用新口令登录，原卷和文件不变。另验受损记录、换盘及发布后断开。
- 非空源目录预检：只读清点，不导入。待验证权限、边界和原件变化。
