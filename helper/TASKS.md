# helper 任务清单

本清单区分**已有源码**和**尚未实现的工作**；“已审”只指静态审查，不表示运行通过。命令和使用前提见[使用说明](README.md)，职责分界见[架构](ARCHITECTURE.md)。

**新池基线：唯一 SYSTEM SQLite 数据库，外卷二进制容器与普通正文，独立生命周期锁。** 不依赖文件系统专属特性。本机 `install-pool` 和 `setup-pair` 已接首建/同单续作与固定双账户。没有实际安装、设密或登录验收。下列宿主工具与此分开。

## 源码已审待验证

- H07 [配对后的首次安装向导](docs/disk-web.md#首次安装向导本机命令与原回执)：只比对包内模板，并连接已有真实终端动作、原域摘要、原 SMB 前台启动和原生管理 HTTP。不收秘密或路径，不调用安装、设密或启停；未做现场验证。
- H07 [ZXS 原生管理 HTTP](docs/management-http.md)：按原池及其宿主存储身份启动，无需域名、证书、nginx 或 Unix socket。可安装固定不启用的 systemd 主片段，同一原池经实际有效配置核对后提供前台启停/状态；来自所有 IPv4 接口的 8443 是否可达、浏览器、退出和站点如选外部 TLS 均待实际验收。

- H04 本机回环[磁盘面板](docs/disk-web.md)源码：终端一次配对，页面按需调用同一设备/挂载、被动速率与工具槽观察。仅当终端显式预选一份 FAT32、exFAT、ext4、XFS、NTFS 或 Btrfs 镜像后，页面可在预览确认后执行同一上游只读检查并查回同单结果。ext4/XFS/NTFS/Btrfs 只在确认后读取、验证摘要并持只读租约，不封存或延长会话；没有 Web 路径、参数、修复或写权。待实际验证配对、重复提交仅一次、退出收尾和完整结果；未启动或执行。
- H07/H08 发行端新增 [Debian 13 amd64 私有工具包配置](packaging/debian13-amd64/README.md)：六种上游工具、隔离启动器、闭合运行库与对应源码；已接 FAT32、exFAT、ext4、XFS、NTFS 和单设备 Btrfs 各自的固定只读镜像动作，其余文件系统未接执行。实际归档、安装/安全更新/检查与 Web 状态验收都未运行。

旧 MAINT‑1 和 REGISTRATION/CONFIRMED 的编码、卷标、逐卷同步、改名、冷确认以及四个中断窗口仍可在[切换前的完整清单](https://github.com/isarmg/zxs/blob/bdfc434f3c56f2f948e52550915107bbccc08486/helper/TASKS.md)查看。此前都是源代码静审，不是断电实测。它们不会打开 SQLite 池、为新卷发权、替代 SQLite journal，也不是迁移器；不要再补旧写入口。

## 待写：本机 Web 安装和离线维护

这些是交付任务，不是已运行的功能。现行 v16 仍只能在首建登记全组，其卷声明不可改或删。加盘、换回收盘、带数据导入或永久退登记需要独立的 ZXS+helper 业务契约和实现，不在本轮只查里变通。CLI 和回环 Web 复用小组应用动作，不执行 ZXS 命令、不依赖其进程或相邻源码。授权的离线写与在线业务写不并存。

| 项 | 交付顺序与验收 |
| --- | --- |
| H01 操作者/作业 | 明确启动、身份和原操作 ID、作用范围、计划确认、只查与明确续作分开。失联、同名换盘/账户、响应未知不换新票。helper 面板非 root、仅本机回环，验证会话、Host/Origin/CSRF，限额并排空；不改变 ZXS 业务管理独立监听。 |
| H02 数据盘和回收站盘设置 | 从明确选择的 Linux 挂载核实 SYSTEM、普通卷和唯一专用回收卷；不按品牌准入，不做专属探针。验证别名/重叠、来源不清、回收根与 SYSTEM/任一普通根来自同一文件系统或无法确认隔离、认领冲突、同名换物或未知旧材料时均不写。用已获准的独立试验验证互斥、新建不覆盖、文件/父目录同步及冷读，不把一次预检当作持久证明。 |

| H04 状态 | 两端都呈现系统和磁盘状态。helper 只据已核单元、当次 OS 挂载与路径实体、在安全持锁时读到的登记角色/代次、原操作清理与离线事实；分别标时刻或原 SQL 操作/代次。在线实时业务不可取得就写未核，盘不可达不等于已离线。不能把登记、服务 active、盘可见或系统停止混成一个绿灯。 |
| H04 运维仪表盘 | 分批：① 已有所选根的挂载/只读/容量源码，仍需证实实际 UUID 与注册 ID；② 已有显式块清单、受限型号和被动速率源码；补接口/温度/错误、只读 SMART/NVMe 及独立验收；③ 后续将带证据类型接入本机 Web；④ 可信安装、实际生效单元/覆盖、服务活动与有界近期脱敏报错。每项注明来源与时间，未知/不支持/无权限分开。不读写测速、不泄露序列号，不以整机统计冒充业务健康。 |
| H04 删除盘 | 永久退登记不擦盘，不等于正常主动下线、故障离线或文件软删除。拒绝仍有任何权威原件、待清责任、未知内容/状态或需保留的 SYSTEM/回收盘；服务/磁盘不在线不等于盘空。运行时两种下线仍在 ZXS。 |
| H04 文件系统检测与受限修复 | 独立的可选宿主工具，不改变 ZXS 通用格式。目标覆盖 ext4、NTFS、ZFS、XFS、Btrfs、exFAT、FAT32。先区分有限诊断/未查/需离线，不将 ZFS scrub 当只读、NTFS 有限核查当完整修复，或为 XFS 脏日志启用破坏选项。另做固定工具/版本/参数与原对象归属的预检、原单预览和显式授权；先在身份可核、未挂载、与原件隔离的独立工作副本上修复。不能排除外部日志/其他成员、swap、其他命名空间或重新挂载时，不授权对原盘写。除六类只读副本命令外，已有主流 e2fsck 的独立 ext 工作副本复修源码：本机确认、新文件、`-fp` 后真 `-fn`、不改输入、无覆盖发布。另有本机前台的 [exFAT 工作副本复修](docs/exfat-copy-check.md#只修新建的工作副本)：固定 `-p` 后真 `-n`、无覆盖发布，不强制修复且不承诺保留工作副本中的所有受损目录项。另有本机 [FAT32 工作副本复修](docs/fat32-copy-check.md#只修新建的工作副本)，明确自动模式可能截短、删除或保存孤链，只有独立只读复查后才发布。没有对原盘、ZFS 或其他格式的修复。ext、exFAT 和 FAT32 可从独立配对回环页请求原终端确认；页面不选格式、路径或参数，无实际工具调用与写权。正负镜像、网页隔离/一次请求/终端收割、资源和断电验收未做。 |
| H05 停机核查与按原单查询 | CLI 对指定原池、卷、FILE 容器，分别报告登记、在位、元数据和已实际核验的正文范围；用池/种类/请求和原操作 ID 查历史、未完成或未知。查询停在现有证据，不同步推进或重放；无对应公开业务/账户格式时明确不支持。 |
| H05 受限原单恢复 | 另行授权并持原 SYSTEM 目录及所需原卷排他锁，只续协议允许、来源和阶段可验证的原维护动作。覆盖缺原件/同名替代/无权限不改、查询不续作、重复确认不重做；无默认修复或批量清理。日常建档、保存、发布、移动、回收操作不复制到维护 CLI。 |
