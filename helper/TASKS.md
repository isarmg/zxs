# helper 任务清单

本清单区分**已有源码**和**尚未实现的工作**；“已审”只指静态审查，不表示运行通过。命令和使用前提见[使用说明](README.md)，职责分界见[架构](ARCHITECTURE.md)。

**新池基线：唯一 SYSTEM SQLite 数据库，外卷二进制容器与普通正文，独立生命周期锁。** 不依赖文件系统专属特性。没有 SQLite 写入/检查实现，下面是目前的宿主工具源码及分工。

## 源码已审待验证

在将来获准运行时，以下项目才可记录实际结果。正向文件用例只在受支持文件系统上的专用临时目录创建自己的数据；没有合格位置要记录先决条件不足，不能记通过。

| 项 | 已有源码 | 今后需要的证据 |
| --- | --- | --- |
| H01 操作者和资源 | 无默认服务；显式命令、有限输入和输出。目录最多 16 个、120 对关系、32 KiB 报告，最多占用 18 个目录描述符。 | 无参数或非法参数无观察结果；实核边界值和超限拒绝、无目录扫描及无持久任务。 |
| H02 目录和挂载 | `inspect-dirs` 观察路径实体与可见祖先；保留叶描述符，报告前重新解析原路径。 | 同一目录、兄弟、父子、链接、变换路径分别核对；即使叶仍是同一 inode，原父目录被替换也不得给出原观察。设备号不是物理盘证明。 |
| H03 陌生输入 | 比较前，两端都须通过原始描述符的设备/文件系统、实体、类型、链接数与容量检查；未知文件系统不读取。 | 纯分类用例与生产调用顺序已在源码中；它们不是在网络、虚拟或恶意挂载上实测过。合规文件的阳性对照与被拒输入均须单独记录。 |
| H04 观察状态 | 目录关系是数据；比较的相同、不同、无法完成分别返回 0、1、2。 | 断言实际退出码及输出；首块已不同但后续读取失败或终点意外增长时，不能报“不同”。 |
| H04 选定存储根的挂载与容量 | `storage-status` 受理 1–256 分量的原始选择路径（两个通用命令仍为 128）；对显式 SYSTEM/回收/数据候选分别报告内核挂载 ID、可获挂载根标记、只读标志及以字节计的总/空闲/可用量；末端重核路径与挂载。尚未运行。 | 核对真实观察和部分拒绝的输出，区分 ID 缺失/路径替换/无权限与 0 可用空间。角色是用户所选，不证明已登记、健康或可写。 |
| H04 普通块设备与分区 | `disks [--device MAJOR:MINOR] [--rates]` 源码按持有的 sysfs 原件列内核设备号、容量与分区父盘；列本挂载命名空间的直接匹配 ID。可取得的型号和 udev 别名带来源，不读原始设备。速率需同盘世代、同分区原件/几何及两个实际计数；整盘、分区/叠加设备不相加。 | 待在有界专用环境核物理/虚拟盘、热插拔、分区重建、计数复位、bind、多重/缺失的别名和权限不足。未运行，不是健康、占用或可修复证明。 |
| H04 七种格式的检查工具 | `fs-tools [格式 [--sha256 摘要]]` 展示固定安装位置、元数据、[只读方案和范围](docs/filesystem-tools.md)，可比对单个受保护普通程序的完整字节。没有工具启动、设备检查或修复。 | 待实测安装槽缺失/异物/变动、实配工具与可信摘要；以后另核实际版本、目标充分隔离和工具退出语义，再接只读检查。写修复需单独批准。 |
| H05 离线字节检查 | `compare-files` 从两个固定的普通文件完整分块读取，检查各自实际终点，末尾重核原位置与属性。 | 验证独立短读、受中断的终点读取，以及同一 inode 上的等长改写/新增硬链接；区分真正内容不同与不能完成。 |
| H06 身份与权限 | 只用当前 OS 身份，读取需可信的本进程描述符表和 `O_NOATIME` 权限，不提供隐式提权或换路径回退。 | 在受控环境验证权限不足或无法建立可信描述符时不读取、不返回成功；不为验收修改实际用户文件、凭据、挂载或服务。 |
| H07 独立工程 | 自有 Cargo 工程、锁和工具链；[交付核对表](RELEASE.md)列出独立构建与测试的输入及记录项。 | 尚无实际构建、用例结果、复建一致性或安装证据。 |
| H08 发行材料 | [依赖核对表](DEPENDENCIES.md)记录了全部 21 份锁定源码包的 SHA-256 比对、上游许可声明及包内材料位置。 | 尚未核实将交付的二进制、实际组件和随包许可材料；没有本次发行签名或独立验签证据。 |

### 曾审过、不再作为交付门的原型

旧 MAINT‑1 和 REGISTRATION/CONFIRMED 的编码、卷标、逐卷同步、改名、冷确认以及四个中断窗口仍可在[切换前的完整清单](https://github.com/isarmg/zxs/blob/bdfc434f3c56f2f948e52550915107bbccc08486/helper/TASKS.md)查看。此前都是源代码静审，不是断电实测。它们不会打开 SQLite 池、为新卷发权、替代 SQLite journal，也不是迁移器；不要再补旧写入口。

## 待写：本机 Web 安装和离线维护

这些是交付任务，不是已运行的功能。CLI 和回环 Web 复用小组应用动作，不执行 ZXS 命令、不依赖其进程或相邻源码。授权的离线写与在线业务写不并存。

| 项 | 交付顺序与验收 |
| --- | --- |
| H01 操作者/作业 | 明确启动、身份和原操作 ID、作用范围、计划确认、只查与明确续作分开。失联、同名换盘/账户、响应未知不换新票。Web 非 root，仅本机回环，验证会话、Host/Origin/CSRF，限额并排空。 |
| H02 数据盘和回收站盘设置 | 从明确选择的 Linux 挂载核实 SYSTEM、普通卷和唯一专用回收卷；不按品牌准入，不做专属探针。验证别名/重叠、来源不清、回收根与 SYSTEM/任一普通根来自同一文件系统或无法确认隔离、认领冲突、同名换物或未知旧材料时均不写。用已获准的独立试验验证互斥、新建不覆盖、文件/父目录同步及冷读，不把一次预检当作持久证明。 |
| H03 非空普通盘导入 | 只读清点与确认计划先行，保留空目录和原件；只向独立合格目标写普通文件，不就地转换。核命名冲突、数据与元数据/配额、暂存、数据库与回滚日志空间及恢复余量。目标同步后独立重开、核对实际内容；成功也不自动删源。 |
| H04 状态 | 两端都呈现系统和磁盘状态。helper 只据已核单元、当次 OS 挂载与路径实体、在安全持锁时读到的登记角色/代次、原操作清理与离线事实；分别标时刻或原 SQL 操作/代次。在线实时业务不可取得就写未核，盘不可达不等于已离线。不能把登记、服务 active、盘可见或系统停止混成一个绿灯。 |
| H04 运维仪表盘 | 分批：① 已有所选根的挂载/只读/容量源码，仍需证实实际 UUID 与注册 ID；② 已有显式块清单、受限型号和被动速率源码；补接口/温度/错误、只读 SMART/NVMe 及独立验收；③ 后续将带证据类型接入本机 Web；④ 可信安装、实际生效单元/覆盖、服务活动与有界近期脱敏报错。每项注明来源与时间，未知/不支持/无权限分开。不读写测速、不泄露序列号，不以整机统计冒充业务健康。 |
| H04 删除盘 | 永久退登记不擦盘，不等于正常主动下线、故障离线或文件软删除。拒绝仍有任何权威原件、待清责任、未知内容/状态或需保留的 SYSTEM/回收盘；服务/磁盘不在线不等于盘空。运行时两种下线仍在 ZXS。 |
| H04 文件系统检测与受限修复 | 独立的可选宿主工具，不改变 ZXS 通用格式。目标覆盖 ext4、NTFS、ZFS、XFS、Btrfs、exFAT、FAT32。先区分有限诊断/未查/需离线，不将 ZFS scrub 当只读、NTFS 有限核查当完整修复，或为 XFS 脏日志启用破坏选项。另做固定工具/版本/参数与原对象归属的预检、原单预览和显式授权；先在身份可核、未挂载、与原件隔离的独立工作副本上修复。不能排除外部日志/其他成员、swap、其他命名空间或重新挂载时，不授权对原盘写。本片没有安装、调用、修盘、自检或 Web 写入口。 |
| H05 停机核查与按原单查询 | CLI 对指定原池、卷、FILE 容器，分别报告登记、在位、元数据和已实际核验的正文范围；用池/种类/请求和原操作 ID 查历史、未完成或未知。查询停在现有证据，不同步推进或重放；无对应公开业务/账户格式时明确不支持。 |
| H05 受限原单恢复 | 另行授权并持原 SYSTEM 目录及所需原卷排他锁，只续协议允许、来源和阶段可验证的原维护动作。覆盖缺原件/同名替代/无权限不改、查询不续作、重复确认不重做；无默认修复或批量清理。日常建档、保存、发布、移动、回收操作不复制到维护 CLI。 |
| H05 SQLite 准入、首建及离线互斥 | 两端独立实现同一 DDL/向量，核本机标准 VFS、库身份/约束、DELETE/EXTRA、外键/受限 schema。在线与离线参与者独立打开同一原 SYSTEM 目录 inode，在不同 OFD 上分别取 SH/EX，不跨参与者复制或传递 OFD；同一次首建或多根动作复用自己已锁的原 S OFD。所有 SQLite 连接关闭后才释放，不设锁文件、不在 DB inode 上加 flock。目录锁不支持、原根被替换、他池/旧登记或陌生 journal 不接手；只读热日志不能以写入降级。全新库须 OS 独占预留，写完未决 SQL 原单后才轮到各外卷，全部文件/父同步核实后才用 SQL 确认。以真实双实现、争卷、磁盘满、失联重试、热日志及恢复前后原件作验收；未实现。 |
| H06 首管/密码重置 | 原状态明确从未创建管理员才首设；明确的恢复身份才重置，撤销相应会话，绝不依据 eUID/文件缺失。采用成熟凭据算法和受控输入，不落明文、不通过命令行/环境/日志或回执传密码。两边同一认证数据，不维持影子账户库。 |
| H07 安装向导/服务管理 | 环境 → 数据盘/回收站盘 → 首管 → 确认服务配置 → 状态/排错。核可信制品/目标/固定 systemd 单元及覆盖，区别配置、启停和开机启用；限权适配器独立认证，拒接管同名陌生单元、执行任意 shell 或系统控制命令。未获得真正离线锁不操作存储。 |
| H08 独立交付 | 以[交付核对表](RELEASE.md)分别证明实际构建、许可、签名、安装、升级和中断；既有依赖来源核对不是发布验签。 |

通用文件导出没有新需求，不顺带新增。没有受管备份、旧格式兼容或自动迁移。需要检查的共同数据向量不是第三个项目、共享运行环境或共同代码库。
