# helper 任务清单

本清单区分**已有源码**和**尚未实现的工作**；“已审”只指静态审查，不表示运行通过。命令和使用前提见[使用说明](README.md)，职责分界见[架构](ARCHITECTURE.md)。

镜像工具和网页的本次移除仅完成源码和静态复核，未运行构建、测试或现场验收。

当前格式由 [离线首设与密码重置](docs/guides/headless-offline.md)维护。旧 SQLite 装机、账户和迁移流程不再交付。宿主诊断独立运行。

## [仅静态] 当前源码及验收缺口

- H04 在线宿主观察：ZXS 运行时，`disks --rates`、`storage-status`和 `hardware`不等待停机或离线 SYSTEM 锁。CPU/内存走同一组有界、只读 procfs 采样，不启用后台任务，不检查 ZXS 吞吐、注册或设备健康。定向源码夹具覆盖计数回退、缺值/真零、解析限额，以及用临时目录演示容量观察与原 SYSTEM 排他不相干。真实并行运行、主机可见数据和停机核查另验。

在将来获准运行时，以下项目才可记录实际结果。正向文件用例只在受支持文件系统上的专用临时目录创建自己的数据；没有合格位置要记录先决条件不足，不能记通过。

## [仅静态] 当前格式的离线操作

- 首设：验证一个系统根、一块专用回收盘及一块或多块数据盘的角色标记；指向异物或中止时保留原件。
- 密码重置：运行时拒绝重置；停机重置后，原用户名可用新口令登录，原卷和文件不变。另验受损记录、换盘及发布后断开。
- 离线加入或移除空数据盘：待实盘验证登记、退盘、原回收回执及中断后续作。
- 非空源目录预检：只读清点，不导入。待验证权限、边界和原件变化。
- 已登记空 DATA 原位初始化：在已初始化的池中只建目标 DATA 的私有布局；不启动服务、不清理或首次初始化其他卷。已有空前缀、未知/已有数据、未确认系统路由和中断续作需在隔离环境验证；未运行。
- 单文件及明确映射的批量离线导入：准备并保存原票据；批计划在写入前完整校验，逐项复用相同单文件工作进程和精确回执。待在隔离实盘验原文件不变、部分中断重放、碰撞、介质满与变更。
- 整个非空源目录的文件导入：固定原目录两次清点并对照每个文件的原证据；允许审阅同一批计划，原始字节映射不受命令行长度限制。待在独立环境验证实际挂载根与子目录、嵌套/冲突映射、目录或文件中途变化、空目录与外部符号链接、恢复并对比完整内容；未运行。
- 命令行[服务单元预览](docs/guides/headless-offline.md#可选服务单元预览)：按实际准入的角色目录路径表达挂载顺序。待验证前台启动器及实际挂载顺序。Helper 不需要 systemd，也不开机启动。

## [设计中] 下一批离线能力

- 后续独立验收整容器跨 DATA 盘离线移动、回执与正文核验、单工作进程的可续作导入和显式 ZIP 打包。本次不增加这些入口。
- 不提供非空盘就地擦除、用空目录冒充层级导入或自动接管旧池。ACL 和硬链接拓扑不在文件容器格式中重建。

## 退役格式清理

退役的 SQLite 装机及共享账户源码、测试入口和专用组包依赖已从当前源码树移除。[六类镜像工具及本机网页](docs/archive/retired-volume-tools.md)也不再交付。仍适用的原件校验夹具、许可与来源记录继续保留。此变更不提供旧盘迁移，也不构成当前格式的运行验收。

可选发布器的主机和路径边界独立于旧安装流程。受批准原 ZXS ELF、非覆盖发布和独立冷启动仍需专机验收，尚无当前发行制品。
