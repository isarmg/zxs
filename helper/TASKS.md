# helper 任务清单

本清单区分**已有源码**和**尚未实现的工作**；“已审”只指静态审查，不表示运行通过。命令和使用前提见[使用说明](README.md)，职责分界见[架构](ARCHITECTURE.md)。

**新池基线：普通文件、目录、锁和同步，不使用任何文件系统专属功能，reflink 也不是可选路径。** 下面列出现有通用检查；旧 MAINT‑1 内部首登原型另列作历史，不充作通用介质的实现或验证。

## 源码已审待验证

在将来获准运行时，以下项目才可记录实际结果。正向文件用例只在受支持文件系统上的专用临时目录创建自己的数据；没有合格位置要记录先决条件不足，不能记通过。

| 项 | 已有源码 | 今后需要的证据 |
| --- | --- | --- |
| H01 操作者和资源 | 无默认服务；显式命令、有限输入和输出。目录最多 16 个、120 对关系、32 KiB 报告，最多占用 18 个目录描述符。 | 无参数或非法参数无观察结果；实核边界值和超限拒绝、无目录扫描及无持久任务。 |
| H02 目录和挂载 | `inspect-dirs` 观察路径实体与可见祖先；保留叶描述符，报告前重新解析原路径。 | 同一目录、兄弟、父子、链接、变换路径分别核对；即使叶仍是同一 inode，原父目录被替换也不得给出原观察。设备号不是物理盘证明。 |
| H03 陌生输入 | 比较前，两端都须通过原始描述符的设备/文件系统、实体、类型、链接数与容量检查；未知文件系统不读取。 | 纯分类用例与生产调用顺序已在源码中；它们不是在网络、虚拟或恶意挂载上实测过。合规文件的阳性对照与被拒输入均须单独记录。 |
| H04 观察状态 | 目录关系是数据；比较的相同、不同、无法完成分别返回 0、1、2。 | 断言实际退出码及输出；首块已不同但后续读取失败或终点意外增长时，不能报“不同”。 |
| H04 选定存储根的挂载与容量 | `storage-status` 受理 1–256 分量的原始选择路径（两个通用命令仍为 128）；对显式 SYSTEM/回收/数据候选分别报告内核挂载 ID、可获挂载根标记、只读标志及以字节计的总/空闲/可用量；末端重核路径与挂载。尚未运行。 | 核对真实观察和部分拒绝的输出，区分 ID 缺失/路径替换/无权限与 0 可用空间。角色是用户所选，不证明已登记、健康或可写。 |
| H04 普通块设备与分区 | `disks [--device MAJOR:MINOR] [--rates]` 源码按持有的 sysfs 原件列内核设备号、容量与分区父盘；列本挂载命名空间的直接匹配 ID。可取得的型号和 udev 别名带来源，不读原始设备。速率需同盘世代、同分区原件/几何及两个实际计数；整盘、分区/叠加设备不相加。 | 待在有界专用环境核物理/虚拟盘、热插拔、分区重建、计数复位、bind、多重/缺失的别名和权限不足。未运行，不是健康、占用或可修复证明。 |
| H04 七种格式的检查工具 | `fs-tools [格式 [--sha256 摘要]]` 展示固定安装位置、元数据、[只读方案和范围](docs/filesystem-tools.md)，可比对单个受保护普通程序的完整字节。没有工具启动、设备检查或修复。 | 待实测安装槽缺失/异物/变动、实配工具与可信摘要；以后另核实际版本、目标充分隔离和工具退出语义，再接只读检查。写修复需单独批准。 |
| H05 通用卷的普通认领文件 | 已有[定长卷标契约](docs/portable-volume-claim-v1.md)、S/R/F 及后来加入的 F 向量，以及独立纯字节编解码。只区分结构正确/与期望行相符，不打开文件、签票或提供维护命令。 | 两端须对同一 103 B 向量逐字节相同；截短、未知域、错行、错原单或摘要不符均不认。认领决定及前沿的真实持久读回、原登记/选卷/锁/冷重启和授权仍未验。 |
| H05 普通首登记与零前沿 | [规范及四根向量](docs/portable-genesis-v1.md)区分原认领主体、四份反馈、同一登记 inode 的初始/发布名和普通确认文件；helper 的只读字节检查只核完整首登记、零下界和连续匹配的卷标前缀，不检查实际名字、租约或权限。 | 两端仍须实测同向量；原登记与前沿从同一受保护 SYSTEM 实读、跨进程互斥、冷续原单和断电检验。未知尾、缺失/滞后下界及相同字节的副本都不准按空池写。 |
| H05 按原单查看待完成首登记 | 从独立提供的受保护 SYSTEM 与原请求，持同一 `INITIALIZING` 普通文件排他锁，在目录短锁内实读原记录、`CONFIRMED` 和 S 卷标。区分未见下界、零下界未标、零下界已有 S 标；不从记录打开其他卷，不同步或续写。无命令入口。 | 自有目录中的独立锁竞争、等字节换物、有标无下界、未识别名字或尾帧，以及实际两端并发与重启仍待运行；这些观察不证明其他卷可用、专用回收盘隔离或操作者授权。 |
| H05 整组续作到零下界 | 内部续作只接受与原请求相符的完整、独立宿主选择：保留原 `INITIALIZING` 文件 EX，再非阻塞取齐所有实际根 EX。先核第 0 行确为原 S；整组原件、祖先、连续卷标及每卷可放下 43 字节固定名均核准后，重新同步原登记及父；只独占建立或重同步正确的零 `CONFIRMED`，从原父重开核同物、105 字节与 EOF。回收盘隔离要比较已选原 FD 对应的内核超级块，不是看挂载名或 inode 设备号；代码拒绝子树 bind、不可核祖先和外来记录。是否确为批准的原介质、没有虚拟重导或镜像，仍须可信宿主另证，不能据此识别重启后的物理原盘。没有生产授权签发方、CLI、自动补标或 READY。 | 受限非 root worker、两种真实存储来源的四根及同根/同源冲突、受锁的后序卷、仅后序卷有标、存在半写文件等用例须在专用环境实跑。不同逻辑文件系统不保证物理盘独立；部分写、同步不明、断电与双端互认均未验，不得报首登完成。 |
| H05 逐卷同步普通认领标记 | 已在原单上实际同步零下界的内部动作才可从第 0 行开始；每次只处理原表下一卷。已有的准确 103 字节标记只重同步，缺标只独占新建；同步前记录文件和原父的实物与属性，同步后从原父另开核同一原件、全部内容及 EOF，末端两者未变才计入进度。所有原根与登记的排他锁全程保留；即使全部标记已见也不跳步、不改为 READY。 | 源码覆盖首卷完成后冷开、从第 0 行重验且不换原件、后来卷错标及同字节替件阻止下一行。未运行，不含授权签发、READY 发表、断电或跨实现验收。 |
| H05 冷开查看通用空池的发布名 | 内部只读动作只认原 SYSTEM 上唯一的 `REGISTRATION`、首登记正文的真实 EOF、精确零下界与 S 卷标；持原登记 EX，不跟其他卷路径，不同步、不代替原单确认。 | 已有查询与待办名互不混认、双名/缺标及小尾/超出空池窗口的源码用例。真盘、断电和已有业务后的整池状态均未验。 |
| H05 整组发布及已发布空池的原单重确认 | 内部发布只消费本次每行真正同步的整组；原登记 EX 及所有根 EX 不放，确认原 `INITIALIZING` 与目标空缺后才作同父原子不覆盖改名，原文件及父同步、从原父重读 `REGISTRATION` 和整组证据才确认。改名一旦尝试而后续未知，保留现场，不回滚。纯冷查不等于确认；单独获准的空池重确认先证全组，再同步已有原件、最后同步原 SYSTEM 父并复核，缺标不补。 | 未执行的用例涵盖未完成前缀、占名不覆盖、同一 EX 跨改名、可见 READY 但此前同步结果不明、缺外卷标不补。缺真正的宿主授权、从空根发行第一份 `INITIALIZING`、双实现运行/断电验收，仍无安装或写命令。 |
| H05 离线字节检查 | `compare-files` 从两个固定的普通文件完整分块读取，检查各自实际终点，末尾重核原位置与属性。 | 验证独立短读、受中断的终点读取，以及同一 inode 上的等长改写/新增硬链接；区分真正内容不同与不能完成。 |
| H06 身份与权限 | 只用当前 OS 身份，读取需可信的本进程描述符表和 `O_NOATIME` 权限，不提供隐式提权或换路径回退。 | 在受控环境验证权限不足或无法建立可信描述符时不读取、不返回成功；不为验收修改实际用户文件、凭据、挂载或服务。 |
| H07 独立工程 | 自有 Cargo 工程、锁和工具链；[交付核对表](RELEASE.md)列出独立构建与测试的输入及记录项。 | 尚无实际构建、用例结果、复建一致性或安装证据。 |
| H08 发行材料 | [依赖核对表](DEPENDENCIES.md)记录了全部 21 份锁定源码包的 SHA-256 比对、上游许可声明及包内材料位置。 | 尚未核实将交付的二进制、实际组件和随包许可材料；没有本次发行签名或独立验签证据。 |

### 首次登记的四个断电窗口（待实际验收）

| 中断点 | 重启后只能依据哪些原件、允许做什么 |
| --- | --- |
| 正在写某一卷标，只写了部分字节 | 若部分文件仍在，报告原单未完成，原样保留，不补尾、不覆盖；若确实未留下该名，只能在完整原单、零下界、连续准确的较早卷标及整组原锁均核定后从 S 重走。均不能报 READY。 |
| 卷标文件已同步，其父目录尚未确认同步 | 文件可能仍在，也可能没有留下名字。正确且连续的已有标须重同步**同一文件和原父**并从该名实读；确切缺标才可不覆盖新建。若有洞、错标或来源不明，只核查，不前推。 |
| `INITIALIZING → REGISTRATION` 已改名，原 SYSTEM 父未确认同步 | 不能预言断电后会出现哪个名。若仅原待办名和完整反馈可证，重新获准后只续同单；若仅原发布名可证，纯查看只报观察，另获准才核全组并重同步已有原件、最后同步原 S。双名、两名皆无、换物或混杂均不重建、不搬回。 |
| 最终文件/目录同步和全组回读已完成，但确认回执丢失 | 若同一个完整空池原单与各原件仍可核，显式重确认，不再次改名、发 ID 或补标；无法证明操作者曾收到回执。若已出现不认识的业务后继，不退回空池处理。 |

现有源码夹具构造了部分反馈和“已见发布名、父同步结果未知”等现场，不是断电实测。真正验收须在获准的专用介质/环境中于这些位置分别中断并冷开，对照原始字节、名字和拒绝结果；不能以单次进程重启或缓存中的可见性代替。

### 不再作为通用新池准入的旧实验

MAINT‑1 的字节、匿名登记、卷根锁、首次具名、卷标和冷确认曾经做过静态审查，未运行，也没有对外写命令。[原审查清单及每项未验边界](https://github.com/isarmg/zxs/blob/4affcdbe77130979b470ebeecf0fe37e69c10576/helper/TASKS.md)保留完整记录。可沿用的是**原锁不能换物、未知材料不覆盖、独立核对原单**这些要求，不是旧的字节或介质前提。

| 现有依赖 | 通用格式如何处理 |
| --- | --- |
| 卷标/确认前沿使用 xattr | 改为具有本池和原单身份的普通记录，分别定义写入、校验和父目录同步；不能因为缺少新文件就认领已有根。 |
| `O_TMPFILE`、从匿名 FD 链接第一名称 | 在已核受保护原父内独占创建本单普通文件；须说明第一处可见但未写全、名称碰撞、发表中断时如何保留现场和只查原单。 |
| FS UUID、内核导出句柄、挂载/设备号组成的 birth | 不作为持久身份。逻辑原件由普通登记和各卷认领记录交叉验证；活体用原 FD、挂载、权限和两端同锁。只靠这些记录不能鉴别原盘缺席时的完整逐位副本。 |
| 文件系统类型白名单 | 只描述现有 `compare-files` 在读取陌生输入前排除伪文件的安全边界，不是新池支持清单。未能证明目标是可安全操作的普通存储，绝不盲目放行。 |

## 待写：本机 Web 安装和离线维护

这些是交付任务，不是已运行的功能。CLI 和回环 Web 复用小组应用动作，不执行 ZXS 命令、不依赖其进程或相邻源码。授权的离线写与在线业务写不并存。

| 项 | 交付顺序与验收 |
| --- | --- |
| H01 操作者/作业 | 明确启动、身份和原操作 ID、作用范围、计划确认、只查与明确续作分开。失联、同名换盘/账户、响应未知不换新票。Web 非 root，仅本机回环，验证会话、Host/Origin/CSRF，限额并排空。 |
| H02 数据盘和回收站盘设置 | 从明确选择的 Linux 挂载核实 SYSTEM、普通卷和唯一专用回收卷；不按品牌准入，不做专属探针。验证别名/重叠、来源不清、回收根与 SYSTEM/任一普通根来自同一文件系统或无法确认隔离、认领冲突、同名换物或未知旧材料时均不写。用已获准的独立试验验证互斥、新建不覆盖、文件/父目录同步及冷读，不把一次预检当作持久证明。 |
| H03 非空普通盘导入 | 只读清点与确认计划先行，保留空目录和原件；只向独立合格目标写普通文件，不就地转换。核命名冲突、数据与元数据/配额、暂存及 SYSTEM 交易条数/总字节和恢复余量。目标同步后独立重开、核对实际内容；成功也不自动删源。 |
| H04 状态 | 两端都呈现系统和磁盘状态。helper 只据已核单元、当次 OS 挂载与路径实体、在安全持锁时读到的登记角色/代次、原操作清理与离线事实；分别标时刻或原前沿。在线实时业务不可取得就写未核，盘不可达不等于已离线。不能把登记、服务 active、盘可见或系统停止混成一个绿灯。 |
| H04 运维仪表盘 | 分批：① 已有所选根的挂载/只读/容量源码，仍需证实实际 UUID 与注册 ID；② 已有显式块清单、受限型号和被动速率源码；补接口/温度/错误、只读 SMART/NVMe 及独立验收；③ 后续将带证据类型接入本机 Web；④ 可信安装、实际生效单元/覆盖、服务活动与有界近期脱敏报错。每项注明来源与时间，未知/不支持/无权限分开。不读写测速、不泄露序列号，不以整机统计冒充业务健康。 |
| H04 删除盘 | 永久退登记不擦盘，不等于正常主动下线、故障离线或文件软删除。拒绝仍有任何权威原件、待清责任、未知内容/状态或需保留的 SYSTEM/回收盘；服务/磁盘不在线不等于盘空。运行时两种下线仍在 ZXS。 |
| H04 文件系统检测与受限修复 | 独立的可选宿主工具，不改变 ZXS 通用格式。目标覆盖 ext4、NTFS、ZFS、XFS、Btrfs、exFAT、FAT32。先区分有限诊断/未查/需离线，不将 ZFS scrub 当只读、NTFS 有限核查当完整修复，或为 XFS 脏日志启用破坏选项。另做固定工具/版本/参数与原对象归属的预检、原单预览和显式授权；先在身份可核、未挂载、与原件隔离的独立工作副本上修复。不能排除外部日志/其他成员、swap、其他命名空间或重新挂载时，不授权对原盘写。本片没有安装、调用、修盘、自检或 Web 写入口。 |
| H05 停机核查与按原单查询 | CLI 对指定原池、卷、FILE 容器，分别报告登记、在位、元数据和已实际核验的正文范围；用池/种类/请求和原操作 ID 查历史、未完成或未知。查询停在现有证据，不同步推进或重放；无对应公开业务/账户格式时明确不支持。 |
| H05 受限原单恢复 | 另行授权并持原登记及所需原卷排他锁，只续协议允许、来源和阶段可验证的原维护动作。覆盖缺原件/同名替代/无权限不改、查询不续作、重复确认不重做；无默认修复或批量清理。日常建档、保存、发布、移动、回收操作不复制到维护 CLI。 |
