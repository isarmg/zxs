# helper 任务清单

本清单区分**已有源码**和**尚未实现的工作**；“已审”只指静态审查，不表示运行通过。命令和使用前提见[使用说明](README.md)，职责分界见[架构](ARCHITECTURE.md)。

## 源码已审待验证

在将来获准运行时，以下项目才可记录实际结果。正向文件用例只在受支持文件系统上的专用临时目录创建自己的数据；没有合格位置要记录先决条件不足，不能记通过。

| 项 | 已有源码 | 今后需要的证据 |
| --- | --- | --- |
| H01 操作者和资源 | 无默认服务；显式命令、有限输入和输出。目录最多 16 个、120 对关系、32 KiB 报告，最多占用 18 个目录描述符。 | 无参数或非法参数无观察结果；实核边界值和超限拒绝、无目录扫描及无持久任务。 |
| H02 目录和挂载 | `inspect-dirs` 观察路径实体与可见祖先；保留叶描述符，报告前重新解析原路径。 | 同一目录、兄弟、父子、链接、变换路径分别核对；即使叶仍是同一 inode，原父目录被替换也不得给出原观察。设备号不是物理盘证明。 |
| H03 陌生输入 | 比较前，两端都须通过原始描述符的设备/文件系统、实体、类型、链接数与容量检查；未知文件系统不读取。 | 纯分类用例与生产调用顺序已在源码中；它们不是在网络、虚拟或恶意挂载上实测过。合规文件的阳性对照与被拒输入均须单独记录。 |
| H04 观察状态 | 目录关系是数据；比较的相同、不同、无法完成分别返回 0、1、2。 | 断言实际退出码及输出；首块已不同但后续读取失败或终点意外增长时，不能报“不同”。 |
| H05 离线字节检查 | `compare-files` 从两个固定的普通文件完整分块读取，检查各自实际终点，末尾重核原位置与属性。 | 验证独立短读、受中断的终点读取，以及同一 inode 上的等长改写/新增硬链接；区分真正内容不同与不能完成。 |
| H06 身份与权限 | 只用当前 OS 身份，读取需可信的本进程描述符表和 `O_NOATIME` 权限，不提供隐式提权或换路径回退。 | 在受控环境验证权限不足或无法建立可信描述符时不读取、不返回成功；不为验收修改实际用户文件、凭据、挂载或服务。 |
| H07 独立工程 | 自有 Cargo 工程、锁和工具链；[交付核对表](RELEASE.md)列出独立构建与测试的输入及记录项。 | 尚无实际构建、用例结果、复建一致性或安装证据。 |
| H08 发行材料 | [依赖核对表](DEPENDENCIES.md)记录了全部 13 份锁定源码包的 SHA-256 比对、上游许可声明及包内材料位置。 | 尚未核实将交付的二进制、实际组件和随包许可材料；没有本次发行签名或独立验签证据。 |

## 待写

首阶段没有“完成构建/测试”的替代代码。下列工作有明确用途和授权才启动；目前没有这些命令、服务或发行物。

- **H01/H06，可选本地面板：** 若仅靠 CLI 确实不能满足操作者需求，才设计显式本机启动、自身会话失效、来源验证、作业所有者、慢客户端与排空；不引入默认监听、外部账户或口令重置。
- **H05，可选通用导出：** 若明确需要独立导出，须绑定原始源和目的父目录，只向全新目标无覆盖发布，可按原作业恢复；未知结果保留现场。不能借口“恢复”覆盖现用文件。
- **H07/H08，自身发行：** 锁定依赖的来源已列明；实际制品及随附的许可、校验/签名材料和安装/升级说明仍待交付。如需安装，必须能识别未知目标并拒绝覆盖。此清单不启动打包、签名、安装或部署。
- **H02–H04 的界线：** 不待实现业务磁盘登记或格式化、自动挂载陌生介质、链式复制/备份、解析专有持久格式、判定业务健康或重建服务状态。只在出现具体的本机观察问题时，才增加通用证据，不用未知状态猜测成功。
