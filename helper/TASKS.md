# helper 任务清单

本清单区分**已有源码**和**尚未实现的工作**；“已审”只指静态审查，不表示运行通过。命令和使用前提见[使用说明](README.md)，职责分界见[架构](ARCHITECTURE.md)。

## 源码已审待验证

在将来获准运行时，以下项目才可记录实际结果。正向文件用例只在受支持文件系统上的专用临时目录创建自己的数据；没有合格位置要记录先决条件不足，不能记通过。

| 项 | 已有源码 | 今后需要的证据 |
| --- | --- | --- |
| H01 操作者和资源 | 无默认服务；显式命令、有限输入和输出。目录最多 16 个、120 对关系、32 KiB 报告，最多占用 18 个目录描述符。 | 无参数或非法参数无观察结果；实核边界值和超限拒绝、无目录扫描及无持久任务。 |
| H02 目录和挂载 | `inspect-dirs` 观察路径实体与可见祖先；保留叶描述符，报告前重新解析原路径。 | 同一目录、兄弟、父子、链接、变换路径分别核对；即使叶仍是同一 inode，原父目录被替换也不得给出原观察。设备号不是物理盘证明。 |
| H03 陌生输入 | 比较前，两端都须通过原始描述符的设备/文件系统、实体、类型、链接数与容量检查；未知文件系统不读取。 | 纯分类用例与生产调用顺序已在源码中；它们不是在网络、虚拟或恶意挂载上实测过。合规文件的阳性对照与被拒输入均须单独记录。 |
| H04 观察状态 | 目录关系是数据；比较的相同、不同、无法完成分别返回 0、1、2。 | 断言实际退出码及输出；首块已不同但后续读取失败或终点意外增长时，不能报“不同”。 |
| H04 选定存储根的挂载与容量 | `storage-status` 与新登记解码同用 1–256 分量的原始选择路径（两个通用命令仍为 128）；对显式 SYSTEM/回收/数据候选分别报告内核挂载 ID、可获挂载根标记、只读标志及以字节计的总/空闲/可用量；末端重核路径与挂载。尚未运行。 | 核对真实观察和部分拒绝的输出，区分 ID 缺失/路径替换/无权限与 0 可用空间。角色是用户所选，不证明已登记、健康或可写。 |
| H05 离线字节检查 | `compare-files` 从两个固定的普通文件完整分块读取，检查各自实际终点，末尾重核原位置与属性。 | 验证独立短读、受中断的终点读取，以及同一 inode 上的等长改写/新增硬链接；区分真正内容不同与不能完成。 |
| H05 新登记的字节证据 | 独立解码 MAINT‑1 初始登记，核原始二进制路径、物件身份、角色序及 SHA‑256；按行核原卷标签和零业务前沿。只处理给定字节，无磁盘或账户操作。 | 与独立实现核同一固定向量；凭据来源、原 inode、挂载与在线共享/离线独占锁仍须在实际设备边界独立证明。不能用纯字节证据判定“已登记”或允许续作。 |
| H05 首次登记原 inode 自身的互斥 | 内部原语只在已持有的 SYSTEM 目录下新配 `O_TMPFILE`，在同一未具名、0600 的原常规文件上取 `flock(EX\|NB)` 并持有；不落名字、标签或初始字节，没有命令入口。若将来调用，会分配 inode，不是被动观察。 | 在隔离合格介质验证原对象具名/改名及最后一个同 OFD 描述符关闭时的互斥；正向命名用例需要能用 `AT_EMPTY_PATH` 链接自己创建的匿名文件。不同匿名 inode 互不排斥，不能代替全根锁、出生证、宿主/业务授权或在线持有链。 |
| H05 实际出生凭据 | 在内部首登锁持有期间，用原 SYSTEM 目录和同一未具名登记文件的正规描述符分别核对设备/inode、挂载、真实 FS UUID、完整内核文件句柄及存储 UID，只与给出的新登记中这两个原物比较；没有命令入口。 | 在受支持的自有测试介质验证真正匹配及“同 inode 数值、借用其他物件句柄”被拒；两件匹配不证明路径、其他卷、卷标、前沿或授权，不允许开始写。 |
| H06 身份与权限 | 只用当前 OS 身份，读取需可信的本进程描述符表和 `O_NOATIME` 权限，不提供隐式提权或换路径回退。 | 在受控环境验证权限不足或无法建立可信描述符时不读取、不返回成功；不为验收修改实际用户文件、凭据、挂载或服务。 |
| H07 独立工程 | 自有 Cargo 工程、锁和工具链；[交付核对表](RELEASE.md)列出独立构建与测试的输入及记录项。 | 尚无实际构建、用例结果、复建一致性或安装证据。 |
| H08 发行材料 | [依赖核对表](DEPENDENCIES.md)记录了全部 21 份锁定源码包的 SHA-256 比对、上游许可声明及包内材料位置。 | 尚未核实将交付的二进制、实际组件和随包许可材料；没有本次发行签名或独立验签证据。 |

## 待写：本机 Web 安装和离线维护

这些是交付任务，不是已运行的功能。CLI 和回环 Web 复用小组应用动作，不执行 ZXS 命令、不依赖其进程或相邻源码。授权的离线写与在线业务写不并存。

| 项 | 交付顺序与验收 |
| --- | --- |
| H01 操作者/作业 | 明确启动、身份和原操作 ID、作用范围、计划确认、只查与明确续作分开。失联、同名换盘/账户、响应未知不换新票。Web 非 root，仅本机回环，验证会话、Host/Origin/CSRF，限额并排空。 |
| H02 数据盘和回收站盘设置 | SYSTEM、普通数据盘、唯一专用回收盘分开选择，错角色/重合/回收盘同文件系统拒绝。分别实现首次初始化、既有池加入，不偷偷替换回收盘，不挂载、格式化或擦盘。 |
| H03 非空普通盘转换 | 只读清点与确认计划先行，保留空目录和原件；核验命名冲突、独立暂存空间、SYSTEM 交易条数/总字节及恢复余量。按原单导入、重新打开验证，未确认不动原件；成功不自动删源。 |
| H04 状态 | 两端都呈现系统和磁盘状态。helper 只据已核单元、当次 OS 挂载与路径实体、在安全持锁时读到的登记角色/代次、原操作清理与离线事实；分别标时刻或原前沿。在线实时业务不可取得就写未核，盘不可达不等于已离线。不能把登记、服务 active、盘可见或系统停止混成一个绿灯。 |
| H04 运维仪表盘 | 分批：① 已有所选根的挂载/只读/容量源码，仍需证实实际 UUID 与注册 ID；② 显式有界候选盘清单、接口/型号、温度/设备错与权限；③ 同一设备两次被动计数采样的读写速率；④ 可信安装、实际生效单元/覆盖、服务活动与有界近期脱敏报错。每项注明来源与时间，未知/不支持/无权限分开。不读写测速、不泄露序列号，不以整机统计冒充业务健康。 |
| H04 删除盘 | 永久退登记不擦盘，不等于正常主动下线、故障离线或文件软删除。拒绝仍有任何权威原件、待清责任、未知内容/状态或需保留的 SYSTEM/回收盘；服务/磁盘不在线不等于盘空。运行时两种下线仍在 ZXS。 |
| H05 跨实现的离线互斥与恢复 | 拟议 ZXS-MAINT/1 先固定规范、正反例/中断向量和摘要。原 SYSTEM 登记文件上的生命周期 flock：在线业务全程共享、离线维护独占；与短期目录事务锁分开。覆盖首次并发、不同 SYSTEM 争同一候选卷只一方可认领、热锁 inode 被替换、长读/在途写、未完成登记、冷重开及拒绝旧格式。双方实现前禁用离线存储写。 |
| H06 首管/密码重置 | 原状态明确从未创建管理员才首设；明确的恢复身份才重置，撤销相应会话，绝不依据 eUID/文件缺失。采用成熟凭据算法和受控输入，不落明文、不通过命令行/环境/日志或回执传密码。两边同一认证数据，不维持影子账户库。 |
| H07 安装向导/服务管理 | 环境 → 数据盘/回收站盘 → 首管 → 确认服务配置 → 状态/排错。核可信制品/目标/固定 systemd 单元及覆盖，区别配置、启停和开机启用；限权适配器独立认证，拒接管同名陌生单元、执行任意 shell 或系统控制命令。未获得真正离线锁不操作存储。 |
| H08 独立交付 | 以[交付核对表](RELEASE.md)分别证明实际构建、许可、签名、安装、升级和中断；既有依赖来源核对不是发布验签。 |

通用文件导出没有新需求，不顺带新增。没有受管备份、旧格式兼容或自动迁移。需要检查的共同数据向量不是第三个项目、共享运行环境或共同代码库。
