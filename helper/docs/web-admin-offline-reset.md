# 原部署的 Web 管理员：离线重置

此命令只认根目录下唯一受保护的原 ZXS 部署登记、原完整 ZXS 文件和其精确 v17 SYSTEM。需要完全离线且能持有原 SYSTEM 排他租约；没有停止、启动、自动采用他处站点、迁移、盘操作或服务命令。Helper 不保存路径或凭据配置。

```text
helper reset-web-admin new --op ID --approval ID --helper-sha256 HEX
helper reset-web-admin receipt --op ORIGINAL_ID --approval ORIGINAL_ID --helper-sha256 HEX
```

新单只指定两个不相同的操作与批准参考，以及独立取得的原 Helper 文件 SHA-256。不能用未核来源的文件对自身摘要作授权。不要把密码放在命令行、环境、浏览器、脚本或文件。命令会显示原站点、原 Web 登录名和上一代次，需要在同一可信本机前台明确确认，再通过原不回显终端输入两遍。低权限进程须能核实当次 TTY 未记录输入、锁住校验工作内存（Argon2id 64 MiB 加进程开销）、禁用 core 转储并证明原库、原标记与原待核凭据；无法做到就不接受密码或不提交。不要求当前 Web 密码，也不会变更账号名、分享、SMB 凭据或 ZXS 文件。存在不能确认的 SMB 代次或原 vault 证据时保守拒绝，不能借此修复 SMB。

写入只在原 SYSTEM 的短 SQLite 事务中同时记录 Web 新代次和相同原操作的已提交回执；没有中间可登录的临时凭据。确认结果需同一原库落盘、独立复读、实际工作进程正常退出与通道关闭，并在最后核对保留的原库、原 SYSTEM 卷标及原 SMB vault 对象；前台不取得可读的数据库或卷标文件。回执不是登录验收。若开始提交后没有收到明确结果，不重新发单：用同一操作和批准参考只读查询。结果会标明这是否仍是当前 Web 代次；查不到或证据不足不是重试许可。回执不要求输入口令，不重算校验器。没有密码、校验器或 SMB secret 进入前台进程、日志或工作进程通道。

源码和一次性合成测试不等于原部署上实际重置或冷启动验收。本轮不做实际凭据变更。
