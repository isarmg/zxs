# 空 DATA 退盘的回收回执

回执字节布局以 [ZXS 回收记录规范](../../../zxs/docs/specs/recycle-record.md)为准。Helper 独立读取，不依赖 ZXS 的代码或构建。

Helper 在离线独占锁内核对已登记的角色目录和原 `server.conf`。目标盘的 `data` 和 `staging` 必须为空；只有标记、未初始化的盘不能有容器路由。

若系统盘的原路由仍指向此 DATA 令牌，Helper 只在原已登记回收盘的 `containers` 下核对选中回执对应的副本。副本的 `ready` 必须与系统盘回执逐字节一致，副本外层目录 inode 必须匹配，且必须有同挂载下的真实 `container` 目录。不会跟随符号链接或访问其他挂载。

RC2 要求原池、路由的 DATA 令牌及已登记回收盘令牌相符。内核设备号重分配不改变登记身份，挂载与原件仍在每次操作时核对。旧 RC1 只按原设备号和 inode 核对，不自动改写，设备号不匹配时拒绝退盘。

这里核的是回收回执和所在原件，不把源证明表的摘要当作容器内容校验。核对失败时拒绝退盘，保留原盘、标记和回执。
