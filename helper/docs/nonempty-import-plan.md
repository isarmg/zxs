# 非空源目录：只读导入计划

原源目录和现有目标卷必须分别由操作者明确指定。只有同一确切 v19 池、同一已提交 INIT 登记的普通 F 才可作这项计划的目标，不能选 SYSTEM、回收卷、未登记目录或默认磁盘。请先从池内现有资料确认普通卷 ID 和原登记目录。

```text
helper plan-nonempty-import --init-actor ID --storage-uid N --storage-gid N \
  --system DIR --pool POOL_ID --init INIT_OP --source DIR \
  --target-volume VOLUME_ID --target DIR
```

沿用[只读源清点](nonempty-source-preflight.md)的本机可信前台、原 SYSTEM 只读/noatime、原目录持有和两次有界元数据清点；不会打开源文件正文。目标也须是同一挂载证据下独立、实际持有的原目录，不与已登记的其他根或所选源重叠。核对原 INIT 的 ID、路径、卷标和单名限制；目标目录当时应只有原登记标记。不会锁定或读取其他普通卷或回收卷的内容，不更改任何挂载或权限。

- **0，计划观测完成、未见这里检查的阻挡**：显示源文件数、目录数、逻辑长度、目标卷/挂载及单名上限、两次观测中较小的可用字节估计。
- **1，有已见阻挡**：原源清点拒绝条件仍有效；只读目标、名称或相对路径在规划普通文件 ID 后过长、可用估计不足以覆盖源完整逻辑长度也会阻挡。
- **2，未确认**：如目标不是本次原 INIT 的空普通 F、卷标或实体不匹配、忙、现场发生变化，或证据不足。不会猜测默认目标或给出不完整的计划。

这是必要条件检查，不是导入许可、空间预留、配额或持久凭据。估计没有计入容器、目录或 SQLite 事务开销；源内容、冲突、最终布局和断电恢复仍需后续的实际导入协议。不会导入、建立池、复制、删除、转换或写入 SQLite，源盘原件不变。
