# 按需复查原 ZXS 部署

`helper check-deployment` 只在真实宿主前台管理终端按需执行。没有参数、浏览器入口、另一份 Helper 配置，也不查找其他位置。它不启动或停止 ZXS；原部署正在使用或无法确认时，只报告「未确认」，不会建议重装、改写或自动采用另一个实例。

此检查只接受当前候选的确切 v18 来源。先持有原 ZXS 权属目录的共享租约，再持原 SYSTEM 独占租约和原实例独占租约：验证固定原部署选择记录、完整受保护的 `site.v1` 与原安装计划，验证它们保存的原单 ELF 规范路径与独立批准的完整 SHA-256（不执行它，也不另选路径）。已降权读者只使用原 SYSTEM 和标准 SQLite 只读连接，核旧 INIT 原身份、卷标与完整原登记摘要，再读当前已提交的 Web/SMB 共用代次和公开凭据坐标。读者退出后仍核回原数据库和卷标的同一非可读描述符及实际原名。父进程只比对同一原凭据记录的头部 224 字节，不读取末尾凭据内容。SQLite 和文件系统仍可能进行通常的访问时间记账；该检查不修改应用数据、登记、密钥、配置或介质。

退出值 0 只表示这一次在锁内确认了原离线部署与当前凭据代次，不授权维护、不保证服务可用，也不访问原数据卷和回收卷。退出值 2 是缺失、忙、发生变化或确证不足。不把只读检查结果持久化或交给任何写入口。`helper discover` 仍只是独立的非授权候选发现，也不会自动调用此命令。
