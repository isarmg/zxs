# 只读 NVMe 健康观测

先用原有 `helper disks` 查出自己要检查的整块命名空间，再明确指定一个设备数字：

```text
helper disk-health --device MAJOR:MINOR
```

只支持有可核实本机直接 PCIe 控制器的 NVMe 命名空间。分区、多路径、网络 NVMe、SATA/SAS、未经核实的设备名、系统不准读取或设备换代均不给健康结论。读取日志可能要求 Linux 的 `CAP_SYS_ADMIN`；命令只报告拒绝，不提权、不搜索其他设备，不会由 `helper disks`、Web 或安装过程自动运行。

输出是**控制器级的瞬时观测**，并不是文件系统或某分区的健康保证。报告关键警告位、开尔文温度（未报告单列）、备用空间及其阈值、耐久度消耗百分比（可超过 100）、完整介质错误计数。退出 0 表示得到该报告，不表示设备健康；退出 2 表示未观测到可靠结果。

只请求标准 SMART / Health Information 的固定 512 字节日志，保留异步事件通知，不写磁盘、不清日志、不启动自检、不更改电源策略或挂载、没有外部工具。这个日志请求仍是硬件 I/O，不能保证控制器不唤醒；不希望接触设备时只用原有被动清点。当前源码和合成记录不代表真实硬件验收。
