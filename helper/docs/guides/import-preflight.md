# 非空源目录预检

供导入前清点使用。先停业务服务，以原服务账号提供当前角色清单。
只观察元数据，不读正文、不预留名称或空间，也不发生导入。

```sh
helper preflight-import SOURCE SYSTEM RECYCLE DATA [DATA ...]
```

`SOURCE` 是待清点的外部目录。后续参数按当前登记顺序填 SYSTEM、RECYCLE 和全部 DATA，不是导入目的盘。
来源可以位于同一文件系统的非重叠位置，不能与角色、状态或安装路径重叠。不跟链接、不跨挂载。

| 选择 | 看到什么 |
| --- | --- |
| 无选项 | 普通文件、目录和空目录计数，文件逻辑总字节，以及需映射子目录文件、非法顶层显示名的计数。多硬链接按名字计数，并单独提示。 |
| `--show-names` | 在完成清点后输出按原字节转义的来源相对路径。只有可原样使用的顶层文件有建议名；其余为 `mapping-required`。 |
| `--check-target` | 先在同一独占锁内使用已安装 ZXS 核对现有容器名，再清点源目录。可原样使用的顶层名称分别报告 `target-name-exists` 或 `no-exact-target-name`，不替需映射项建议名字。 |

`--show-names` 和 `--check-target` 二选一。名称按原始拼写、区分大小写，例如 `Report` 与 `report` 分别检查。
不自动展平、改名，不验证 Workspace 本地名称限制。

## 限制与拒绝

- 遇到链接、特殊项、意外跨挂载或原件变化，拒绝输出部分清单。
- 目标名称查询要求固定安装位置 `/zxs/bin/zxs` 及其父目录受 root 保护；其他账号不可写。
- 预检没有全局项数或自设超时限制；列名的内存随清单增长。路径和描述符仍受系统限制。

结果是这次观察，不是目录快照或导入计划。要写入池，另行[准备并应用原计划](offline-imports.md)。
