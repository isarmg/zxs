# 离线核验一个容器

[仅静态] 需要配套的 ZXS 核验入口。此命令只核验指定容器，尚无实机盘验证。

先停 ZXS，用原专用非 root 账号，按登记顺序给出全部角色目录：

```sh
helper verify CONTAINER SYSTEM RECYCLE DATA [DATA ...]
```

`CONTAINER` 由 32 个小写十六进制字符组成，不能全零。按原路由仅核验活动 DATA 或已选中的回收副本，不猜名字、不扫描其他容器。

核验包括选中容器的原回执链，以及每份保留正文的完整字节数、实际 EOF 和 SHA-256。Helper 与 ZXS 在本次调用中核对双方持有相同的原角色目录。只有结果匹配、子进程正常退出、没有多余消息且原锁与原件仍可确认，才输出报告。零字节正文可以有效。

路由存在但尚无完整的选中容器、选中回执或正文不一致，或缺少配套程序时，不报告成功。通过只说明此次读取的指定容器与原回执相符，不判定未核暂存、先前操作是否已持久化、物理盘健康或备用副本可用。

不新增、修复、迁移或清除任何存储记录。不改用旧命令，也不格式化、挂载、卸载或改变服务状态。
