# 非空普通盘：只读源清点（确切 v19 源码候选）

这不是转换器。它不在原盘就地建池，不复制文件，不创建暂存或 SQL 记录，不删除、卸载、格式化、重启或启用任何东西。命令不接目标参数，也没有批准、恢复或应用模式。没有执行现场预检或验收。

```text
helper check-nonempty-source --init-actor ID --storage-uid N --storage-gid N \
  --system DIR --pool POOL_ID --init INIT_OP --source DIR
```

由操作者在可信本机 root 前台明确选择既有 SYSTEM 和一个原源目录。两目录都须在已挂载的文件系统上，且能独立核实原路径与实体；不是块设备、卷镜像或任意程序。只支持核准的确切 v19 SQLite；不按版本数字猜测格式。原 SYSTEM 在整个只读观察中保持同一实际排他租约，唯一读工作进程按本次给出的 UID/GID 降权；核对真实 INIT 原主体和池登记的 UID，GID 用于确认当次低权限身份，并非 SQLite 保存的历史 GID；没有另存的 Helper 配置，并只在固定 Unix SQLite 只读路径两次确认同一原已提交 INIT、卷标和全部登记根。因 SQLite 的标准 VFS 不申请不更新时间，SYSTEM 必须**已有**只读或 noatime 挂载策略；不为此更改挂载或降级。旧 R/F 名称只作排除；没有读它们的卷标、正文或原设备。已有登记路径的冲突可以直接阻断。SYSTEM、明确所选原源及其他用于排除的登记路径均使用同一有界的本任务挂载证据，逐层检查当前目录描述符；已知网络、自动挂载、伪文件系统、不明或多义的跨挂载在深入前拒绝，已知本地跨挂载只试一次无重新查找回退的缓存路径。固定卷标和 DB 名也禁止跨挂载。前后挂载证据无法重合、实际持有物无法复核，均属未确认，不猜测来源可使用。此限制假定可信本机挂载命名空间，不认证底层物理介质；操作中请勿调整目录、挂载或权限。

源目录从终端固定原实体和挂载，工作进程复核后只在同一受支持本地文件系统上，以同一只读目录租约和 `O_NOATIME` 独立两次清点。当前初版用已有本地且可证的完整挂载边界（ext2/3/4、XFS、Btrfs、F2FS）；子目录 bind 或不能证为完整根的 Btrfs 子卷挂载也可能未确认。不会因预检限制要求更换文件系统。只按实际目录描述符走单个相对名称，不越过符号链接、其他挂载或实体边界。最多观察 2048 个非点项、相对 32 层和 4096 字节；这是**预检预算**，不是未来导入文件数上限。文件只有 O_PATH/元数据/当前读权限查询，不打开正文。两次相同的有序名字和元数据证据后才发布；目录租约是协作式，不冻结外部程序或管理者；这不是原子快照。

- **0，源元数据清点完成**：只给普通文件数、子目录数（分开计空目录）、逻辑长度与当次挂载 ID。原目录读权限测试不是正文完整性。未核目标、空间或配额，不能据此开始转换。
- **1，有已见阻挡**：如重叠已登记位置、疑似控制名/旧卷属性、越界挂载、符号链接或非普通项、硬链接、不能按当前普通名称解释、确知没有读取权限、完全空根。不公布条目名或部分清单，也不把保守拒绝解释为真实旧池。
- **2，未确认**：如忙、池/角色证据不全、路径或名下物件变化、权限/无时间更新证据不足（例如原低权限工作进程无法为不归它所有的子目录用 O_NOATIME）、I/O 或超限。没有自动重试、继续、强制或借新路径取代原件。

下一步需**另选和获准**一个不重叠的暂存目录。它可以在原盘同一文件系统的独立目录，例如不属于源清点树的兄弟目录；另一块物理盘不是硬要求。同一文件系统并不等于已经隔离、空闲或足够；选择整个挂载根时不能默默排除其内子树，须另定独立范围。未来导入须证明实际目标、名称冲突、容量/配额、同步、SQL/回滚日志、断点和目标独立复开的一致性，且原数据保留；导入结束也不授权删除原件或接管旧格式、历史或权限。
