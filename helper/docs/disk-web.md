# 本机磁盘面板

获准运行时，普通 Linux 用户可在自己的前台终端输入 `helper disk-web`。打开终端给出的 **`http://127.0.0.1:随机端口/`**，在页面中输入一次性配对码。没有默认端口、后台安装、启动时扫描或局域网地址；不把码放在链接、命令行、环境或日志里。当前只有源码；没有启动面板或做浏览器验收。

| 面板按钮 | 实际会做什么 |
| --- | --- |
| 查看设备与挂载 | 和 `disks` 使用同一宿主读取。显示块层容量、整盘/分区和父盘、可核型号、内核设备号、缓存 FS UUID/PARTUUID、当前直接匹配的挂载 ID。它们是不同的标识，不是健康或归属证明。 |
| 读取本次 I/O 速率 | 只在点击后对同一实例采两次内核计数。显示实际间隔、读和写 B/s；不产生测试流量。实例更换/计数下降/样本缺失为未知，不把整盘和分区相加。 |
| 核对工具安装位置 | 从 `fs-tools` 的七项类型化清单读取每个固定槽的安装元数据。区分随包配方和宿主观察，不因位置存在而认定版本匹配、验签或开始检查。OpenZFS 不加载模块、不调用 `zpool`。 |

### 可选：在网页上检查一个已封存的镜像

`helper disk-web --fat32-copy /绝对路径/volume.img --sha256 受信来源给出的完整SHA256` 是操作者**只授权本次面板检查这一份副本**的选择。IMAGE 和 SHA 是操作者本机命令行参数，可能出现在 shell 历史或按宿主策略可读的进程参数中；不用它们代替会话票。启动即按[镜像和几何边界](fat32-copy-check.md)读取原普通文件，制作不可执行、不可写的独立内存副本，并全量核独立摘要。失败不进入监听；默认 `disk-web` 不读取镜像，配对也不能补发此授权。

1. 配对后点“预览终端已选镜像”，核对 SHA-256、字节数、扇区及簇数。预览不运行检查器，确认票 90 秒有效；没有文件路径、上传或设备选择框。
2. 点“确认：只读检查这份副本”。服务端先认领本票，只有独立普通工作进程才会重新验证所持副本的封印、全 SHA 与几何，并运行已固定的 `fsck.fat -n`。没有自定义参数、维护权、原件路径或修复模式。重复确认不会启动第二次。
3. 点“查看同次结果”。只显示已确认的类别与数值，不显示卷内文件名、工具原文或镜像正文。工具不可用、异常退出和不完整回执都不报“未发现问题”。浏览器在提交后断线时可在同一仍配对页面查询，不能用刷新或启动新进程找回旧结果。

这里的工作进程必须是受保护 `/usr/bin/helper` 中与本次运行相同的原 ELF；没有 PATH 或不同安装回退。子进程只继承封存镜像和专用结果/错误管道，获得的输入不包含浏览器配对凭据或监听套接字；它关闭其它描述符的继承，在用于上游工具的隔离中不挂载原件或设备。关闭应答只表示不再接受请求。终端随后向正在运行的专用进程发 TERM 并等候其实际退出；没有原结果及完整回收证据会报未确认。强杀、异常退出或内核 I/O 停顿时，不承诺已排空，不能用浏览器回复或进程消失当作升级许可。不会启动 ZXS、加载模块或修盘。升级时先关闭面板并等正在运行的检查完全收尾。本操作未构建、运行或做实机验收。

配对仅一用，2 分钟有效；失败六次关闭。已配对会话最多 10 分钟、程序全程最多 512 次本机连接。刷新页面、关页不会找回凭据；“结束会话”关闭监听，或直接从终端结束进程。网页不写 cookie、本地存储或请求日志。凭据仅留在本标签页内存；每次观察都校验同一回环地址/端口、精确 Origin、会话授权和单独的 CSRF 值。不接反向代理、不提供 CORS 或可嵌入框架。

配对码只发到进程已有的标准错误终端：接受已核定的 Linux 虚拟控制台、devpts 从终端或当前 TTY 设备；需与操作者同会话、同前台进程组。后台、重定向、其它会话、伪终端主端或不能确认的终端拒绝，无其他输出回退。必须是有控制终端的受限本机普通单线程进程（非 root，实际 UID/GID 一致，没有额外宿主组、可继承或有效能力，禁止取得新特权）。账户不符合时拒绝，**不要用 sudo 运行**。信任操作者终端、本机内核和当前浏览器；不防已控制同一账户/终端的进程。HTTP 只用于本机回环，不构成对外公开部署方案。

### 待运行验收

在独立 Debian 13 amd64 验收机上使用已验证的已安装发行物、受限普通用户和自建 FAT32 测试卷镜像：
- 不预选、错摘要、超限镜像、非固定安装、非前台终端均不能得到有效检查票。无参数面板仍可观察。
- 终端封存后在自有夹具替换原路径；预览和检查仍须针对原封存摘要，替换文件无变化。另一会话、跨源、缺任一凭据、伪票、超时未用旧票均不能启动。
- 同票双击/模拟浏览器断开后再查询：最多一项上游检查，完整回执中应得到与独立 CLI 相同的类别和簇计数。缺依赖、已更换安装、子进程信号或输出残缺无任何“未报告问题”回执。检查后不留后台工具，HTTP 页面、回执及转述的检查结果不传原路径或卷内文件名。
- 验证普通结束、终端发出中止及请求已送出但应答丢失的实际状态；不把没有收到浏览器回复当作已取消或已成功。清理未证实时不得据以升级私有工具包。

核对点见 [Linux 非可执行 memfd](https://docs.kernel.org/userspace-api/mfd_noexec.html) 和 [父进程退出信号](https://man7.org/linux/man-pages/man2/PR_SET_PDEATHSIG.2const.html)。
