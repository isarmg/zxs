# ZXS-PORTABLE-1：卷认领普通文件

> **历史原型，已停止。** 下文只记录切换前的试验格式，不适用于新池。新池使用[现行离线首设契约](headless-offline.md)，不从这里初始化、迁移或续写。

本页固定一项互操作数据：受保护卷根下一份**普通文件**，下文简称卷标 `VOLUME`（不是业务名或实际盘上文件名）。文件只声明“哪个池的哪一笔原决定给这个逻辑卷指定了什么角色”。它不是登记数据库、物理盘身份证、管理员授权、完成回执或用于搜盘的指针。辅助端与业务端各自实现，不相互调用。这里尚未定义整个池的创建、发表或恢复；**没有可以写盘的入口**。

## 固定位置：不占用业务名

SYSTEM、回收及各普通卷在各自登记根下使用同一精确 ASCII 文件名：`.zxs-new-ffffffffffffffffffffffffffffffff-0`（32 个小写 `f`，总 43 字节）。这沿用业务命名已保留的**一个拼写**，不把 `VOLUME`、所有点文件或整个前缀变成保留名。普通数据根仍直接承载业务目录和 FILE 容器，不新增外层。该拼写也不是普通 FILE 的派生容器名：只有开头一个点，末尾不是 FileId 的 32 位十六进制。

新格式只在所选登记根这一层、按本池确切原据识别卷标。在这些根上，暂存票分配、恢复和清理**不得**签发/移走/清扫这一个槽；名称语法仍须把它和普通业务目录区分，不能因不再签发该槽而允许用户建同名目录。这个限制不保留整个票号或其他槽，更不把任何其他层级的同名物解释为卷标。大小写/别名不能折算成原件；同名未知、错类型、实际名字不精确或物理组件限额不足，一律不接管。不根据文件名打开外部路径。

## 文件的全部 103 字节

偏移从 0 计。没有长度前缀、填充、换行或尾随字段。所有 ID 和摘要都是原始字节，不是十六进制文本，也不进行整数、UUID 字段或宿主字节序转换。

| 偏移 | 字节数 | 含义 |
| ---: | ---: | --- |
| 0 | 22 | ASCII `ZXS-PORTABLE-1/VOLUME` 后跟一个实际的零字节（`00`）。 |
| 22 | 1 | 角色：数值字节 `00` = SYSTEM（S）、`01` = 唯一专用回收卷（R）、`02` = 普通数据卷（F）；不是 ASCII 字母，其余值拒绝。 |
| 23 | 16 | PoolId，不能全零。 |
| 39 | 16 | VolumeId，不能全零。 |
| 55 | 16 | 最初认领这个卷的 OpId，不能全零。初始卷用首次认领单；后来加入的卷用它自己的加入单，不是“任意最新单”。 |
| 71 | 32 | `source_digest`：SHA-256 的 32 字节原值。指向本行**原认领决定的规范主体**，不是当前整份登记文件的摘要。 |

**摘要方向只从原决定到标记。** 原决定主体自身按版本区分操作种类，绑定池、原操作和不可变的认领选择；输入是其原始规范字节，不包括后续提交/确认封套、派生的 `VOLUME` 字节或该文件的散列。先有一份确定的原决定及其摘要，再得出一个或多个标记，不能让两者互相依赖。更晚的账户、数据或拓扑变化不重算旧标记。没有摘要缺省值，也不再给这个标记加一层自校验：在位核验须与受保护 SYSTEM 给出的**完整预期行**逐字节相同。不能仅凭自算哈希或任意一个给出的 32 字节认定原决定。首次认领的主体、原登记和零前沿见[首登记规范](portable-genesis-v1.md)；后来加盘的原决定另定。这些规范与合成向量都不是已启用的签发路径。

## 如何判读，何时停下

1. **结构检查**只认上述固定长度、域、角色和非零 ID。截短、附加字节、旧域或未知角色一律拒绝。单独遇到结构正确的文件，最多读作一份声明；它的摘要也不能据自身验证。
2. **按原行核对**时，从显式选定且有受保护来源的 SYSTEM 开始，在正确的原登记锁下核实登记、对应行和确认位置。先核 S 自己的行 0 与它的 `VOLUME`，再按本操作获准的根集核 R/F，不从陌生文件打开外来路径。按池、卷、角色、认领 Op 和原决定摘要比全值，另核当前仍有效的登记及现场目标。已落原票但未完成、历史已退登记或同一逻辑卷出现在两处，都不等于当前可用。
3. **不是写许可。** 字节完全相同的副本也会通过字节比较，但不能据此证明是原介质、确认回收盘独立或授权维护。文件缺失也不能证明空盘；同名目录、链接、未知/旧格式及无法归属的半写文件均不覆盖。将来的维护写仍须单独授权、取得真原登记和所需全部卷根的排他锁，满足可信来源及普通文件/父目录的耐久条件。不靠扩展属性、设备号、导出句柄或任何文件系统品牌。

[固定向量](../tests/portable/volume-claim-v1.txt)含同一初始原单的 S/R/F 以及一笔后来加入的 F。`source_input_*` 是**仅为测试编造的字节**，不是合法 SYSTEM 记录或授权；给它们算 SHA-256 只是为了固定此处外部输入与完整卷标字节，不能把测试来源升作真实认领决定。向量文件使用小写十六进制；盘上的 `VOLUME` 始终只含那 103 个原字节。
