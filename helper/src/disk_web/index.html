FIRST INSTALL

首次安装向导

这里仅核对安装包的固定模板并给出本机步骤。不会选择盘、执行这些命令、安装服务或接收口令、路径、审批、回执。步骤不会自动打勾；真实结果请留在终端。

本路径面向 Debian 13 amd64。若尚无独立验签的同版发行、合格的新卷及受保护的宿主维护身份，请停在准备阶段。模板一致不等于已验签、已配置、已启动或可登录。

可选择并复制下列某一段固定命令。先在对应的另一个本机终端用真实、非秘密值设定该段的变量；缺值会阻止执行。不要把口令设进变量或复制到本页。每个写操作分别确认，不能用配对授权。

  1. 核对新卷，在终端初始化存储池

    先独立确定全新 SYSTEM、专用回收卷和至少一个普通卷，按约定预先挂载。回收卷须与 SYSTEM 和所有普通卷来自不同的文件系统；一个名字或挂载 ID 不能证明独立。普通用户可先观察，不会写入：

    /usr/bin/helper storage-status \
  --system "${SYSTEM:?set SYSTEM in this terminal first}" \
  --recycle "${RECYCLE:?set RECYCLE in this terminal first}" \
  --data "${DATA:?set DATA in this terminal first}"

    下面是本机 root 前台的独立离线写入，只选新根；多块普通卷各加一对 --data 参数。留存已确认的 pool= 与原 operation=。如果中断，只核当时原件，按原单指引选择同一 INIT 的 resume，不要换号或重做。

    /usr/bin/helper install-pool new \
  --op "${INIT_OP:?set INIT_OP in this terminal first}" \
  --approval "${INIT_APPROVAL:?set INIT_APPROVAL in this terminal first}" \
  --system "${SYSTEM:?set SYSTEM in this terminal first}" \
  --recycle "${RECYCLE:?set RECYCLE in this terminal first}" \
  --data "${DATA:?set DATA in this terminal first}"
  2. 准备新的专用 Samba 实例并生成原域

    只在另一个受信 root 前台操作。若现场已独立准备相同合格布局，别再建。否则这一步只新建实例布局，不启动服务；真正完成会返回 layout=prepared。

    /usr/bin/helper setup-pair provision --create-layout \
  --instance "${INSTANCE_ID:?set INSTANCE_ID in this terminal first}" \
  --approval "${LAYOUT_APPROVAL:?set LAYOUT_APPROVAL in this terminal first}"

    域供给是另一个需单独批准的写动作；其原号不能沿用 INIT。成功的 domain-binding=confirmed 还带 bound_sha256=，把它随原回执留在本机，供稍后的启动前预检。缺回执或中断不重发新单。

    /usr/bin/helper setup-pair provision \
  --system "${SYSTEM:?set SYSTEM in this terminal first}" \
  --pool "${POOL_ID:?set POOL_ID in this terminal first}" \
  --init "${INIT_OP:?set INIT_OP in this terminal first}" \
  --instance "${INSTANCE_ID:?set INSTANCE_ID in this terminal first}" \
  --op "${DOMAIN_OP:?set DOMAIN_OP in this terminal first}" \
  --approval "${DOMAIN_APPROVAL:?set DOMAIN_APPROVAL in this terminal first}"
  3. 在原终端设置唯一 Web 管理员与 SMB 用户

    继续使用另开的受信本机 root 前台终端，不在磁盘面板的普通用户终端执行。使用两个不同登录名与不同口令；命令确认同一池和专用域，秘密按固定无回显提示分别输入。页面不会代输。确认后留存 pair=confirmed 及两原 ID，这不保证能登录。

    /usr/bin/helper setup-pair enroll \
  --system "${SYSTEM:?set SYSTEM in this terminal first}" \
  --pool "${POOL_ID:?set POOL_ID in this terminal first}" \
  --init "${INIT_OP:?set INIT_OP in this terminal first}" \
  --instance "${INSTANCE_ID:?set INSTANCE_ID in this terminal first}" \
  --domain-op "${DOMAIN_OP:?set DOMAIN_OP in this terminal first}" \
  --op "${SETUP_OP:?set SETUP_OP in this terminal first}" \
  --approval "${SETUP_APPROVAL:?set SETUP_APPROVAL in this terminal first}" \
  --web-login "${WEB_LOGIN:?set WEB_LOGIN in this terminal first}" \
  --smb-login "${SMB_LOGIN:?set SMB_LOGIN in this terminal first}"

    只查也在受信本机 root 前台，使用原来的所有非秘密选项和同一个原操作号。退出 0 为该原单已确认，1 是未找到或待办，2 为未能确认。只查不会提示口令、同步或重做。

    /usr/bin/helper setup-pair enroll \
  --system "${SYSTEM:?set SYSTEM in this terminal first}" \
  --pool "${POOL_ID:?set POOL_ID in this terminal first}" \
  --init "${INIT_OP:?set INIT_OP in this terminal first}" \
  --instance "${INSTANCE_ID:?set INSTANCE_ID in this terminal first}" \
  --domain-op "${DOMAIN_OP:?set DOMAIN_OP in this terminal first}" \
  --op "${SETUP_OP:?set SETUP_OP in this terminal first}" \
  --approval "${SETUP_APPROVAL:?set SETUP_APPROVAL in this terminal first}" \
  --web-login "${WEB_LOGIN:?set WEB_LOGIN in this terminal first}" \
  --smb-login "${SMB_LOGIN:?set SMB_LOGIN in this terminal first}" \
  --receipt-only
  4. SMB：先生成不启用的预检候选

    在普通用户自有、他人不可写的工作目录操作。原域摘要应来自已确认的原回执，两份在线程序摘要取自独立验签材料，不从待验文件自行核准。生成器只写一个未启用的 zxs-smb-preflight.service 候选。

    /usr/bin/python3 -I -S -B /usr/share/local-ops-helper/smb-host/check.py render \
  "${SYSTEM:?set SYSTEM in this terminal first}" \
  "${POOL_ID:?set POOL_ID in this terminal first}" \
  "${INSTANCE_ID:?set INSTANCE_ID in this terminal first}" \
  "${DOMAIN_OP:?set DOMAIN_OP in this terminal first}" \
  "${STORAGE_UID:?set STORAGE_UID in this terminal first}" \
  "${STORAGE_GID:?set STORAGE_GID in this terminal first}" \
  "${BOUND_SHA256:?set BOUND_SHA256 in this terminal first}" \
  "${DEDICATED_SMBD_SHA256:?set DEDICATED_SMBD_SHA256 in this terminal first}" \
  "${SMB_STORAGE_SHA256:?set SMB_STORAGE_SHA256 in this terminal first}"

    只有管理员独立复核单元、来源和原件后才可另行安装并手工启动这一个预检。退出 0 只表示所选安装原件与投射相符；失败、未运行与登录是不同状态。这里没有公开的 SMB 启动动作。

  5. 管理 Web：启动 ZXS 的原生 HTTP

    两账户已确认后，用该池登记的普通存储身份启动验签版 ZXS；不需要 nginx、域名、证书或套接字激活。下列命令只是在终端运行 ZXS。需确认你愿意让管理端口在所有 IPv4 接口监听；直连没有加密，只在可信网络使用。

    ZXS_SYSTEM_ROOT="${SYSTEM:?set SYSTEM in this terminal first}" \
ZXS_POOL_ID="${POOL_ID:?set POOL_ID in this terminal first}" /usr/bin/zxs

    从浏览器打开 http://<服务器实际 IPv4>:8443/，用唯一 Web 管理员登录。0.0.0.0 仅是监听值。若需要 HTTPS，由你的外部软件独立终结 TLS，不在 Helper 中安装或配置。若使用 systemd，可在自有私有工作目录生成不启用的候选：

    /usr/bin/python3 -I -S -B /usr/share/local-ops-helper/web-management/profile.py render \
  "${SYSTEM:?set SYSTEM in this terminal first}" \
  "${POOL_ID:?set POOL_ID in this terminal first}" \
  "${STORAGE_UID:?set STORAGE_UID in this terminal first}" \
  "${STORAGE_GID:?set STORAGE_GID in this terminal first}"

    生成不等于安装或启动。只选择终端运行或管理员独立审核的 systemd 方式之一；没有实机登录验收。
