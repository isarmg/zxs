# ZXS 文件、磁盘和备份的四区演示

直接在浏览器打开 [index.html](index.html)。不需要安装依赖、构建产品、启动服务或登录。四区分别模拟辅助工具、ZXS Web、SMB 文件浏览和磁盘位置；它们共用同一份内存状态，不读写真实磁盘。图中的原存储分区用于解释既有演示，不代表[目标磁盘布局](../docs/file-only-migration.md#disk-target)已实现。拖动分隔线或用键盘调整大小。

## 可试的操作

1. 在 SMB 打开示例中的 `project.zxs`。它是一个普通 FILE，初始示例文本甚至不是 ZIP。编辑器只改它的正文，不展开成员、不替它保存目录结构。
2. 选中报告并改名，查看 FILE 的历史内容。容器显示当前名称，正文叶保留各自创建时的名称。切换同一 FILE 的历史版本不改写另一 FILE。演示从**已明确提交**的文件开始；示例的自动开关不是新池产品默认值。
3. 关闭文件的自动开关，保存两次，再显式提交。保存时可以读工作稿，提交前历史节点数不增加。历史版本、标签、复制出的新身份和软删除后保留的原身份可以分别查看。
4. 在普通文件夹间剪切/粘贴或 Ctrl/Command 拖动复制。复制取得独立容器；同盘移动保留身份。重名、离线和未知来源都不自动覆盖。删除区只读，移回普通文件夹才恢复可写。
5. 在辅助工具配置 B 的直接来源为 A，创建计划并依次推进复制、校验、决定和安装；可在中途模拟故障。再将 C 的来源设为 B，查看 C 保留的递归来源及同一 FILE 的完整版本。这个过程使用独立的 JSON 副本，不是磁盘持久化或真实 Samba 验收。

状态默认只在内存中。可以把当前模拟保存到本浏览器，或导出 JSON；不接受旧示例状态，不迁移或删除它。快捷键只在 SMB 文件区处理，不读取系统剪贴板。不要输入真实凭据。
