# 演示功能矩阵

“可操作”表示页面按钮改变同一模拟状态、其他区同步，不是静态图或已上线能力声明。
所有功能均只作用于浏览器模拟；无 ZXS 生产依赖。

| 领域 | 可操作内容 | 模型边界 |
| --- | --- | --- |
| 四界面 | 四区联动，三条独立分隔线、键盘、触屏事件、复位 | 不是四个真实服务 |
| 磁盘 | 登记、唯一名称、稳定 UUID、层级、容量、组件上限、改名、断开/重连、损坏/校验、注销 | UUID/序号是演示生成值；真实挂载、clone UUID 与 inode 检验不执行 |
| 三根与三份管理数据 | common-data/deleted-data/zxs-data，双管理分区，SYSTEM/DISK/FILE 投影 | 树中数据库为职责投影，不运行 SQLite、quorum 或磁盘同步 |
| 备份拓扑 | 1–32 层、紧邻来源、扇出/汇聚配置、明确目标、来源名+完整 UUID | 每次明确选择一个目标，不按候选数量自动复制；生产备份仍最后开发 |
| 全量备份迁移 | 完整容器/目录仓库单位、嵌套仓库同盘、工作稿与历史、递归来源链 | 保存完整 JSON 材料而非真实磁盘字节；不表示加密校验成功 |
| 迁移状态 | 计划→复制→校验→决定→安装、容量拒绝、来源变化围栏、中断恢复、决定前取消 | 阶段按钮模拟后台调度，未实现真实崩溃和原子发布 |
| 磁盘改名 | 下游组合目录由稳定来源身份重新投影，所有层可见名称联动 | 不跑跨盘原子 rename 与离线安装协议 |
| 名称 | UTF-8 字节、目标上限减16、保留名/字符、大小写冲突、完整路径预算 | 模拟组件上限由用户输入；Unicode 采用浏览器 NFC+小写，不等于产品固定 casefold 表 |
| 删除命名 | 2位盘序号+类型+7位UTC日期时间+5位标识+连字符，共16字节 | 5位用确定性独立序号，非密码学随机源；完整身份不从名字解析 |
| 普通 SMB 目录 | 多盘、嵌套/空目录、新建、改名、同盘移动、复制、删除 | 已初始化仓库需明确撤销；跨盘整目录使用完整单位方案，普通跨盘递归搬移不冒充实现 |
| 普通 SMB 文件 | 新建即容器、改写、复制、同盘保身份移动、跨盘新建目标并软删源、改名、软删除与恢复 | 目标独立容器仅含当前正文、不继承源历史；原盘历史仍引用原容器 |
| 身份 | 同名/同正文不归并、删除后同路径重建独立、未知来源导入独立 | 不猜测 SMB 客户端意图；操作按钮本身是明确事实 |
| 文件历史 | 内容变化才节点，A→B→A保留过程，历史选择、命名分支、改名、显式采用另一分支正文、节点标记 | 合并是用户明确采用另一正文，不实现自动文本冲突合并 |
| 最新名称与标签 | 容器/SMB/内部版本同一最新名；容器标签跨节点分支统一 | 快照逻辑路径固定；worktree 改名不反向重命名外部容器 |
| 手动提交 | 默认自动、容器级切换、共享工作稿、保存不动HEAD、显式提交、丢弃、脏稿阻断切换 | flush/close抽象为保存按钮；不运行真实SMB写句柄协议 |
| 内容树和事件轴 | 内容父边标识、最长因果路径分行、操作点/贯穿虚线、下方小号浅色说明、点选 | 分支列为显示布局，父边以稳定ID注明；无大图分页/虚拟滚动/生产布局精度验收 |
| 目录初始化 | 在任意普通目录显式添加.zxs，无自动首节点，可嵌套仓库 | 不使用旧目录Git staging/子提交引用语义 |
| 快照 | 完整当前SMB正文和空目录，包含子仓暴露正文，不含容器数据库/标签历史 | 仓库与worktree固定归属磁盘ID，只引用同盘容器；未提交文件工作稿先明确处理 |
| 目录分支 | 从当前HEAD建命名分支；历史worktree提交按当前HEAD续接/分叉 | 不直接把历史节点checkout覆盖原目录 |
| 仓库撤销/恢复 | .zxs整体留存deleted-data，原文件和子仓不动；新仓不同身份；冲突恢复拒绝 | 有活动worktree先明确软删；恢复选择不覆盖当前仓库 |
| 稀疏worktree | 初始空目录、不可变映射、仅修改落盘、多实例、001–999、同父命名空间冲突 | JS单线程串行分配，不模拟多进程真实预留锁 |
| worktree文件操作 | 新增即时容器、改写、删除、改名/移动、子目录新增/移动/删除、复制/移动出去 | 导出创建独立容器，不把原历史快照当可变文件；没有拖拽原生文件管理器 |
| worktree移入 | 同盘移动映射原容器；跨盘移动在目标deleted-data建独立容器并软删源；复制/未知新建独立容器 | 同节点不同实例的同名导入各自独立；跨盘不直接引用源容器 |
| worktree提交 | 修改MOVE、未改COPY，完整新快照，SMB结构不变，稀疏层清空 | MOVE/COPY是模型归属与日志，不执行OS系统调用 |
| 容器同步 | 按同盘稳定身份及来源节点更新，包括同盘其他目录/删除区；历史分叉 | 跨盘引用先拒绝；权威模拟物理删除后跳过；离线/损坏阻断，不误判消失 |
| worktree软删/恢复 | 先文件提交，无目录节点；保留编辑/发布基线；恢复幂等、名字重分配 | 手动文件模式与目录提交/软删的未决边界明确标注，未擅自覆盖产品决定 |
| 管理员物理删除 | 删除区容器可确认物理移除，快照独立保留 | 仅演示；没有真实数据删除权限含义 |
| 会话与示例持久 | 模拟登录/注销管理入口、保存状态、冷重开、导出、重置 | 不是安全隔离、CSRF、真实账号/密码系统；JSON仅导出，旧格式不迁移 |

## 不以示意冒充功能

真实硬件访问、Samba ABI/网络协议、文件句柄与并发写、密码安全、完整BLAKE3校验、
数据库格式/三范围权威协议、掉电/fsync/锁与共同决定、真实多机备份、Foreign外来链
准入与权限迁移、性能/分页/大文件资源预算，不在纯前端实现中成立。
相应页面提供的是可交互的业务状态、拒绝条件和位置变化。尚未决定的产品规则保留为
显式限制，不通过恢复旧目录Git或非容器兼容路径填补。

浏览器交互已核验：四区启动、创建稀疏worktree、修改正文、提交后MOVE/COPY日志及内容节点
联动。正式模型行为套件交由GitHub定向执行；以准确提交的CI结果为准。
