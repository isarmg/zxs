# 界面基准与复刻边界

基准为 `77dbd4f58d1bfb90c1b50797e2ea90f1775ae3de` 的主线源码。当前只有云浏览器，没有连接 Windows 桌面，也没有已确认运行的 ZXS / helper 实例，因此本版本是**源码对齐**，不是逐像素验收。

## 已采用的具体来源

- 辅助工具：`helper/web/index.html` 的主页面静态标记、卡片顺序、表单、警告和按钮文字；`helper/web/console.css` 的颜色、间距、字段网格与卡片。页面标记内嵌于单文件，运行时不加载产品脚本、接口或资产。为防止误填，密码和上传输入改成明确标注的演示字段。
- ZXS Web：`src/web/src/ui.rs` 的八项导航；`src/interface/src/components/shell.rs` 的品牌和顶部导航结构；`src/web/public/styles/tokens/tokens.css` 及 `components/content-blocks.css` 的白灰内容块、无填色按钮风格；`src/web/src/files/view.rs` 的文件和磁盘表；`src/web/src/files/detail.rs` 的位置、类型、备注、文件分支与版本历史布局。
- SMB：按用户最新允许自主设计的地址栏、侧边导航、名称/类型/大小表。保留资源管理器式操作习惯，不追求 Windows 实机像素匹配。
- 物理布局：原有独立状态模型的目录树。没有独立的“实际 ZXS 物理布局 Web 页面”，它是只读模拟，不冒充文件浏览器或硬盘读取。

## 操作界线

辅助安装表单提供可点击的“核对 / 确认 / 原请求回执”演示状态，不执行包管理、账户创建、服务启动、凭据保存或磁盘写入。回执明确包含 `simulation: true` 和 `real_system_changes: false`。可操作的磁盘与内容流模型独立放在“演示扩展”。

ZXS Web 文件详情中“浏览分支”只改变预览，“设为默认分支”才改变共享视图。文件备注是独立界面示例。完整文件容器、工作稿、目录快照、worktree、备份、故障流程继续由原模拟模型提供，在“演示扩展”中保留，没有宣称这些目标已在生产主线全部实现。

## 仍有差异

- 未嵌入超过 10 MB 的 ZxsUI 字体，使用系统等宽字体；未还原运行时 G4 轮廓几何，图标使用可读字符。
- ZXS Web 管理页尚未逐表单复刻，仓库、备份、恢复页明确引导到独立演示扩展，不伪造已实现界面。
- 辅助工具没有真实宿主探测，安装步骤的回执只是演示，不能作为安装完成证明。
- SMB 文件编辑器和完整操作抽屉是演示交互，不是 Windows 资源管理器自带文本编辑器。
- 现有四区同步、分隔线拖动/键盘、完整模型均保留。目标是持续补齐源码界面，不以本轮主壳对齐宣布“一模一样”。
