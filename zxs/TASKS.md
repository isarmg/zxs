# ZXS 交付与验收台账

以[顶层设计](ARCHITECTURE.md)为准。这里记录还要交付的业务和验收证据，不把源码、定向执行、实机验收、发行混为一谈。当前基线 `8d1ad744` 只完成下表提到的本机空池登记源码及静态复核；**本次重构未运行构建、测试、服务或真实磁盘实验**。

| 顺序 | 应交付的正常路径 | 哪些事实才算验收 |
| --- | --- | --- |
| A 新池与原始登记 | 本机维护主体，SYSTEM、普通 FILE 根、专用回收根；只读检查、显式初始化、相同原请求续作/查询、独立核验实际卷。源码：`src/pool.rs`、`src/pool/format.rs`、`src/fs/`，相应用例在 `tests/unit/`。 | 源码已静审，未执行。待在两个支持所需 ABI 的真实文件系统上验证：不支持的挂载、未知内容、伪造旧格式、缺失标签、同名替换/可复用 inode、同步失败、错误角色均不改变其他原件。每个中断点应区分“知道原结果”和“现在能使用”。 |
| A 既有普通卷管理 | 独立增加/启用/停用/计划离线/注销，原请求绑定实际 UUID、角色和代次。允许配置的卷显示名或前缀只作 SYSTEM 别名，不改卷身份证明、BODY 或原回执。 | 在两个真实普通根上分别验证：A 停盘只看经授权的既有元数据、不打开 A 正文；A 注销后同名新建不应满足旧选择，B 的当前 FILE、历史和目录续页仍可用。根放置规则只影响新创建；配置成功不是文件搬移。 |
| B 普通目录、FILE 首稿 | 空目录/嵌套目录有稳定身份。空 FILE 分配 FileId 而无首节点，手动模式默认；新建、重开、保存、读取。密封 HTTP 上传才可顺带创建绑定原请求、原正文和实际父目录的隐式父项。 | 同名或同字节的两个 FILE 不串用锁、分支或正文。普通改名/同卷移动不改创建时的历史正文名；检查名称字节限额、Unicode/大小写等价、权限/目标被替换。覆盖空稿/旧版本，跨进程读取，断连、重试和冷重开。 |
| C1 正式历史 | 分支、选择代次、独立完整 FULL、节点、标签及独立路径事实。已有节点合并复用原 NodeId；保留输入和单独合并事实，不造“元数据节点”或父边。 | 默认/手动模式的首节点只由显式提交产生。明确启用自动模式的无首节点 FILE，也必须针对准确已保存 revision 通过独立的正式决定，才有首个 FULL 节点；写入、flush、close 或确认稿均不等于建节点。历史跳转、页签/过滤、权限变化和原游标冷重绑要可核对；分别量测冷首屏、换 FILE 和热续页。 |
| C2 共享稿与自动提交 | 已确认随机区间、覆盖/追加/截断、基准和当前长度可复验。脏稿切分支/节点/模式须保留或拒绝。自动须显式启用，滚动 60 秒第 21 个不同成功 revision 先落稿再锁存保护；解除需当前 epoch 和 revision，不补积压。 | 跨进程读取最新已确认区间；分别验证真实增量占用、独立 FULL 合成的峰值空间、并发句柄和中断重开。已决定旧 revision 不清新稿；目录/时间只计在原目录真实自动发表的节点，并按当前授权过滤。 |
| C3 用户明确 COPY、只读导出 | COPY 是新 FileId 的独立历史，不是 MOVE。源版本序号、正文与原回执不变，目的容器由本次决定产生；可携带历史/审计导出只产生所选输出。 | 缺正文、缺稿基准、来源/授权/容量不明时，必须在创建输出前拒绝。准确核验非 HEAD 版本、原始来源、目标冷开；丢响应仅查原请求，不复制第三次或日后自动回源。 |
| D1 真 MOVE | 同卷不覆盖原子改名；跨卷保留同一 FileId、全部历史/工作稿和单一归属。完整目标核验并同步，唯一 SYSTEM 决定，原名不覆盖安装，重开目标后再退役精确源。 | 分别覆盖原保留前、部分传输、已同步未决定、已决定未安装、已安装源未清理、响应遗失。未决定源不动；决定后不退回源服务。占用、离线、空间不足/目录关闭错误范围准确，不能用普通 COPY 或同卷成功替代真实跨盘。 |
| D2 回收、撤销与永久退役 | 软删将原容器移入唯一回收根；还原须有实际可用普通目标，原名被占用不覆盖。普通文件夹批量回收/恢复保留空目录和真实组织关系。永久版本退役另走明确授权。 | 单文件、整批、撤销、永久退役分别核对原主体/删除操作、范围外引用、分页及准确重试。整组未安装齐不能逐件显露；未知或离线不等于删除。临时上传不进入用户回收；逻辑不可见不是物理退役。 |
| E1 HTTP、Web 与 SMB | 普通新建、读取、保存、改名、移动、回收/恢复走同一主体和命令。Web 区分标签、当前/历史、登记成员、遥测的空/零/失联/未验证；SMB 默认与命名共享绑定实际 EntryId/FileId/选择代次。 | CSRF、会话撤销、跨页竞争、迟到响应/重登、慢客户端；共享访问锁、只读、等价名互斥、权限及游标重绑。保持原句柄的追加/截断/flush/close 含义；真实浏览器、真实 Samba 和客户端各留证，进程内分发不替代。 |
| E2 密封上传与安全关闭 | 上传、密封、稿保存、正式发表分开。关闭先停新准入，排空已受理的 HTTP/SMB、传输和维护，之后才释放 SYSTEM 写锁。 | 冷开只清理证明属本次未发布且确实不完整的暂存；保留完整正文、已确认稿、其他上传和未知材料。分别覆盖连接慢/断、队列中的请求、超时、关闭/同步失败，按原任务续作而非新任务。 |
| F H01–H06 管理与恢复 | 首账户/丢凭证须有实际本机维护授权与精确 SYSTEM；维护互斥、同源管理、真实管理员/SMB 凭证重置和会话撤销。外来卷默认只读，明确接收须另验原盘、目的授权、身份/同名冲突、完整材料和冷开。 | 单盘只能证明本 FILE 的可读原料，不恢复全局权限或最后归属。正常重建要求完整原 SYSTEM 前沿和确切 FILE；损坏、缺件、非原决定、意外尾、空间/页（或等价检查点）上限、FD、fsync/关闭失败逐项验收。外部命令结果未知只查原操作。 |
| G H07–H08 工程与发行 | Debian 13 amd64 离线安装、非 root 账户、同一构建来源的服务/Web/VFS、配置保留与服务交接、损坏修复。 | 签名、校验、依赖/源码/许可证与交付制品对应；不能拿相同版本字符串当同次构建。契约、确定性、最大规模、目标设备掉盘/断电和发行分别记录准确提交、筛选、用例数和未运行原因。 |
