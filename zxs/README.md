# ZXS

独立的 Linux 文件容器存储项目。这个目录有自己的 Rust 包、锁文件及源码；不导入同仓其他项目，也不需要它们的构建产物。原生接口只使用 Linux 系统调用和 C 标准库。构建输入为 Rust 1.100.0、目标 Linux 的 C 编译器及归档器；不需要从包仓库下载依赖。

## 此批源码提供什么

`zxs check-new SYSTEM RECYCLE FILE [FILE ...]` 对**已存在、明确选择的空目录**做只读检查。示例参数顺序：`zxs check-new /mnt/system/zxs /mnt/recycle/zxs /mnt/data/photos`。输出是当时观察到的角色、路径和目录身份。它不创建目录、初始化池、迁移旧格式、移动或删除数据；没有挂载、格式化或自动发现行为。

- SYSTEM 和回收盘都必填，至少有一个普通 FILE 存储根。回收盘不能与 SYSTEM 或任一 FILE 根位于相同文件系统；两个普通根不要求采用不同后端。不同 `st_dev` 只证明文件系统标识不同，不证明硬件或控制器冗余。
- 每个路径必须绝对且规范。逐级用 `openat` 打开目录，不跟随符号链接；拒绝同一目录充当多个角色、互相嵌套或在检查中被替换。被选根须属于运行账户，不可由组或其他用户写入。
- 从已持有的目录描述符读取目录内容及 `user.zxs.volume` 静态卷身份标记。任何已有内容/已有标记均不视为新盘。不支持查询该属性、观察不完整或目录正被独占使用时直接报错；不降级为按路径相信、不清理任何内容。
- 共享目录锁只在这次观察期间有效，不留下锁文件。该报告不是后续写入许可：初始化必须在其自己的独占持有与原始登记决定下重新检查。

新产品目标是一个 FILE 只有一个持久容器；文件数据和历史在容器内，全局归属在 SYSTEM，删除进入专用回收盘。**本批只有新盘检查源码**，尚未提供初始化、容器读写、移动、恢复或网络服务。
