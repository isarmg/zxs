# 通用介质：账户、共享和许可的同一确认流

这是库内只读组件：从明确选择的 SYSTEM 和预期 PoolId 核原首设、普通账户、发布的普通卷根共享及对指定账户的授权。独立验证口令并观察授权范围，并可用已确认的出生记录核普通根中实际空 FILE 的成员元数据，不是网站、Samba 会话、文件读写或任何发行端。没有默认共享；首管不会自动获得文件权限。初始 [GENESIS](portable-storage.md)、卷标和零下界不变。

- `REGISTRATION` 终身不替换，生命周期 SH 先锁原普通常规文件，短暂锁同一 S 后读取；验证第 0 行的真实 S、当前 storage UID、组件预算、原 103 B 卷标以及同切面的 `CONFIRMED`。此观察不跟随任何其他卷路径，不要求 R/F 在线；不可辨的整池副本不自称唯一原件。目录只容许原 `REGISTRATION`、`CONFIRMED` 与原卷标三个控制项。同一打开的 REG 可接续确已确认的新决定；内容或原下界变化时重新核整段原链，要求严格延伸这次观察已见的最新 (seq,累计字节,D)。不同 REG inode、未知后继、倒退、同序换下界或将新下界原位写进仍持有的旧 CONFIRMED inode，不能沿用旧权限；较高水位须换成本次新普通文件。这是热端对仍持原件能做的核验，不倒推冷介质早先如何改名。
- 所有整数大端。`B||G` 之后逐个决定：`"ZXS-PORTABLE-1/DECISION\0" | total:u32 | pool:16 | seq:u64 | previous:32 | kind:u8 | OpId:16 | request:32 | body | D:32`。total 含魔数与末尾摘要，最小固定外壳 165 B，每帧最多 4096 B。D 是本帧自魔数至 body 末字节的 SHA‑256，不是含末尾 D 的二次散列。第 1 帧 previous=G；后续必须为直接原前一帧 D。完整下界照原协议为 `"ZXS-PORTABLE-1/CONFIRMED\0" | G | seq:u64 | GENESIS 之后累计帧字节:u64 | head:32`。共用容量为 8192 笔、8 MiB 帧字节；不是版本代数上限。
- 第 1 帧必须是 kind=9 的首管，且从完整原历史证明从未首设。body=`profile:u8 | AccountId:16 | operator_ref:16 | login_len:u8 | login | salt:16 | argon_tag:32`。profile 必须在这次离线维护授权中明确选定：`1` 管账户、发布共享、管理读权限；`2` 另可管理写权限。两者均不授本人 FILE 权。request=`SHA256("ZXS-PORTABLE-1/FIRST-ADMIN\0"|pool|OpId|从 profile 到 login 的确切字节)`，不含口令、盐或验证值。缺 profile/未知值、保留窄权限原请求而改宽，或二次首设一律拒。没有未发行格式的兼容、升级或默认；维护关联号不是授权。[密码验证和依赖](first-account-v1.md)独立于数据权限；仅通用族签账号事实，旧空池读取器不会解释账户帧。
- 只承认完整且被这个下界准确确认的前缀。部分首帧、帧已写而仍为零下界、任一额外（即便完整）未确认帧、未知种类、陌生侧件、重复首设、旧前缀替原件均拒；不得返回上一次成功结果冒充现在。原 Op 查询只给非秘密账户身份与原决定摘要，不吐 salt/tag，也不接受口令作为查询条件。账号和共享查询彼此独立；普通根 FILE 出生见下节；后续放置和自动 SAVE/任务仍须在这一个原决策流中衔接；可解卷标、匿名句柄、单独的物化读回及首管角色均不发 FILE 权限。
- [两组固定向量](../tests/vectors/portable-first-decision-v1.txt)基于同一四根 GENESIS、公开演示账户，分别展示 1/2 两种首次设置（不是在同一池先后执行）。两帧各 258 B，下界各 105 B。未运行。helper 当前仍不签账户或恢复这些决定；有未识别尾不能当作空池。

## 普通账户与普通卷根共享

- kind=12 新建一个**无管理资格**的普通账户。body=`当前管理者 AccountId:16 | 其凭据决定 D:32 | 新 AccountId:16 | login_len:u8 | login | salt:16 | argon_tag:32`。request 使用域 `"ZXS-PORTABLE-1/ADD-ACCOUNT\0"`、pool、OpId 与 body 中除最后 48 B 以外的原字节。新账户 ID/准确登录名必须在已确认前缀中均未占用；身份/名字不同即不能凭另一人的 grant。无默认数据权限，不能任命自己作管理者。口令核验只用原账户的一份有界验证值；写端将来为每次真正首次设密取得独立随机盐。
- kind=10 只发布新的逻辑 ShareId，根须来自同池已登记普通卷；并未创建网络共享、改权限或启用 SMB。当前唯一已知管理主体必须对应本池已确认首管；以管理能力作此操作**不等于本人可列/读**。body=`管理 AccountId:16 | 其当前凭据决定:32 | ShareId:16 | 根端点标记0:u8 | 原普通 VolumeId:16`。请求摘要为 `SHA256("ZXS-PORTABLE-1/PUBLISH-ROOT-SHARE\0"|pool|OpId|整个确切body)`。本片不处理撤回/变更共享路径，不把重复发布当作改址；将来改址须新决定并使此前发布的授权失配。
- kind=11 设置某个确已存在的账户对**该发布决定**的 ACL。在上项五字段之后加 `该次发布 D:32 | 目标 AccountId:16 | 前一 grant(0 或 1+D:32) | 权限位:u8`，请求域 `"ZXS-PORTABLE-1/ROOT-ACCESS-GRANT\0"`，其余算法同发布。位值：1 遍历/列举，2 读当前，4 读指定正式，8 创建，16 保存；非零须含 1。任何改动写位（增加或撤销）均须首设 profile=2；自己有数据权限不等于可批准授权。0 撤销已有授权并留下真实前驱，拒重复/no-op、未知位、错前驱。后续事务须额外验证确切共享/父、对象、权限与当前放置；本片只是匹配所求动作，不会写文件。
- 库在 REG 原 OFD 持 SH 的期间，从同一前缀选准确登录账户，放掉短 SYSTEM 锁再作原 Argon2id 核验，随后重获当前切面核同一账户/凭据 D。未知合法长度的名字通过同一受限 KDF 路径后拒。打开和使用授权选择都核账户＋发布 D＋该人授权 D；不相干的已知授权决定不使它失效，撤销后给同一人重新授相同位也不会复活旧选择。单独的授权观察只报告所选普通 VolumeId；实际 FILE 查询还需下列原出生及物理核验。没有网口、正文或任务发行；SID 绑定、禁用/重置、账号与共享的真实修改发行端另待实现。

## 普通根中的已确认 FILE 成员

kind=13 是根级 CREATE 的结果，不是 SAVE、正式节点或自动任务。请求部分为 `创建账户:16 | 凭据决定:32 | ShareId:16 | 发布决定:32 | 授权决定:32 | 普通根标记0:u8 | VolumeId:16 | name_len:u8 | 原UTF-8名字`。摘要域为 `"ZXS-PORTABLE-1/CREATE-ROOT-FILE\0"`，接 pool、OpId、上述请求字节。body 末另存原发行的 EntryId、FileId、HistoryId、主 BranchId、私票（各16 B）及成功槽序:u8。首次出生没有正式节点；手动为默认。原账号在**当时前缀**必须具备对这次发布及该根的 CREATE。从每个普通根自己的原标开始累计必需终名和外部头链接，计每名的长度字节；原槽与当时必有的低槽也须能放下。目录真实枚举上限为 8192 项/512 KiB，先碰任何一条都不再接新的原出生。最低占用的冷核不能取代发行前对当前实物、余量与各槽的复核。全前缀防重用同种业务 ID、原操作与已发私票；同一普通根、准确原名只占一个成员，不按共享复制名字表。不承认未实现的子父/移动/工作模式或业务帧。

普通根含标准卷标和实际业务容器。一个 FILE 只增加一个外部普通硬链接：容器内 `FILE` 原头的第二个名字是其确切父下 `.zxs-new-<当前放置Op>-7`（出生即 CREATE 原 Op）。头的原字节为 `"ZXS-PORTABLE-1/FILE\0"|PoolId|创建Op|EntryId|FileId|HistoryId|BranchId|name_len:u8|原名`；后续放置不改头。实际打开核真父、确切大小写、同挂载、0600/属主、两个名字和本次持有的同一件。私票另行签出，其合法较低空目录槽不是常驻普通文件，更不收养、清除陌生物。仅一个名字复制或同字节换容器拒；两名及整个介质同时克隆/协调回退不能用这点识别。硬链接只在本地同一文件系统内成立，绝非跨盘原身份。

列举和指定目标均以**当前查看者**现时的原账户、共享及授权决定，核该普通根原卷标/成员/实物，再核当前切面。原创建人的权限之后被撤销，不使 FILE 对其他有权者消失。出生已确认而安装未齐时不能给完整空表。每次列举只在同一普通根首尾取直接名录，逐对象验原头，既不读正文也不探离线回收卷。本片没有建 FILE、签 SAVE 或直接发后台额度的生产写入口。
