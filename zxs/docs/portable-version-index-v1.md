# 通用正式版本的直接区间表

这是存储表示的一部分：一个已持有的普通文件足以复原**这一个版本的完整索引**，不必打开祖先节点。它不包含普通用户文件的正文，不能代替 SYSTEM 对“谁发表了哪个节点、当前哪个表示有效”的原决定，更不能单独证明材料在位、其字节正确或用户有权读写。当前仅有内部源码和未运行的源例；旧介质没有这个新字段，不因解出一张表就接纳新格式。

## 规范字节

全部计数/偏移是无符号大端，ID 是原始非零 16 字节。不存路径、当前 HEAD、上代文件名或文件系统专有数据。确切布局依次是：

- 27 字节 ASCII 域 `ZXS-PORTABLE-1/RANGE-INDEX` 含一个末尾的实际零字节。
- PoolId、FileId、NodeId、VersionId，随后为表示代 u64、逻辑正文长度 u64、材料数 u32 和区间数 u32。表头共 115 B。
- 每个材料声明为发行 OperationId、该次发行的 slot u32、该不可变数据材料的实际长度 u64：每项 28 B。材料键属于本 FILE，不能把另一个 FILE 的材料或同样的 SHA 当作这个原材料。同一原材料至多一项，按区间首次使用的顺序排，必须全部实际使用。
- 每个区间为累计排他终点 u64、材料序位 u32、该材料内起点 u64：每项 20 B。从 0 开始无缝覆盖至逻辑终长，终点严格递增。序位 0 表示逻辑零，此时材料内起点必须为 0。其余按 1 起编号；读到材料末尾以外即拒。相邻的零段、或引用同一原材料且物理偏移连续的段，须在编码前合并。
- 字节数必须恰为 `115 + 28 × 材料数 + 20 × 区间数`，无填充、尾随数据或自签。空文件要求零区间/零材料。当前内部读码上限是 131072 个实际区间且材料数不多于区间数，不是父代数限制。

原表示的外部描述符还须绑定索引字节数、逻辑长度及对**整份规范索引字节**的 SHA-256。这不是平铺正文的 SHA-256，不在表尾重复，更不等于已经发表。表示代使同一节点早期/后期的物理组织不能互换；原节点身份和原逻辑内容仍要独立验证。接生产时，描述符应来自同一受纳 SYSTEM 原前缀；仅在内存里由待查数据算一个描述符，不能给自己授权。普通 read-at 只把已取过的同一表头与后续字节组成一缓冲，校验通过才交索引；不能先验一遍再从可变文件读第二份表。

[规范样本及拒绝源例](../tests/unit/flat_stored.rs)以四种实际方式区分：原表可在没有祖先文件时重新打开；更换材料键即使逻辑长度相同也不能沿用原摘要；重新给非法字节算摘要也不能把重号、漏号、越界、重复可合并区间变合法；相同字节的别份文件可以得出同一个**逻辑读计划**，不表示它就是可接纳、可清理的原物。真实材料正文的分块认证、原件选择、命名落位、恢复及自动物化是[整个存储设计](portable-storage.md)的另行准入条件。

## 正文与分块证据

每个不可变材料的正文仍是单独的普通原始字节文件。它的原发行记录还应提供与准确材料身份相绑的分块索引承诺；上述整份版本表只给出材料键和长度，不替原发行记录作证。内部普通读件可在同一已选表与这份目录下读出正文；它不选择路径，不证明目录/原登记/用户权限，没有开放新的池或签发命令。

每个材料只配一份普通分块表。95 B 表头依次是 ASCII `ZXS-PORTABLE-1/BLOCK-TABLE` 加 NUL，PoolId、FileId、原发行 OpId，slot u32、材料长度 u64、固定块大小 4194304（u32）、每页 1024 个摘要（u32），均为原字节或大端数。按顺序存每个实际正文块的 32 B SHA-256；末块仅含真实余数，不补零。随后存每页最多 1024 个块摘要的 SHA-256，末页按实长。外部原承诺是 `SHA256(完整表头 || 页摘要目录)`：它经目录间接绑定各页和实际正文块，不是整份正文、整张表或逻辑版本的平面 SHA。空材料只有表头，目录为空。读端按真实大小计算两表确切长度；当前原页摘要目录最多占 8 MiB（一个材料最多 1 PiB 数据），是显式元数据资源上限，不是版本代数。不能表示时不可先确认再降级。

打开精确扁图时只核各材料的原引用，不打开全部正文。每次范围读取先从该表找出相交的不同材料。额度由调用者为本次实际提供：每件另占两个 FD 和它的页摘要目录；选中的材料共用一个摘要页和一个正文块缓冲，按此次相交的最大实际大小计。先核额度并打开所有要用的原件，按原引用核表头、页目录、大小、不同实体，再交付第一个字节。单次放不下或有一对打不开，连开头的零也不交付。一次请求内复用该材料确切 FD，最后 flush 后放掉；另一次请求须凭同一冻结原引用重新取件，不把长寿命句柄变成不断增加的 FD/内存缓存。这里的字节预算不代表整个进程内存。读取只实读相交的摘要页和正文整块：先验手中这一页/块的**同一缓冲**，再取所求区间。零段不打开正文；未涉及的页、块不声称已验证。前段已交、后段校验失败时停在错误处，不重发前段；读后检查及最终 flush 仍在已持材料内。候选块表只写入调用方新建、确空且与源不是同一实体的普通 FD，按偏移写并同步；同一源的另一打开或硬链接在写前即拒，候选本身不授发表。形状和字节不能区分完全相同的副本；真正的注册、所在 FILE、原名与权限必须由外层同一原前缀和根租约提供，不得由回调临时另签。

[普通正文源例](../tests/unit/flat_body.rs)含 `abc` 的 159 B 块表、同字节异材料、零段、跨两件短读、同块范围外损坏、未选另一页损坏、晚段中止、小额度分散读取、候选写入别名及最终 flush 故障。100 GiB 材料有 25,600 个 4 MiB 块，块表主体 819,200 B、25 项页摘要目录 800 B；这是格式算量，未进行测试或测速。

## 同一直接父内打开具名材料

内部读件只在调用方已选的受保护 FILE 容器中查固定角色名。每个实际普通文件有主名和原发行/交接时在**同一目的文件系统**留下的第二个硬链接。两者解决重开后单边同名替换的问题，不是第二份数据、另一个版本或另一份归属决定。本范围的操作全是读取，不新建、不补链、不改权限、不删除。

- 扁平表用 `index-<NodeId>-<表示代16位小写hex>` 和 `pin-index-<同后缀>`。材料后缀是其原 OpId 的全32位小写 hex、连字符、8位小写 hex slot。改变数据主名为 `change-<后缀>`；完整 RAW 仍用原15位 VersionStorageId＋连字符＋本版提交时的原文件名。两种数据各有 `pin-data-<后缀>`。校验表一律用 `checks-<后缀>` 和 `pin-checks-<后缀>`。不从枚举反解 Op、FILE 或版本；绝不将另一个文件的相同 SHA 当原材料。
- 在同一仍持有的父上采一次精确拼写样本。主名、见证各先以不跟链接、不激活设备/FIFO 的句柄检查，两名须为同一普通文件、同一现场挂载、确切长度、服务属主和 0600，恰有这两个硬链接。拿原件非阻塞共享租约后复核，由首次核实的同一 FD 和观察贯穿最后 flush，复核属主/权限/链接数等事实，不用后来另取的 stat 重设基线。每次发首字节及最终 flush 前后均要实际父仍是私有 0700，包括只读零段；不用为此逐块扫描父。每件的两个数据/索引 FD 之外临时开名需要两个额外 FD 的峰值余量；名字、连接数和目录容量另算。所有材料成对之前不输出，零范围不打开材料，这不表示检查原父完全无需临时 FD。不能提供普通硬链接证据的组合不降为按路径或 SHA 读取；现行目录枚举 8192 项/512 KiB，发行时须计入每个独立材料四个名字、每个版本索引两个名字。
- 完整 RAW/校验表仍从同一已签原引用取数据，节点索引也须取其独立原承诺。此组件只验证**调用方所选容器内**的这个关系。若主名与见证被一起重新造，或整套介质被复制，单靠两名/散列不能判断哪个是现行卷。真正注册、FILE 当前放置、授权和活跃的表示必须由同一已确认 SYSTEM 提供；不开放新池、写入、清理或网络访问。[实物源例](../tests/unit/flat_local.rs)只构造普通文件来对照，未执行。

## 逻辑内容承诺，不等于存储位置

新版本单列类型 `LogicalV1`，不能把旧节点的整文件 SHA-256 或材料自己的 `directory_sha` 改名解释为它。同一文件的确认版本将另行绑定其 Node/Version、历史决定、实际材料及索引；内容承诺不授予读取、写入或表示切换权限。

将逻辑字节从偏移 0 起每 4 MiB 切块，末块按实际长度，每块作 SHA-256；每 1024 个连续块摘要组成一页，页摘要为串接各项后作 SHA-256，最后不足一页不补零。再取 `SHA256("ZXS-PORTABLE-1/LOGICAL-BLOCKS\0" | logical_bytes:u64be | 4194304:u32be | 1024:u32be | 顺序全部32字节页摘要)`。域标末尾为一个实际零字节。零长不产生块或页；零洞在逻辑上是零字节。材料编号、物理分段、原 FILE 路径、节点和表示代不混入内容等价关系。它不是无条件对文件字节直接做一次 SHA-256。

当已认证的真实索引**只有一个**偏移零、长度正好等于该原 FULL RAW 整体的非空段时，可核实际命名 RAW/完整块表的原件，重用块表里实际认证过的页摘要算逻辑根。不可从目录摘要值直接推根，不另写同一份摘要表；空索引不证明存在某个空 RAW。另一条显式核验才会按同一真实版本完整读取并逐块校验逻辑内容。元数据相符并不证明后台副本已经逐字节写过、具名后完整读回并同步；损坏的原 RAW 可以有正确的旧目录但整读仍须拒绝。本片无正式发行、无每次 SAVE 自动整读；以父版认证逻辑页和真正变化块增量形成下一版的发行路径另行完成。上述源码/固定向量未运行。


### 自动节点的完整副本：实际复制与读回

[内部物化读写件](../src/ordinary/flat/materialize.rs)只接已经选定的同一 Pool/File/Node/Version/表示代、该节点原 LogicalV1 与本次新建的私有作业目录。本次作业在写入前即固定原 FILE 目录、原表示索引描述符、逻辑内容承诺与可用容量；另一个同长或更大的版本不能先占用它的 RAW。它不负责发票，也不接受任意普通文件或输出流作为目的。普通 `O_CREAT|O_EXCL` 创建新 RAW，已有名字不重用、不截断。按规范扁平表逐段读取经过验证的真正材料，零段也写入实际零字节；不对祖先递归，不使用克隆、预分配或稀疏长度来代替复制。源材料按连续运行段只留当前一对 FD，共用校验页/块缓冲；高度交错的材料可能重复打开，不能将逻辑字节量等同设备实际读取。

目标文件与原作业目录分别同步，持最初写 FD，从准确私名独立再开只读 FD，逐字节读完整文件，重算节点的 LogicalV1。空版本也要建真实独立普通文件并走同步、准确重开与复核。成功结果只针对同一原作业、同一节点/表示与承诺；原位置仍未改变。失败不删除已经确认的形式、源材料或两者的任何依赖；不替拥有者清理私件。这个阶段的源 FD/缓冲预算不包括本作业常驻的目录、写目标、独立读回与原索引；当前只在未运行的源码夹具中可取得新作业，真实原 SYSTEM 作业发行、掉电后的同单续作、落位联接、对外服务均未开放。
