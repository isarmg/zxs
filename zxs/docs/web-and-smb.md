# Web 管理，SMB 传输文件

ZXS 只有两个在线产品入口：Web 管理和内置 Rust SMB 3.1.1 文件访问。二者是同一 `zxs` 程序内的隔离角色，不另装 SMB 后端，不提供通用服务或产品业务 CLI。源内有 [管理 Web](web-management.md) 和 [原站点启动边界](../src/smb/launch/site/CONTRACT.md)；新站点候选中的 Web 只接直连 HTTP 0.0.0.0:8443，不接受旧外部 HTTPS 代理配置。这不是安装、真实客户端互通或正式发行说明。

## Web 的第一条真实路径：登录后查看和管理

1. 浏览器在受保护网络上直连 HTTP 登录，只核当前 SYSTEM 的唯一共同账户、Web 验证器和生效代次，再建立可撤销的短时会话。服务从受保护的配置选原池；浏览器不能提交原生路径、伪造 UID 或以账号名代替授权。后台会话在服务重启或过期后失效；首设/重置不是 Web 登录动作。
2. 只向**唯一 Web 管理员**返回固定账户的非秘密设置、共享配置以及版本元数据（例如节点、父、标签、提交时名称和时间）。磁盘信息与诊断使用 [Helper](../../helper/README.md)。查询和命令都要核本人当前权限、确切的池/对象；版本元数据权限不是 SMB 正文权限，首管也不因此能读全部 FILE。适用的显式版本管理命令独立绑定原操作，重试不重复发表。
3. 共享只显示逻辑标签、VolumeId 与当前停用／只读／读写设置，不以这些字段推断实际物理挂载状态。写管理动作须防 CSRF、处理撤权与并发；回执同样受授权。停机维护、首设/密码恢复和磁盘准备属于独立的离线资格；此前台不安装、操作或依赖系统服务单元。
4. Web 不提供普通文件内容上传、预览、下载、分块转发或临时链接。管理 HTTP 请求当然可以有表单/JSON 并返回页面或元数据，但没有打开 FILE 正文的 handler、静态根映射或兼容 URL。

## SMB 业务入口：一个总目录

只接受原连接上由内置 Rust 严格验证的唯一 SMB 用户，准确匹配受信域、AccountId、当时凭据代和同次安装。guest、匿名、错凭据及拿 Web 会话顶替 SMB 一律拒，不能据此列出共享。另核已启用 ShareId、RO/RW、确切普通卷根或已安装 DirectoryId 与可见成员；不能拿布尔许可按另一个前沿重开。网络请求不直通宿主路径，不用未实现的操作绕开业务核验。

**首装及唯一入口。** 只针对新池。受权维护选择具体 LAN 地址和客户前缀、普通数据盘、目录名、初始模式与独立回收角色，据同一原安装和已确认的 SYSTEM 帐号取得资格，不必另到 Web 发布目录。启动只允许同一私有低权角色使用实际批准地址上的 TCP 445；每条连接仍核其本址批准的前缀。[同一制品的原预备和共同放行](rust-smb-custody.md)不是登录、读写或应用保存的证明。

客户端访问 `\\服务器\ZXS`，每个已选数据盘都是其中一个一级目录；只有这个业务共享，不提供逐盘别名或真实宿主路径。盘、真实子目录和文件的逻辑名均按原 UTF-8 字节区分大小写；同一个普通父下，目录和文件不能占同一名称。Web 只能改变首装已选目录的模式，不在线新建共享。停用或改代不让旧请求/句柄拿到新权限。同树回收目录按原删除单区分轮次，允许枚举、读取和到实际可写数据盘或已发表子目录的原生同树还原，不覆盖。物理 R 从不直接共享；R 暂不可用不拦已验明的普通盘。无通用 IPC/RPC 或其他共享的备用业务入口。

**认证要在真实连接上验。** 用独立无共享凭据缓存的客户端验证：错密码、未知账号及只持 Web 会话不能顶替 SMB；同一共同账户仍须独立完成 SMB 认证；不带凭据的新会话不能枚举或打开共享，也没有可用的匿名管道；有效 SMB 用户只在启用的目录按 RO/RW 准入。实际试验应记录端点、客户端、原制品和协议结果，不能拿配置字、启动回执或其它服务的历史结果代证。

客户端看到业务名和当前内容，不见物理 FileId 后缀。逻辑名字区分大小写，真实客户端须分别列/读 `Report.xlsx` 和 `report.xlsx`，并确认全大写的错拼写不得命中。原会话只持已核的业务对象，不传宿主路径、环境或外部句柄充当权限。

打开持真实目录/正文、工作或历史边、当前位置和 原 S 目录共享锁；按 offset 多次读不能随新版本改换已选材料。正常打开选当前稿，不能因为非空首次工作稿还缺准确的有界随机读，就改读上次正式版本。已有 PublishedVersion::open_listed 是显式固定已发表 Node 的**业务内核**，不是普通 SMB 当前读的退路，也不是网页接口。保留其真实节点、材料校验、范围/空区间、慢流与最终 flush 的原锁。读/写、设置 EOF、追加/裁短、FLUSH、CLOSE 和冷重开各核其原句柄。SMB 协议没有通用的 Ctrl+S 事件。普通 WRITE/SET EOF 只改原写者私有暂存，写者读自己的变化；对端真正成功的脏 FLUSH、需要写穿的写入、或带未确认变化的正常 CLOSE 才是相应确认边界。先按同一旧基线、实际变更和原单持久确认，再给该次操作成功；普通 WRITE 返回接受的字节数不等于发布节点。干净的 FLUSH/CLOSE 不产生新工作修订；已确认的 flush/写穿不释放仍打开的写者席位。不要求客户端提供私有摘要或 OpId。上述 SMB 操作从不发表节点，只更新本轮同一个增量。只有另行明确的手动提交才冻结本轮。断线不是应用的正常 CLOSE：停止准入、让旧写者不能再写并收尾或使已派发的操作失效，绝不把没有确认的暂存谎报为已发表；已提交但丢响应只能按服务端已绑定的原单回查。

## 排空与验收

在线服务含空闲期持续持原 S 目录共享锁；先停管理请求和 SMB 新准入，再排空已接工作、完成必要同步或明确失败，最后释放原物。短 SQL 事务不跨慢客户端 I/O。宿主进程状态不证明原读者和写者已经放锁。

- **保留业务证据。** [原提交回执](../tests/formal_receipt.rs)、[真实父目录](../tests/ordinary_directories.rs)、[删还](../tests/recycle.rs)和[固定历史与交接](../tests/two_increments.rs)按类型调用真实库，分别核确切原件、晚失败、冷开与原单，不再启动旧 argv。它们不证明旧进程隔离或跨进程停机；相关 FD、进程和新 SQLite 的现场验证仍各有独立通过条件。

- **分别验适配。** 浏览器验登录、越权/撤权、账户/共享配置与获准的版本元数据；请求普通 FILE 字节的路径不会给出正文或泄漏原路径。真实 SMB 客户端验同名不同 FILE、大小写、权限、打开/offset/EOF、断连、原材料改变、重开及应用写语义。另有[隔离客户端夹具](../tests/acceptance/rust-smb-client.md)；其外部标准客户端不属于产品构建或运行依赖，也不能代替 Windows、Finder 或 Linux 原生入口验收。

- **离线不走在线命令。** 交付二进制无历史业务 argv、隐藏测试命令或独立 Web/SMB 启动后门。ZXS 承担在线协议、原持有物和正常排空；Helper 独立在停机后核原池/卷/容器和准确原操作。查询不推进写入；维护写必须满足同一原 S 和相应卷的实际独占。首次设置、普通卷运维与凭据恢复的已实现边界见 [Helper 台账](../../helper/TASKS.md)，宿主监督不属于两个程序的安装动作。
