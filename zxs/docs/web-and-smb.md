# Web 管理，SMB 传输文件

Web 和 Rust SMB 3.1.1 编入同一个 `zxs` 可执行文件。Web 提供 HTTP，可由外部代理提供 HTTPS。配置见 [管理 Web](web-management.md)和[站点启动](../src/smb/launch/site/CONTRACT.md)。

## Web 的第一条真实路径：登录后查看和管理

- 用 ZXS 共用账号登录。管理员可以查看账号、共享配置和版本元数据，也可以手动提交版本。会话过期或服务重启后需要重新登录。
- 共享设置只适用于首装时登记的数据目录，支持停用、只读和读写。文件正文由 SMB 访问。磁盘状态、首次部署和离线维护由 [Helper](../../helper/README.md)负责。
- 修改共享和版本提交时核对当前授权及原操作；失去应答时查询原回执。

## SMB 业务入口：一个总目录

- 首次部署新池时选择监听地址、客户端网段、数据目录、初始模式和回收盘。服务在批准的地址监听 TCP 445。
- 客户端访问 `\\服务器\ZXS`，各数据盘是总目录下的子目录。使用共用账号完成 SMB 签名认证；匿名和访客禁用。未启用的目录拒绝访问。
- 名称区分大小写。同一目录中，文件与子目录共用名称空间。回收站支持枚举、读取、移回可写数据目录；还原不覆盖。回收盘暂不可用时，已核验的数据盘继续使用。
- 每个文件允许一名实际写者，仍可打开读句柄。写入先进入暂存。有未确认改动时，成功写穿、脏 FLUSH 或正常 CLOSE 确认工作稿；断线不确认暂存。正式版本只在 Web 手动提交时生成。
- 查看[共享准备与放行](rust-smb-custody.md)和[固定版本与工作稿](portable-storage.md)。

## 排空与验收

停机先停止接收新请求，再排空现有工作，完成必要同步或保留原失败结果，最后释放原系统盘的共享锁。Helper 写入维护前须独占原池及对应卷。

相关用例：[提交回执](../tests/formal_receipt.rs) · [普通目录](../tests/ordinary_directories.rs) · [回收还原](../tests/recycle.rs) · [历史与增量](../tests/two_increments.rs) · [其他用例](../TASKS.md)。
