# 普通空目录与导航：N1 设计边界

> 以下 N1 原帧只描述既有实验；保留普通父、跨类型撞名、未安装不可用、不接管他物的要求，不再签发该类自研帧。 当前权威见 [SQLite SYSTEM](sqlite-system.md)。


面向用户的文件目录 I/O 由 SMB 承担，Web 只做管理；本文的本机调用指过渡验收驱动，不是产品 CLI。实现与断点用例均为源码；未构建、运行或完成实盘验收。

目的：能在一个已登记的普通数据卷里创建、查见、进入真正的空目录，并在其中再建目录。目录不是 FILE，不产生 FileId、工作稿、分支、提交、隐藏管理文件或另一份业务索引。N1 只负责目录及导航；[N2 本机接口](files-in-directories.md)另行支持在已安装的普通子目录创建或搬入 FILE。目录递归删除、改名、整组回收和网络权限仍不在这两片范围内。

**寻址。** 目录父选择为注册根 Root(VolumeId) 或 Child(DirectoryId)。根只由 SYSTEM 的原卷登记标识，不伪造 mkdir。每个真实子目录有 DirectoryId、独立 EntryId、同一普通 VolumeId、准确父、规范原名、父的原登记/目录决定及创建时原生实体 (FS 生存句柄 + 设备/inode)。父结合自己的原父决定逐层到确切根；根、普通目录、FILE 容器和回收区不能互换。单组件按[存储命名](storage-names.md)保留原 UTF-8；业务与物理占用分别核对，不折叠大小写；不接主机绝对地址、.、..、符号链接、子挂载或文件后缀推断。深度/总路径/最坏临时名按已有硬门逐个检查。

**两条本机业务命令。** dir-mkdir <Op> <SYSTEM> <普通卷> <root 或 DirectoryId> <name>；dir-list <SYSTEM> <普通卷> <root 或 DirectoryId>。逐层导航用上一层返回的稳定目录 ID；混合列出本层的普通目录和业务 FILE，两种条目类型显式，每项返回真实 EntryId 以及本类型的 DirId 或 FileId。原 file-list 仍返回根级 FILE，但用同一真实双类型库存核验，不能因新出现合法目录而失败，也不能把未知普通目录跳过。一次列举不递归扫无限子树，遵守名称/字节数/FD/深度上限，释放原柄前重核同一父及所选项。只访问所选普通根；失联是 unavailable，历史原请求可读不等于现场空。未有带权限与冻结名录的真实分页前，不宣布有分页。

**一个原决定。** 普通目录只用原 SYSTEM REGISTRATION 的同一确认下界、排他的全池原票和原帧序列；不是第二个目录数据库。原帧绑定池/操作/维护主体、父的确切地址、规范请求、原父实体、稳定 EntryId+DirectoryId、实际签发的私槽与新生目录实体；有界编码 ≤4096，保留每张未恢复原删除的独立还原额度。不得用时间、同名、inode 号码单独或重新扫描推定绑定。新请求和每次恢复都正面核准 ordinary 角色、同一条实际父链以及不覆盖/等价名占用；父目录错位或无单个原件，保留状态、拒绝借同名替身。已发表且收尾完的原操作按 ID、原主体和原请求返回旧回执，不为读回执重新验证现在的名字。不同参数复用 Op 拒。

**物理顺序。** 先预留原票与有界私槽，后在原父下 mkdir、同步新目录及父、把此调用实际持有的新实体绑定原票；中断前未绑定的空私槽只作有界占位数，不收养/不删除。密封后完整确认同一对象仍空、最终人类名称仍空，再追加原帧；在 FrameSynced 回来且下界抬升之前，仍在同一 SYSTEM/卷写租约重新核原票、密封帧、完整父名录、准确持有的原目录及空终名。未确认尾不进入业务命名空间；确定后才在同一父下 NOREPLACE 安装，复核新名下确切原物/同步父。到此才能报告现场可用。决定后晚出同名只可待安装，原项不可换票或降格；不得先把陌生同名、非空私目录、符号链接或伪 FILE 算作已完成。热与冷走同一组阶段。所有名字和原未决私票都带原父范围，同卷同名不同父不互相占用。子目录只是一项经过授权的普通物理目录；不为了给它发次级权限而写上全局业务目录表或卷标签。

**与现有 FILE 共存。** SYSTEM 的同一份位置索引区分 (volume, typed-parent, canonical-name) -> FILE/Directory/在途；真实 FILE 出生、MOVE、原地/显式 RESTORE 和新 mkdir 在根层使用同一逻辑和物理占用检查（包括同名已登记目录位置离线、同名未安装、私槽和旧源待清）；回收物理叶不获得普通父能力。FILE 的原出生、历史与原 MOVE 收据不更改，root 表示既有 FILE 格式的精确含义、不加兼容推断。不得给普通根强加不存在的目录 FILE 或从当前路径补字段。N2 另用真实父引用签发、安装和恢复子目录内 FILE；正文打开和原回执均不靠拼接路径猜父。

**类型、占名与安装的四个反例。** (1) 共享占用键严格不同于来源授权。目标只要有任一真实或待安装类型便冲突；普通 MOVE/DELETE 在源端必须用原受核的 (VolumeId,Root,name,FILE,EntryId,FileId,当前 placement 与实体)，不能以一个“有某个来源”的布尔代替。mkdir 的子父必须属于同一普通根，源于更早已确认并完成安装、当前具名原件可复核的 Directory；具名 FILE、尚未安装或仅保留的目录一律不是父。目录与 FILE 统一去重 EntryId、原操作与私票、已登记的原生实体。用同名不同父、伪报目录为 MOVE 的 FILE 源、同一原名字后来是不同类型/ID 作反例。(2) 已封完整帧但未确认时原父清单没有新 Directory 项，也没有可用子父；原票在该原父继续排他占名。若已决定而未能重开终名，父查询必须显式返回待安装项或整体不可用，不能报告完整空表/可进入；该保留未收尾时新 FILE/MOVE/RESTORE/SAVE/MKDIR 等不借用全池写槽，已完成的旧原收据可读。(3) 原私名与终名同见、已绑定而两名皆无、终名同一原实体但含未签发内容，未证明本次空目录完成安装；绝不静默补建/承认。实际 rename 中断后须认同一原物、补同步确切父、再核空目录与原名，方可完成。目录后来经原决定建孙，老 mkdir 原单只返回其历史空目录创建回执，不再要求今天为空；当前列验的是这一层现在的受权孩子。(4) mkdirat 与重新取得子 FD 不是原子领取新 inode。基于原卷/原父独占维护及只许可信本机主体写的假定，不能宣称抵御同 UID 蓄意换物；不明物绝不冒领或清除。

**该写的验收源码。** (i) 根有一个真实 FILE、一个空目录、两个不同父里同名 child；冷开逐层只列真兄弟，DirectoryId 与 EntryId 稳定，FILE 原历史照读。(ii) 准备前同名目录/FILE、同 ASCII 等价名、未知 FIFO/链接、错卷或父被改名并以等名替换，拒绝而不清理；父路径预算不足在任何原写前发现。(iii) 逐项断在原票、未绑定 mkdir、命名同步、密封、完整帧未确认、已决定未安装、rename→父同步、丢响应；未绑定异物不能认领，已绑定缺件不能另生，迟到竞名热冷一致；已决定晚冲突不得回滚或覆盖。(iv) 既有目标 FILE MOVE/RESTORE/CREATE 和 mkdir 各不借另一种对象的同名；恢复原件时保持专用 R/还原预留/原操作事实，额满后不同事务不借额度。(v) 一卷离线不妨碍另一卷普通 FILE 读及目录导航，历史回执与当前目录可用性用不同状态。这里只列源码验收，不宣称已运行。

后续不同议题：通用多代历史用一份 FILE 内独立、不可变、经 SYSTEM 原决定确切引用的有序历史材料清单，而不是每加 I3/I4 都在帧与状态机加一个字段。先另论历史图、增量与检查点、完整移交/恢复/容量以及有界流式验真；不作为普通目录前置，也不在本设计或代码里提前签入。
