# 通用存储：一次定位到正文，不依赖文件系统专用功能

**实施目标，尚未切换介质或入口。** ZXS 只使用一套普通文件格式。既不要求、也不探测或调用特定文件系统的克隆、快照、子卷、私有 ioctl 或 sysfs；不存在“可选快路径”。Linux 在产品外挂载，ZXS 只用已登记的私有目录。Web 管理账户、共享、系统/磁盘与版本元数据，不传正文；SMB 是日常文件 I/O 入口。helper 独立停机维护；两边不调用对方程序或共享源码。

## 正式版本直接寻址

每个已确认 Node 有不可变逻辑身份：池、FILE、历史/分支、直接父 Node/Version 和原决定、此次 Op、版本创建名、时间、终长和带算法的内容承诺。父边用于历史与准入，**不用于逐代查正文**。无两代上限，不强制作 FULL。节点的一种当前表示为普通完整 Raw＋校验索引；另一种为完整覆盖逻辑地址的**扁平区间索引**＋不可变普通材料，二者都是当时可读的正式版，不是“将来才能读”的队列项。

按逻辑起点严格递增，非空段无重叠、无空洞，刚好覆盖 [0,终长)。每段要么是显式零，要么是同一 FileId 下一个已发行的 **MaterialId、材料内字节偏移及长度**。材料有原操作、不可变长度与分块校验承诺；绝不取名字/SHA 当物料 ID，不合并不同归属的同字节件。相邻零合并，同一材料且物理字节紧接的段合并。零长度有唯一空表。不存在 Parent、某个旧节点 HEAD、路径或“向前找不到就是零”的段。截短裁掉尾；再扩长产生新零，旧父尾巴不复活。

新版本从**实际直接父已经验证的扁平表**复制/分裂所需元数据、切入本次真实改变及准确终长，形成规范的新表。只继承实际原物，不复制父正文来构表。先核资源和边界（含加法、源偏移、成员归属、原材料足长）；提交前同一 SYSTEM SQL 事务中的位置/父与已有原材料重验。读某个正式 Node 时选它自己的已确认表示，按 offset 在有序段表二分或按已验证索引页定位第一相交段；只到实叶，不打开父节点解释器。校验所需索引/页面与实际相交数据块后才交付，不把未读取的正文称已校验。慢读持 原 S 目录的共享 OFD、所选表示和材料读租至最终 flush。大文件总耗时、索引大小、逻辑读取量和盘速是不同概念，没有跑分。

**逻辑承诺与平面 SHA 不混。** 固定“按逻辑位置分块的内容承诺”算法及长度/空版/零区间的域；索引与每个原物另外有自己的摘要。写时核相交旧块、改后块、边界及终长后形成新承诺；不能把父 SHA 和变更 SHA 拼成整文件 SHA。需平面 SHA 才实读计算。物理表示可换，节点的逻辑承诺永不因换文件改义。具体 wire、可恢复的材料身份、限额及公开独立向量需逐项另审，本设计不授权发票。

## 手动与自动各只有一种语义

**手动是默认。** 首次真正改变时固定准确正式基底＋工作代，首次无正式节点用空基底。该轮只建一个逻辑工作稿：一份普通的改动数据文件和对应的可恢复索引，未改区直接引用已核的旧材料。既无同步整份复制，也无后台整份复制。后续 SAVE 持续改这一稿；不复写仍有引用的旧区间；旧修订/读者释放后可复用空间或有界压实，不把每次 SAVE 永久留作一份工作文件。可用有界的局部组合，不能靠未分配磁盘洞判历史覆盖；裁短再扩仍是零。单纯打开、读取或相同字节/终长不产生新节点；0 B 首次独立保存回执、显式提交空 FULL 均保留。

工作读者持本 FILE 的读租至 flush；写者不持 SQL 事务等本 FILE 的独占。在一个活动数据文件里只写上一已确认修订/在途引用没有选中的区域，先同步；SQL 再选择新图。每个工作修订认证原段偏移/有效长度和该范围的分块摘要，末段不因未确认追加而扩大到实际 EOF；冷开不能把未选尾巴当已保存或反过来判原稿坏。其原物/范围规则独立于正式只读材料的全文件长度/stamp 验证。旧段在全部引用退出后才可复用/有界压实。提交时冻结实际贡献的改变材料，不再允许下一轮复写；不后台复制基准，不造第二个就地 redo 决定。

**自动：一次真实改变并确认的 SAVE 就是一笔正式发表。** 新节点在确认前已有同步过、可直接按 offset 读的独立扁平表与真实改变材料，可立即作为下一节点的父。没有“第 21 次只记工作稿”、合并数个已确认 Op、或先报成功以后补 Node；容量/额度不足在确认前明拒。C 后台未完，D 同样可确认。每个未物化正式节点都由同一 SQL 提交建立一项独立的后台任务，不按最后 HEAD 折叠。

后台在不同受保护私名中，逐段读取该节点的完整逻辑内容（含零）并写满一个新的独立普通文件，不以重命名、链接、复制加速系统调用、改标签、或仅验证变化块代替。实际文件同步、具名后独立完整重读，核长度/原逻辑块承诺、准确目标及父同步后，才依原任务和当前放置/表示代改变该 Node 的物理表示。保留原 NodeId/VersionId/父/时间/创建名/HEAD 与原 SAVE 回执，仍是一笔历史；失败/断电保留原表示和原任务，可重做自己的未确认副本。C 的迟到作业不能动 D 的 HEAD；掉线时只给原回执/未知可读性。用十进制容量举例：100 GB 的 FILE 在一分钟内真正改变并确认十次，就有十个固定节点。十次后台物化最终约需 1 TB 逻辑源读＋1 TB 逻辑目标写，另有约 1 TB 完整目的读回及索引/同步；若持续这个速率，仅后台目标写就约 16.7 GB/s。这不是设备测量，也不是要求单分钟全部做完。最新确认节点读不等队列，队列/空间真正满时只在新 SAVE 确认前明确背压，不能吞旧任务、换 NodeId/退 HEAD。后台并发有限；不持 SQL 写事务等待慢复制。不承诺设备实际分配方式、底层压缩或独立物理扇区。

**不能一换 Raw 就删旧材料。** D/E 的扁平索引可能仍直接引用 C 的旧改变材料，即使 C 已切换为 Raw、C 原读者也已关闭。退出集由原 SYSTEM 确认的所有现存节点表示、工作稿及其在途材料、未决交接/后台签票、及活读者的实际冻结引用共同决定；只有准确原物已无上述引用、逐件清退权限成立才可退。若后来歧义/无法证实，保留并报告；孤立统计或文件消失不能制造删除许可。不让签过的 D 从读取“MaterialId X”暗换成“C 今天的表示”。

## 跨普通卷、回收与冷接续

同一普通父域的无覆盖改名要在确认前取得真实两父可安全执行该类切换的证据；不足就**事前**选真 transfer 或拒，不在确认后改票。跨盘以及进出独立回收 R 始终真实流式复制。冻结全部保留的节点/逻辑承诺、原 FILE 与放置/表示代、准确成员表（各节点扁平索引及独特 MaterialId 的集合、完整 Raw/索引、应完成的后台任务）。按原物 ID 去重，只复制真正相同的材料，完整历史绝不按当前 HEAD 的大小算。读一段、建 D 的成本，和跨盘验证及保留整份历史的成本分开。跨盘先以同单具名/独立读回/文件和父同步，再事务切换位置/记原回执，其后才逐件清源。同盘在首个改名前的 SQL 待办已批准准确物理动作，不预报成功；直到名字/父同步与原物齐全后才公布新位置；读者/决定/收尾三态分开。

搬运时已对某自动节点逐字节实写新 Raw、具名完整读回/同步，且其原任务和额度、原表示与目标角色正式绑定在**同一交接决定**，此时可记录该节点物化已成，不再抄第二遍；只复制改变材料、做同盘改名或“刚好有同内容”均不能抵充。专用 R 首版只接满足全部冻结任务/历史条件的完整目的，无证据在确认前拒，不授一般后台 R 写权。跨盘目标可在源离线/待清时独立读已核历史；R 不是 SMB 普通共享。原删除/还原键和代次不由名字或可读性代替；同 FileId 的物理容器名字节不因回收变。真实新/旧目录、账户范围、同名不同 FileId、权限和“不覆盖”不变。

SQL 中的交接/物化任务及其成员行冻结确切身份和所需资源，不把成员表塞进单个 4 KiB 帧，也不用应用级 INTENT 分页/重放。允许的深度取决于实际 SQL、目录、字节、FD、后台与还原额度，不继承旧 8192 条/8 MiB 决策账上限。不得挪占另一 FILE 的还原额。

## 什么叫“通用”

**代码现状与目标不同。** 在现行旧入口，[src/linux.c](../src/linux.c) 的 `zxs_anonymous_file` 用 O_TMPFILE，卷/材料/确认下界/阶段读写仍用 xattr，`zxs_native_birth` 用 FS_IOC_GETFSUUID＋name_to_handle_at，`zxs_allocate_stream` 用 fallocate。这些是尚未替换的真实依赖，不是新介质能力清单。下表是替换与验收计划，不代表当前正式业务已在不支持这些接口的挂载上工作。

| 现在旧实现的要求 | 新格式的要求与替换门 |
| --- | --- |
| 文件系统名称、品牌 UUID ioctl、特定快照/克隆/子卷 | 不作为功能、探针或注册/读写前提。选择受保护普通根，核当前外部挂载映射、权限与真实物。无品牌白名单。可见 UUID 只作可归属状态字段，未知就不填。R 仍需有证据与 S/所有普通根分属不同文件系统，不是另一个路径就行，也不是证明不同硬盘；通用 OS 与部署提供的证据不足则不登记该组合。 |
| 永久 st_dev、export handle、卷/阶段/前沿 xattr | 逻辑 Pool/Volume/Directory/File/Material/Op ID 由原 SQLite 事务发行，并与受保护卷标、确切原请求/材料和摘要关联；文件内容服从原承诺。现场仍在持有 FD 与确切父上核原对象、无链接跳转、原生同物/挂载与权限。路径、mtime、untrusted token、单个 st_dev 数字或自行算出的散列不授签发/读/清理权。完全复制/整体回退的全套介质在原件不在时，单靠普通软件不能鉴别；含糊、双现或未有证据不自动接管/删除。 |
| O_TMPFILE＋私有 xattr、固定 fallocate、仅凭命名缺失判完成 | 使用本操作唯一的私有普通暂存名，排他创建、显式原操作和角色、原文件及目录同步；冷开只续同一原件/原票相符的阶段，不收养已有无归属空目录。可用普通受保护名称固定已领原 regular 的第二个名字作为必要的同物见证；这不是另一份数据或另一授权。若同名替件与原出生不能证明相同，停在非破坏态。空间预检与顺序真写/同步分别处理错误，不靠稀疏大小、预分配或专用块计数证明成功。 |
| 更名的覆盖、根/服务的排他 | 即使通用也不能用“先看不存在→可覆盖 rename”替代原子不覆盖。针对所操作的普通文件/目录须真有独占创建/不覆盖发布、原子切换、持文件锁、文件及父目录同步的语义；准备全在原控制域，能力无法验证的操作据实不支持。临时名若撞既有物保留并拒，不清理未知。用户看到的 FILE/目录仍按同一逻辑父＋原 UTF-8 精确同名跨类型互斥。 |

首次认领、现池冷开和独立停机互斥只按 [SQLite SYSTEM](sqlite-system.md) 做：原 S 目录的同一个 flock 管生存期，SQLite 自己管理数据库、事务及热 journal。不能使用原登记文件加确认下界决定归属，不能由旧原票补新卷标。只有来源不明的空目录、旧 xattr/旧认领或同名他物时拒绝自动接管。

既有 GENESIS/CONFIRMED 的源码与合成向量只记录已终止的实验；本文件的扁图/改变材料/LogicalV1/完整 RAW 保留，其发布、引用、原单与任务关系只来自新库。

## 分片与验收

1. 扁平范围索引/校验与资源约束；用 A→B→C→D 让 D 一次覆盖横跨此前三个真实来源，裁短、再增长出零；早/中/末任意 Node 定点仍见当时原字节；序数 >255，读 D 不需要回开 A/B/C 节点。纯计划/索引实例不是正式 I3 已发行。
2. 手动本轮单逻辑稿＋不覆盖已确认区间 与工作读者；自动 60 秒内 21 个真实确认、C/D 各自发布并与两次真实后台全量作业交错，旧读者、D 对 C 旧材料仍有引用、取消未确认/断电、ENOSPC、重新授权与旧原单。自动原事件按发表时稳定祖先/时间只计一次，搬盘/换表示不重计；按当前权限分页/计数。
3. 单一可信 SQLite 库、普通介质资格及跨项目同一 原 S 目录锁/模式；两类普通父、任意件数 cross-volume MOVE/DELETE/RESTORE、跨 FS 收 Hot、源 A/B 掉线、同名替件、R 自己的还原额度、已确认后不得选另一原件。受理向量必须能区分旧格式、掉线、仅登记、未清、已安装且可读。只有通用版进/出/续作齐全才切换正式发行、移除旧专用依赖，不新增产品 CLI/网络正文路由。这里不声明已编译、执行、实测或上线。
