# 首次设置与离线重置：Web 管理员与内置 SMB 的唯一用户

新池只有两个固定身份，不互相代验。SQLite 是池、Web 凭据和业务授权的权威；内置 SMB 只使用原实例的 [私有凭据正本](../src/smb/credential-record.md)。SQL 保存非秘密的账号、安装绑定、操作与代次，不存 SMB 密码、NT hash、验证密钥或副本。知道公开坐标或拿到历史回执不能登录。Web 密验与 SMB 密验分别使用；Web 登录不授文件权，SMB 用户不授 Web 管理权。没有默认密码、匿名、来宾、远程改密或后备认证。

- 两名各有独立 AccountId 与规范小写 ASCII 登录名（1–64 B、不同名），SMB 名排除 guest、anonymous、nobody 和 root。固定本地域为 `ZXSLOCAL`；账号的精确规范 SID 由原安装与当代绑定核实，不能接受客户端或操作员自报的 SID 代替。Web 的 Argon2id v19 验证值为 32 B，独立 16 B 随机盐，64 MiB、3 次、4 lanes，只交本池 SQL。
- SMB 正本 `vault/credential.v1` 是密码等价材料。只向本次满足实际降权、原站点、原 SYSTEM 锁及当前 ACTIVE 资格的内置 SMB 角色，经原本机受控通道移交**同一**只读实际文件，原文件字节/身份、代次与权限再次核对后才能用于真实协议认证。Web、日志、环境、命令行、公有安装记录与普通回执均不接收 SMB 密验。状态查询既不打开秘密也不推进原操作。
- 已确认 FILE 与历史原单按原历史凭据代解释；当前操作只接受本账号唯一生效代和当前共享模式。旧代留存既不授新权，也不会因重置而丢掉已确认数据或历史。同名物、新代、新请求均不能冒充旧未决写单。

## 原安装内的离线顺序

1. 新设或重置必须有本次、本角色的本机维护授权。先停在线两角色并确认其实际排空与退出；按同一锁次序在原 SYSTEM、准确站点取得 EX，保持到最后确认与同步。不能凭 unit 状态、路径、账号名或另一个站点的文件领用权限。首次只允许明确获准的**新**站点与从未首设的新池；不导入、迁移、接管或用旧安装为回退。
2. 首设或 SMB 重置固定原池/INIT/SETUP、原站点、批准、目标账号、前驱和新代与记录号。私有 staging 可持本次材料，但不是生效凭据；只有同一 PENDING 在 SQL 持久确认后，才可能在原 vault 按确切前驱发布该记录。首设未确认时两种登录均关；有 SMB 重置待决时，旧 SMB 代不可用，不回退最近的已确认代。
3. 必须持原真实 vault、同步文件与目录并独立重开，核实际活动记录与本次原单一致。条件激活只在重新核实原请求、绑定、前驱、代和原记录号后完成原 SQL 事务；可见文件或 SQL 返回一行不等于提交成功。首次 ACTIVE 与所批准普通目录发表/初始读写模式同一 SQL 提交。数据库的原子范围不含文件系统，证据缺失或结果不明即关闭准入、保留现场，不以同名或旧收据补成成功。
4. 先查确切原号才谈续作：确证已发布的是本次目标且原件可重新同步、独立核验，才有资格续同一 PENDING，不重写密码；确证只有本次的原前驱/真正新空现场，也须在同一原单与重新授权下继续。原件不明、已变代、晚失败、缺失正本或介质不能验证时不重发新号、不填未知、不清异物。成功回执只说明当初已确认，不证明当前仍生效。
5. 仅 Web 重置时，在原 Web 前驱门下原子更新其 Web 密验、代与回执，不开 vault、不改 SMB 代；仅 SMB 重置不改 Web 密验/代。停机可终止两边旧会话，但不能让一个持久身份接管另一个。新会话按新生效代和实际启动重新证明。

## 公开原单与验收

[SQL 模式](sqlite-system.md)、[原账户原单](../src/system/credential.rs)与 [Rust 条件激活](../src/system/activate-rust.sql)定义同一请求及唯一生效代。首设/SMB 重置采用各自的无秘密摘要域，绑定完整的公开安装描述与本次固定账号、原操作和记录号；Web 重置只绑定其本角色的前驱与授权。摘要只作同一原单的比较，不是口令验证或发行能力。以原实现为准，三个请求从含实际尾 NUL 的域开始，ID 为原 16 B，名字前用 1 B 长度，以下各字段无额外分隔：

- **SETUP**（kind 2）：`ZXS-SQLITE-1/RUST-SMB-PAIR-1\0`，PoolId、InitOp、SetupOp、维护主体、批准、InstanceId、BindId、Web AccountId、SMB AccountId、首 VaultRecordId、32 B 原安装描述 SHA-256、Web 名、SMB 名及 28 B 原 SMB SID。
- **SMB 重置**（kind 7）：`ZXS-SQLITE-1/RUST-SMB-RESET-1\0`，PoolId、InitOp、SetupOp、本 ResetOp、维护主体、批准、InstanceId、BindId、SMB AccountId、前驱 Op、前驱及新 VaultRecordId、8 B 大端前驱正代、32 B 原安装描述 SHA-256、SMB 名及 28 B 原 SMB SID。
- **Web 重置**（kind 8）：`ZXS-SQLITE-1/RESET-WEB\0`，PoolId、InitOp、SetupOp、本 ResetOp、维护主体、批准、Web AccountId、前驱 Op、8 B 大端前驱正代。不含 SMB 安装、账号或记录号。

仍须分别验证实物首设、SQL 预留和具名同步之间的中断、原 vault 换物、SQL 提交丢答、前驱失效、Web/SMB 互串及原生客户端重登。[站点启动契约](../src/smb/launch/site/CONTRACT.md)只消费正面核实的新安装，不是凭据发行器。此页说明待验的首设、重置及同号续作契约；新站点的实际签发、重置与冷续作没有因此接通或获准。以上不是本次安装、升级、运行或发行结果。
