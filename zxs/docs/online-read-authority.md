# 在线权限：同一账户、两路独立授权

共同账户的新池不增删账号，没有逐人 ACL。[首设](first-account-v1.md)绑定同一个名字、同一生效代。Web 由 SYSTEM 的 Argon2id 验证；SMB 由同一安装的[生效私有正本](../src/smb/credential-record.md)核 NTLMv2 和原连接签名。知道同一口令可分别申请登录，但 Web 会话、SMB 会话及业务权限不能借用。**禁止匿名、guest、过期/错误密验回退及未经认证的共享枚举。** 登录页本身可见，认证前不返回账号、池、共享、文件或版本。

| 操作 | 已通过 Web 认证 | 已通过 SMB 认证 |
| --- | --- | --- |
| 查看固定账户、管理共享／查看版本元数据 | 认证后可用；不收发文件正文 | 拒绝 |
| 磁盘信息、状态与监测 | 不提供；由 Helper 独立办理 | 不提供诊断；常规 SMB 文件系统容量查询仍受实际获准共享与原物约束 |
| 改首设已选普通目录的停用/只读/读写模式 | 可以；不从 Web 新发共享或接入卷 | 拒绝 |
| 浏览共享／列名／开文件／范围读 | 拒绝 | 仅已启用的只读或读写共享 |
| 创建／实际写入／截长／删除 | 拒绝 | 仅已启用的读写共享，仍受原文件受管操作约束 |
| 未发布、停用或无法证明的共享 | 可见自己有权管理的定义；不构成数据权 | 不可见、不可打开，不从真实目录列出 |

共享只记录自己的状态：停用、只读、读写。修改由已认证的 Web 管理员显式进行，原操作要绑定同池、ShareId、当前设置原 Op 和新模式；无模式变更记录就是初始停用，不等于默认只读。读写模式不是额外系统管理员、账户管理或回收盘原始权限。两共享引用同一普通根时仍共用一个业务名字域，不能制造第二份 FILE 或通过一个旧句柄借另一个共享权限。

SMB 每次真实打开/查名及实际句柄操作，都用真实已认证会话的 SMB 身份及代次，在同一短 SQLite 切面核 ShareId、模式修订、精确普通父、成员/对象及需要的动作，再持实际原件。写确认必须再次核该份授权，先启用后停用、RW 降为 RO、停用后重开、凭据重置都不会让旧写入或句柄自动升级。Web 会话或外来 UID、客户端传的账号/SID、某个库函数返回的原元数据不能充当凭据。Web 登录状态不转发到 SMB。Web 只管理，不上传、下载或预览普通正文，亦不转发文件流。

Web 需受保护网络上的真实监听和短时服务端会话、随机令牌、HttpOnly/SameSite cookie、限流与 CSRF；前台可明确选择直连 HTTP 或仅受信本机代理回源；外部 HTTPS 不由 ZXS 配置或证明。令牌、密码不放在 URL、argv、常规日志或回执。内置 SMB 必须在原连接上实际完成严格的 SMB 3.1.1 验证及签名，再按原 SYSTEM 生命周期核定确切主体、代次与业务范围。没有匿名、guest、纯数字会话 ID 或旧站点的后备许可；无这些原证即拒。

源码、启动、监听、真实操作与现场验收分开。最初端到端验收在获准的新测试池上：离线首设并启用一个普通可写目录 → 实际管理员查阅/改动获准模式 → 真 SMB 主体创建 FILE、写入并读回 → 冷开同池/同容器仍得原数据。还须分别验未登录、互串凭据、错密码、只读写入及降级中途提交的行为。本文不报告本次执行或原生客户端通过。
