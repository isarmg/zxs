# 可变深度的正式增量历史

状态：待独立静审的实现设计，不是已开放的第三代或实测结果。目标是同一 FILE 从任一当前正式节点继续保存并显式发表，再无“只能有两个 INCR”的业务规则。不因深度自动产生 FULL。Web 只管理，版本页面可给有权主体看元数据，不收发普通文件正文；数据流仍属于存储内核及后续 SMB。

## 一条原链，一套读取

- SYSTEM 原确认前缀中，每个 FILE 的已有 `deltas: Vec<原决定位置>` 就是这条直系的索引。F0 后每个 INCR 都要逐边核同 FILE/History/Branch、原 NodeId/VersionId、原父决定摘要、父长度和准确的工作边；表来自原决定，不是可改的第二份历史。固定读任一节点只取到它的前缀；新 SAVE/发表只选当下正式末端。正式父和上一笔工作即使同修订/同字节也不可互换。未过确认下界的完整帧不能改变 tip；原单重试不能清理下一轮的稿。
- 物理角色为 FILE、本来那一份 FULL 索引及 RAW、`INCR(自 0 起的有序 ordinal)`。区间读用迭代器解析 `Parent`、本包 `Changed`、`Zero`：Parent 只能回**直接父的同一逻辑位置**，Changed 的物理偏移是该代 dense 流自己的偏移。不得递归栈随深度增长。按本次请求的区间维护非重叠的待解析部分，或用等价的有界 sweep；一次最多产生由实际 run 端点决定的片段数，不为文件的每个字节/逻辑块建表。相邻同一源且连续的物理偏移可合并。截短后扩长只合成零，不能从 F0 找回旧尾。被遮住的版本仍可按自己的 NodeId 读取。
- 新片先把现有两层路径换成同一算法，再连可变深度。整读、区间及空区间遵从已选前缀原图/各需用索引，交付字节前核真实相交数据块；未被读取的其他 BODY 不自称已验。保持持久原 REGISTER 读租至最后 flush。一个 FILE 图只持一组材料和原守护租约，不能为每个节点前缀复制一套 FD 或重建每一历史版本的正文。若采用有限 FD 窗口，冻结的是这份图/位置/每个物料的原生出生及 stamp；用同一目录/原物租约阻止整盒退役，重开时逐项核原物，完整边界不回退为新位置的同名对象。实际 FD/空间不足要可安全失败，不当世代限额。

## 新增量不用整读未改正文

旧正式记录里的平面 SHA-256 就是完整正文的 SHA-256，仍按旧事实返回。后续签发的 INCR 使用**新的正向类型和域**，不是把组合哈希塞入老 `body.sha256`，也不是按“第几代”挑算法。F0 保有原扁平 SHA。对外部/库业务元数据显式区分 `FlatSha256` 与 `ParentMapDenseV1`，长度单列；用户如确要扁平 SHA，只有另行流读所选完整版本后才有，不记为旧回执、不是 Web 正文功能。

组合承诺固定并有域隔离：父的真实 FILE/History/Branch、Node/Version、原决定摘要和正文承诺的类型/值；有序规范映射（含父长度、结果长度、行数、父/变更/零、各段长度）的真实 SHA；实际变化流长度、真实 SHA 及其块链头。定长编码明确，不能取现在 HEAD、借未签临时包或用当前名算根。先核原有父图和各承诺索引，遍历工作布局定位并实读本轮最终可见的 Changed（含实际相交整块），计算 dense；Parent 不复制、不为扁平 SHA 通读，Zero 不物化。签原决定前在实际具名目标上独立读回完整 map、dense 和索引，再以同一归属/原工作票/目标 FD 与确认前沿重核。完全覆盖、纯零和裁空仍认证真实父索引，不虚称本次把未读祖先正文验证了一遍。按需整读可以检测覆盖视图中的实际坏块。跨盘整盒另须逐个核所有原物，包括被后代完全遮住的老包。

## 不让小帧变成新的深度限制

现有 custody 的输入原票≤2048 B、每笔 SYSTEM 决定帧≤4096 B；不能把每个 child 的摘要或每个目标 inode 都塞进上述两个固定头。保留一个确认者和一个写槽。不在各盘增加授权清单、数据库或推测可删的第二来源。

1. 新原票/主帧绑定这笔业务参数、两确切父/角色、前一放置、F0、冻住的正式 tip 与子数、稳定次序及其承诺。冻结范围只来自上次确认前缀。之后在 B 新发表的版本只凭其自身原决定，旧 A→B 回执仍只涵盖当时的前缀。既有已发小格式按原事实核验；新写只用一个与深度无关的格式。
2. 新实物身份用同一 SYSTEM 原登记内**随决定附入的有序材料页**：每页≤4096 B，绝不作为单独经营决定。普通跨盘、删除、还原记录每一目的角色的原 native entity/出生 handle；各行 ordinal、身份/别名去重按原图校验，确切身份从原始页取，不从业务名、当前枚举、xattr 或下载摘要推算。同挂载只是原名不覆盖地迁移，核原组，可不重复储存同一组身份。主帧绑定页数、总字节、角色数和规范页序列 SHA；原头和页一起校验才构成一个决定。页不能成为另一归属、不能替另一个池、FileId、操作或旧删除使用。
3. 临时 `FILE-INTENT` 保留这次将附入的确切有界字节，仍由原 inode、摘要、真实 ALLOC 和前沿识别。总上界由角色数、行上限、日志剩余预算共同决定；先验证精确长度/每页上界再分配。热/冷仅接**字节完全相等的连续前缀**；短页、乱序、重复、额外页、未知尾、换 stage/同名等字节新 inode 均不可确认或退休源。页和主帧须全部落盘同步并重新核物才一次抬现有确认下界；原决定数只加一、确认字节数计入所有页。在这之前 A 仍是唯一原属；决定之后目的未装快照不能回到 A。历史回执和 SYSTEM 冷重放不打开旧源或当前掉线的数据/回收盘；仍能把所有已认可的 native 出生登记入唯一索引。
4. 保留 8192 个经营决定/8 MiB 原决定区的两项池预算，不把原生表藏到不计费的字节里。每个真正保留 FILE 的还原额度从其原删除键、冻结角色数推导为 **1 笔＋最坏规格原头及所有目的身份页字节**（含页封装、最大 native handle 及两项真实父证据）；旧 inline DELETE 最多两个子节点，设计要求统一新编码在该情形下的主帧＋所有身份页总额也≤4096 B（四个基础地址及两个子地址，六个 native 地址最多 990 B；用双普通子父/最长名的真实最坏编码做静态上界与原字节夹具断言）。旧还原票因此不补发、不偷用其他 FILE 的份额。DELETE 在匿名慢复制/持久出票前已容纳本次及此额度；无关写不能借，只有匹配 RESTORE 可用自己的额度。作为输入的估算不是授权，真实签决仍核实际字节。目录 8192 项/512 KiB 名字预算、255/4096/256 组件/路径/层数、真实 FD/空间是现有资源边界。预检发新 leaf 后的暂存及稳态 census，不到下次重开才发现受本次操作挤爆。
5. 退役进度显式 `Armed | Leaf(checked ordinal) | EmptyObserved` 等原阶段，正序规范角色、反序逐物清理。与同一已确认操作、原票/前址/两父和已独立重开完整目标绑定。不使用 u8 强转计数、不得让数值碰撞冒充实空。授权边界前已消失/换物拒；只有当前原叶允许 unlink 已做及正好下一步的重试；只有实空并同步后才允许最后 rmdir 的 ENOENT。物理搬/删/还读遍并复制所有需保留的物料，各物只需要一份原始身份和内容承诺；不能为第 k 个后代再通读 k 份逻辑祖先。

## 分批与证据

1. 可独立审的共同范围解析器和原图/材料序列；现有两代路径用同一实现，尚未支持恢复/退役的深链不提前写进原池。
2. 新 INCR 的有类型内容承诺、真实变化打包/具名核验、工作轮及历史读；可变名单的页编解码、账本/还原额度与可恢复的序位进度单独审。每个已审内部件不是业务开通。
3. 链接至两条 MOVE 和各自 DELETE/RESTORE 的冷热物理路径后，才同时放开真实下一代 SAVE/发表。源码场景至少覆盖 I3 和一条更长的真实链；不同代交叠、截短/扩零、空包、早/中/末 NodeId 与旧原单、未确认新代、祖先包损坏（包括全部覆盖）、同字节异 inode。覆盖 A→B 只冻结前 k 项、B 后生 I(n)→R→原或显式普通父、A/B 分别离线、迟到占名、深链中任意第 k 个清理断点、两张返还额度、末页未确认。用 >255 序数/长名字/目录及日志真边界的有限源码例，区分源读/复制/回读与实盘数据。**只写和静审；未构建、未测试、未运行或测速。**
