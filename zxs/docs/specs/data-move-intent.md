# 跨 DATA 移动：原意图、互锁与就绪

状态：[仅静态]。当前只有私有本机实现和专用夹具，未接入运行入口、Helper 指令或服务启动互锁。总体恢复流程见 [离线移动设计](../../../helper/docs/specs/offline-data-move.md)。

- 从原停机独占范围取得原 STATE、SYSTEM、RECYCLE 及两块原 DATA。持有已有的原角色 owner，核对原 CR1 的精确字节和 native inode/创建时间；不打开通常会补同步或清扫的 Store 入口。
- 源仅读取有界 OC2 账本和所选原件元数据。主账本沿用原序号和操作验证；每个原件结构、所读回执、文件类型和长度均核对。只读取元数据，不读取正文或改变任何 DATA 名称；后续复制仍需验证正文的真实长度、EOF 和完整 SHA-256。
- 用原 SYSTEM `data-relocations/{C}-{O}/` 保存唯一的 `source-proof` 和 `INTENT`。不覆盖旧文件，也不把名字相同的未完成目录变成新意图。先同步原证明，再复核源和候选/目标/暂存的原持有父目录并同步准确缺失，才写原意图。两文件、操作目录、其原父目录及原 SYSTEM 各自同步，再重新核对。冷重开只允许同一个完整原意图及其相符证明；部分或外来材料保留。
- 写互锁前单独核对当前原源/路由、角色和有效前置名，确认候选 CR1、目标 DATA 名及专用 DATA 暂存名均在准确、已同步的父目录中缺失。存在同 C 的上传、回收选择/到达、无法归属的回收暂存或涉及原盘的退盘记录/待选等，拒绝开始，不读取这些位置的正文。
- 在同一个原 STATE 写 `.move-guard-draft-{C}-{O}`：新私有记录的创建时间和已校验意图严格绑定，文件本身先同步。再次核对原意图、原挂载和私有候选后，才以原父目录同位无覆盖重命名到 `.server-stage-move-{C}-{O}`。重新打开并比较改名后同一原文件的 inode/创建时间与字节，不用旧 ctime 当作身份。
- 可见活动名不是成功。原 STATE 父目录同步后，还要证明活动名为原互锁、备用名准确缺失；冷重试只确认这一个相同已知原件。坏记录、未知同名、阶段后缀或已有 READY/SWITCHED/DONE 均不被这个前置入口重用、不覆盖、不删除。

这些持久记录没有临时 `st_dev`、挂载号、密钥、口令或盘路径；会话中仍需核对活文件描述符与挂载。上述 I/G 步骤不写入 DATA。CR1 切换、退休、启动互锁和历史 DONE 查询仍未接入，须与实际 Helper 停机命令和故障资格另行验证。

## READY：私有目标，不是已切换

当前仍只接入私有夹具。只有同一已同步活动互锁才可独占创建 `TARGET/staging/move-{C}-{O}/`。逐项复核原 OC2 与原生证明：保存项流式复制完整正文并核对长度、EOF、SHA-256，纯元数据项只复制回执。每份原文只读一次；同步写出的目标文件、对应目标目录和原暂存父目录。独立遍历目标账本和形状，复核新文件的准确原生证明，不在同一新鲜复制中重读全部正文。

在原 SYSTEM 操作目录独占准备 `target-proof` 和 `new-route`。后者是给目标盘的准确 CR1，READY 另外绑定它的原生 inode/创建时间；它不是现有业务路由。同步前置证据，重验原路由、租约、互锁和源/目标；最后独占写入并同步 `READY`、原操作目录及其父层，重验准确命名。此处没有发布 `.<C>.incoming`、没有发布 `TARGET/data/{C}`，也未改变原 CR1 或删除源。

READY 刚形成时，冷重开核对该准确布局、仍在的原互锁和未发布的原候选，并读目标正文一次（长度、EOF、SHA-256）。不再重读源正文。缺 R 的残留、未知后代、同名不同原件或同步未确认均保留；不得截断、补齐、覆盖或另选盘。这个夹具不证明真实断电、设备掉线或安装后的命令恢复。

## 已就绪原件的顺序到达

同一停机范围内，先把已证目标树从原暂存名无覆盖移动到 `TARGET/data/{C}`。重开准确目标名称，核对仍为原暂存树的 inode、实际挂载和完整账本；原暂存父目录和目标父目录都同步并复核后，才可移动候选。

候选从原 SYSTEM 操作目录的 `new-route` 无覆盖移动到原 `container-routes/.{C}.incoming`。核对它仍是 READY 的原候选文件，精确字节与 inode/创建时间一致；不得把改名之前的 ctime 当作身份。原操作目录和原路由目录都须同步；同步共享路由目录前后均核对原选中 CR1。到达不修改 `container-routes/{C}`，不写 SWITCHED/DONE，不清理源。

冷重开仅承认仍持同一互锁和**原**选中 CR1 时的三个状态：目标和候选都在各自暂存位；目标到达、候选仍在原位；两者按序都到达。分别证明两对名称的准确存在和缺失。冷重开只读目标全量正文一次；同次继续使用持有的完整证明。混合、同名替代、缺失或不确认的现场均保留，不选路、不恢复未知材料。
