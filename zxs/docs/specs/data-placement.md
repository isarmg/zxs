# 首次在线保存的数据盘分配

状态：[仅静态]。本文适用于在线创建容器；不改变已有容器、回收或 Helper 离线导入的目的盘。

- 仅对没有 CR1 路由的首次在线保存采样。对已经持有并核对挂载的 DATA 暂存目录调用 `fstatvfs`，不探测写入，不以路径重新打开替代盘。
- 可用字节为 `f_bavail × f_frsize`。只读、挂载变化、查询错误和数值异常不参与选择。
- 扣除该盘尚在进行的全量首次保存预约，再要求剩余至少等于声明的正文长度加 1 MiB。选择净可用字节最多的盘；相等时选原始字节字典序最小的盘令牌。

预约只在当前进程内生效，最多 64 个。并发同一容器沿用它尚在使用的候选盘，每份正文各计一次，遇到并发变化时，最多进行四次采样及预约尝试。
预约存续到请求的暂存收尾结束；不写磁盘、不占容器名、不承诺日志或回执。正文完全验证后才可持久登记 CR1。

候选盘不存在或不可用、空间不足、并发波动均沿用原协议的不可用响应；不会自动切换或移动已有容器。
可用量是建议值，不保证配额或独立文件系统活动不会令实际写入失败。已登记的盘遇到空间不足或结果未确定时，不在另一盘重试。
