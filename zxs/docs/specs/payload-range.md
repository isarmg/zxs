# v1 完整正文与单段读取

状态：[仅静态]。客户端需已显式登录、核对同一 HTTPS/HTTP/2 入口，并再次验证原容器号和不可变节点号。

仅新增 `GET /zxs/v1/containers/{container_id}/nodes/{node_id}/payload`。只接受已验证的 Bearer，不接受 Basic、别名、自动降级或重定向。
原 R3 Basic 的 `/data`、状态码、正文和摘要头不变。

## 请求

- `Range` 可省略；也可用一项 `bytes=start-end`、`bytes=start-` 或 `bytes=-N`，端点含首尾。显式端点超长可截到 EOF。
- 无效数字、溢出、反向端点、重复头、多段或无效区间形式为 `400`。合法但不认识的单位忽略，返回完整正文。
- `If-Range` 只有与选中正文当前强 ETag 逐字匹配才允许相应部分；弱标签、日期或其它不匹配值返回完整 `200`。
- 不接受 GET 正文、压缩传输或重复 `If-Range`。`HEAD` 和修改操作不在本切面。

## 响应

| 结果 | 响应 |
| --- | --- |
| 完整正文 | `200`；原长度，`Zxs-Sha256` 为整正文摘要。 |
| 可满足单段 | `206`；`Content-Range: bytes start-end/total`，`Content-Length` 恰为本段长度。没有部分段摘要头。 |
| 无可读字节 | `416` 空正文，`Content-Range: bytes */total`。含空正文、起点越界和后缀长度为 0（当 Range 生效）。 |

`200/206` 使用 `application/octet-stream`、`Accept-Ranges: bytes`，以及双引号包住的整正文 SHA-256（64 个小写十六进制字符）强 ETag。
`416` 无正文，带 `Accept-Ranges: bytes`。不提供 HTTP 内容编码。未经授权，不返回正文、原长度、范围细节或 ETag。

## 不变量

- 服务从选中的活动节点原 FD 进行有界定位读取；不改写、不转盘、不回落到回收副本或其它节点。
- 重用连接不重用身份。完整授权和原节点证明后，才返回区间信息。读取中遇到短正文或错误，不拼接其它位置。
- 客户端必须验证 206 本段长度、边界、整正文 ETag 和总长，再处理同一节点的下一段。任何完整 `200` 都不能拼接到旧部分。
- 部分读取不能证明整文件 SHA-256。ZIP 尾、目录或成员跨度由客户端选择，服务只传原字节。按偏移上传、自动重连提交均不在本切面。
