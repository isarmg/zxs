# ZXS 源码仓库

本仓库正在整理为三个独立项目。每个项目从自己的目录开始使用，各自维护构建入口、依赖和文档，不引用同仓其他项目的源码。仓库根目录最终只作为索引，不作为共同构建入口。

| 目录 | 职责 | 当前状态 |
| --- | --- | --- |
| `zxs/` | 单文件容器存储服务。系统盘保存全局状态；用户数据只保留一个正式容器。跨盘移动和回收保留原容器身份及历史，不提供备份功能。 | 独立源码重构中。 |
| `helper/` | 独立管理辅助工具。 | 正在从旧实现拆出独立工程。 |
| [`zxs-workspace/`](zxs-workspace/README.md) | 目录仓库和本地 Worktree，以标准 ZIP/ZIP64 保存完整目录提交。 | 源码已迁入；从 `zxs-workspace/` 目录开始，见其 README。 |

旧根目录代码和配置暂保留供迁移核对，不代表新布局已经完成。新改动仅做源码编写和静态审查，本轮未运行程序、构建、测试或 CI。
