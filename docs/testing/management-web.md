# 管理 Web 验收

Web 外壳不能从存储失败或缺少凭据推断新安装。`/api/management/status` 公开且粗粒度，只有明确 `ready` 才准入存储写入。恢复会话和登录不在显示外壳前加载数据盘；只读、不可用、未配置、需恢复和未知状态分别保留。

首次账户表单在登录前显示，无授权密钥。没有账户且无历史权威时任何可访问 Web 的人可设置；锁内保证并发仅一次成功，已创建或损坏凭据不能重置。此入口不是登录失败回退。初始化只提交管理员凭据，不要求或提交磁盘、预设和模式；管理权威成功后允许登录，存储保持未配置。

<a id="automated-checks"></a>

## 自动检查

- `cargo test -p web-app --lib`：管理初始化回执、首次激活请求、明确确认、未知结果与会话代次围栏。
- `cargo test -p storage-server --lib`：认证／Origin／CSRF、管理账户先建、目录检查、激活与原意图恢复边界。
- `cargo run --locked --offline -p contract-check`：发布 schema、OpenAPI 与正反向量一致性。
- `cargo clippy -p web-app --target wasm32-unknown-unknown -- -D warnings`。

这些是检查入口，不是执行结果。现有浏览器运行器及历史记录需要按新流程重新验收，不能将旧的磁盘向导／预设流程通过记录算作当前流程通过。静态检查和原生单元测试不能替代真实浏览器；若 Chrome 被沙箱阻止，记录限制，不绕过安全限制重试。

<a id="protected-completion-and-local-presets"></a>

## 登录后首次存储选择与补全

验收应先创建管理员并登录，再在系统管理设置发现根（默认 `/zxs/data/disks`），只浏览其内部真实目录，分别选择挂载路径及其内的实际存储目录，包括多层子目录。检查空目录、0700、服务账号所有权、符号链接、路径跨越、挂载／发现根／目录替换、发现根原值冲突及重复选择拒绝；目录选择不是实际 mount 或 chmod。

首次激活成功对象要求 `activated:true` 且 `restart_required/recovering` 恰一为 true。中断、连接丢失和未知结果不得解除防重发围栏；重新查询后仅在 `completion_available:true` 时补全原意图，不能更换选择或重置管理员。需要分别覆盖断连后后台任务继续、撤权、重启恢复、旧响应隔离与关闭／返回后的状态保持。

旧公开预设初始化与初始化补全路由已移除。历史 [UI/G4 与浏览器验收记录](../validation/ui-g4-browser-acceptance-20261031.md) 仅证明对应旧提交的测试，不证明新两阶段流程。已有池在线增盘／移除未实现，不应展示伪成功或恒失败按钮。

<a id="single-disk-regression-boundary"></a>

## 单盘回归边界

单成员开发池应通过“创建管理账户 → 登录 → 选择目录 → 激活”建立，再创建 `target_copies=1` 仓库。移走唯一目录并重启后应仍能登录、查看管理状态与诊断，存储失败关闭且不重建目录。这是隔离模拟目录验收，不是实际设备拔盘／掉电验收。多副本策略仍须显式选择，不以管理就绪代替存储或副本就绪。

## 会话与异步状态评审

业务读取既要在请求发出前检查有效会话准入，也要在完成时核对会话 epoch / 请求代数，避免过期响应写回。完成阶段围栏不能代替发出前鉴权检查。管理状态按设计可匿名读取，但状态 GET 不得与存储重试 POST 重叠，让旧快照清除 `retry_unknown`。页面导航不等于文档根销毁：根所有的 UI 任务可按既有设计跨页面继续，文档根清理才取消；操作回执仍与操作身份绑定。相关源码回归不替代浏览器实际运行证据。

## 可见性与后台读取

文档隐藏或进入 bfcache 时释放 2 秒操作查询和 5 秒健康／状态定时器；可见性恢复或 bfcache `pageshow` 只恢复一组定时器，并立即尝试刷新未知操作和全局存储／认证状态，状态页同时刷新硬件采样。重复可见性事件不积累定时器或补偿全部错过的周期。全局存储／认证查询继续在所有可见页面保留，因为它决定存储写入准入；CPU／内存硬件采样仍只在状态页，目录卡的 SMART 仅在进入系统管理或显式刷新时读取。恢复会话、退出中和退出结果未确认的既有围栏仍生效。

暂停只控制新后台读取，不中止已经发出的请求，不清除未知操作、正在查询的 ID、原操作回执或编辑草稿；完成路径继续按会话 epoch 和操作身份结算。原生测试覆盖调度转移与页面／会话准入，真实 WASM 生命周期夹具检查 bfcache 暂停／重复恢复和根销毁后的定时器清理；未执行浏览器夹具时不得把编译成功记作浏览器通过。

## 目录所属设备健康

`test/web/unit/admin/disk_health_tests.rs` 覆盖逐卡 SMART 来源／设备／UTC 时间、零值和缺失值、全部不可用原因及矛盾映射／无效报告拒绝。磁盘卡状态测试保留独立读取、旧代次隔离、失败后旧观察与错误并存、备注草稿及会话撤权。

`runner/disk_health.rs` 仅替换真实登记目录详情中的显示观测，在生产 WASM 上检查单设备通过、多个设备、权限不足、同一设备多个目录、异常报告与失败刷新标旧；不读取真实设备、不伪称物理 SMART 验收。原真实损坏池用例从系统管理执行恢复重试，确保移除菜单不丢恢复能力。实际浏览器和真实硬盘／SMART 能力验证分别记录，测试源码存在不代表已运行。
