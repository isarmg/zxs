# 架构工作负载探针

这是非破坏性的**开发模式模拟**，不证明物理磁盘独立性、故障持久性或生产吞吐。每次运行创建私有 tempfile 池、三个模拟成员目录和一个系统目录；不接受目标目录或设备参数，不打开原始设备，退出时只删除自己的临时树，不改变既有 ZXS 池。

<a id="reproduce"></a>

## 重现方式

使用仓库指定的 Rust 工具链；baseline.json 是按相同条件另行生成的基线：

```sh
cargo run --locked -p perf-check -- 64 > current.json
python3 tools/perf-check/compare.py baseline.json current.json --require-incremental
```

位置参数为保留的单文件保存次数（4—4096），默认 64。比较时保持次数、依赖锁文件、构建配置、机器和文件系统条件一致。较大规模可选 64、256、1024，但需预留较多时间和空间：历史元数据仍保留，启动恢复仍扫描持久证据。计时包含 fsync，对共享机器负载、缓存冷热和文件系统实现高度敏感，有意不作为通过/失败门禁。

比较前后实现时，应使用同一测量工具口径与匹配的锁文件，为每次运行建立新池，不跨版本复制模拟池。记录基线和当前引擎 revision、未提交的测量工具差异及构建命令；如果使用隔离检出，也须应用相同的测量工具差异。输入规模和环境须一致；报告随 CI 产物或独立测量归档保存，不把单次计时作为产品性能承诺。

<a id="workload-and-checks"></a>

## 工作负载与检查

- 为一个 1 KiB 文件保留历史及三份副本，在第 1、N/4、N/2、N 次保存采样。
- 测量完整的创建工作区、暂存、提交保存流程，包含其持久 I/O。
- 采样时在 SQLite 的类型化历史表 `file_history_versions` 上安装触发器，用 `sqlite_history_writes` 分别统计下一次保存实际插入、更新、删除的行数。不含固定的 `current_state` marker 写入、通用实体镜像、触发器自身记账、日志或文件系统写入，不能当作总写放大。触发器记账会增加测量开销。
- 每次采样关闭/重开引擎，用 `restart_us` 测量 `Engine::open`，要求恢复的 `State` 精确相等。该计时包含恢复及投影重建，不是单独的 SQLite 打开耗时。下个采样点重新安装触发器，因为投影重建可能替换表。
- `index_sqlite_bytes` 是采样重开后的 `index.sqlite` 主库表观长度，包含探针计数表，不含 WAL、journal 等 sidecar，也不是实际分配空间；目录总量继续由 `disk` 字段报告。
- 打开并定位八个 64 字节范围，断言字节精确相等。使用公开的**既有完整验证 `open_content` API**，而非优化 HTTP 范围端点；这些计时不能证明 HTTP 范围路径加速。
- 写入一个 4 MiB 版本，测量首次及重复的既有打开/范围读取。首次打开不是操作系统冷缓存读取，因为保存刚写入这些字节。
- 持有读取描述符及租约，另一线程开始读该不可变版本，同时单写入者提交新版本。要求整个保存期间及之后旧字节保持不变。调度不保证真正重叠；这是持有读取的正确性练习，不是服务端并发/延迟证明。
- 最终引擎完整性检查必须无异常。

比较器对外部报告使用显式校验，Python 优化模式不会跳过准入。重复 JSON 键、非有限数值、布尔冒充计数、负数及无序采样都会被拒绝；增量门禁还要求第 1、N/4、N/2、N 次的完整去重采样点与实际非零写入计数。

报告使用描述性测量字段，不带项目格式版本标签。比较器只接受具有 `sqlite_history_writes`、`index_sqlite_bytes` 及现有计时的当前同口径报告，要求工作负载参数、采样点及五项具名正确性检查匹配；无关报告元数据不是格式分派键。旧的 `sqlite_entity_writes` / `entity_json_bytes_written` 不提供别名或兼容，不可把不同计数范围的差额当作加速。当前报告结构变化时不改写归档证据。

可选比较门禁检查 SQLite 类型化历史写入有界：每次采样保存最多 100 次，首个保存之后增长最多十次。不要求特定加速幅度或索引大小比例；基线已经增量维护历史表时，也可以通过该门禁。应继续使用更精确的架构确定性单元契约：日志扫描次数界限、分块读取字节界限及投影变化行数。

<a id="limits"></a>

## 限制

整个保存路径并未变为 O(delta)：历史状态处理、比较、序列化、快照、历史元数据保留及启动回放仍可能增长。日志优化消除热追加时重复扫描，不消除启动回放。触发器观测 SQLite 逻辑行，而非磁盘扇区或写放大。目录大小合计是文件表观长度，不是实际分配空间。HTTP 范围认证、传输、取消及争用由服务端测试覆盖，不由此核心探针覆盖。
