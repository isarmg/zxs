# ADR 0017：辅助工具与离线磁盘管理职责

[架构决策](README.md) · [辅助工具](../components/helper.md) · [分项迁移边界](../design/helper-disk-management.md)

状态：职责已采纳；实现逐项迁移，不表示所有操作已经可由辅助工具执行。

## 背景与决定

用户将磁盘添加、注销/移除、外来磁盘接入及磁盘初始化改归本机辅助工具，并明确取消磁盘的“离线/计划下线”功能。取消的不是注销/移除，也不是停止服务后维护的工作方式。

- 工具名称为“辅助工具”，可执行文件 `zxs-helper`、包 `storage-helper`、源码 `helper/`。专用编排、CLI 和报告在自身目录；通用格式、证明、文件系统与持久化能力可依赖 ZXS 代码。
- 辅助工具提供自己完整、独立的 Web 控制台，可在 ZXS 主服务未运行时启动；CLI 是可选入口，不以必须先启动主服务的 HTTP 回调实现维护。普通文件访问及日常账户管理仍由主服务提供。
- 辅助工具是手工运行的独立二进制，以 root 运行并默认监听 `0.0.0.0`。不注册 systemd、不配置开机自启，退出即停止控制台；用完即退出不等于删除操作证据或恢复材料。
- 辅助控制台不要求认证或登录，直接打开。它不是 ZXS 的管理登录页；既有 ZXS 管理员凭据和授权不因此被删除或绕过。辅助工具另提供明确确认的 ZXS 管理员密码与已配置 SMB 账户密码重置，密码由用户手动输入。
- 安装也归辅助工具：可预览、确认并配置 ZXS 的 systemd 与 SMB，完成首次安装到验证交接；helper 自身不注册服务或自启。发行物内置可核验的匹配版本 ZXS 安装载荷，支持无网络首装和程序损坏修复；修复默认不覆盖数据、数据库、配置或凭据。
- 公开 release 产物仅四类：源码归档、SHA256 校验文件、辅助工具可执行文件和 ZXS 可执行产物。匹配的安装载荷内置 helper，文档/许可材料随源码或内置载荷提供，不另发布文档或安装包资产；当前不据此承诺尚未验证的平台。
- 第一次运行的账户/系统、必要磁盘配置与初始化全部由辅助工具完成。只有成功核验完整系统后主服务才正常启动；未初始化时明确提示使用辅助工具，不自己初始化或接受半成状态。
- 不提供用户新发起的计划下线动作。磁盘实际失联、不可用，以及既有 Disabled、终态或未决操作仍是事实，必须准确展示。原已持久操作只按原身份、决定和阶段完成或报告阻断，不自动改写成注销，也不通过删除证据“取消”。
- 不提供旧命令别名、旧磁盘格式双读或隐式转换；这不授权丢弃当前格式的历史证明和未决操作。
- 外来二级及以上备份盘的正式接入必须在同一计划中显式设置、核验并纳入全部所需低级链。三级必须同时包含二级和一级，不能以虚占位、先接高层后补低层或保存意图代替完成；中断续作仍只使用原完整计划。
- 正常 ZXS 启动与运行只消费已正式纳入、发布完整且一致的系统。辅助工具先完成外来接纳、盘初始化及其数据库/标签投影准备；外来候选、待初始化盘和未完成辅助操作不能作为运行时数据或已纳入成员。缺失、损坏与不确定结果继续如实报告，不靠清空材料或标记成功制造完整状态。

## 切换准入

入口迁移不是把 `Engine::initialize` 或某个阶段方法直接暴露给 CLI。新的离线 owner 必须与服务启动互斥，绑定准确系统/管理根、当前配置、管理权威和盘目录身份。预览与执行分开，执行必须重核完整预览；永久 operation、控制归档、fence、决定与发布回执保持原语义。取消、重试及中断恢复不能只依据进程退出码或本地 completed 字段。

服务仍需读取的持久事实和验证能力由共用层提供；纯辅助工具编排放在 `helper/`，避免复制另一套权威判断或让服务依赖辅助程序。每项操作有等价证明与真实回归后，才移除对应 Web 写入口；迁移期间不先删除唯一安全入口，不为外来盘尚无写者的状态提供假执行。

无认证控制台监听全部 IPv4 接口且持有 root 能力，任何可达它的人都可能发起敏感操作。启动日志和界面必须醒目说明这一风险，建议可信隔离网络/防火墙与用完即退出，但程序不擅自修改网络或系统设置。可行的 CSRF/Origin 防护和具体危险操作确认仍保留，不能把它们包装成认证，也不能变成强制登录。密码不置于进程参数、URL、日志、明文回显或浏览器持久存储；未受保护的网络传输风险须明确提示。控制台持有实际停服/启动互斥，浏览器断连不丢弃已接管操作，退出须真实排空。

## 代价与替代方案

维护需要停服，且操作者必须能访问受保护的本地根。代价换来单一离线操作 owner 与清楚的入口职责，但停服本身不证明磁盘、历史或事务完整，既有认证、固定成员、发布和恢复约束不能省略。

不选择将 Web 请求转发给一个 CLI 子进程，也不选择复制整套 ZXS 依赖。前者没有真正转移所有权和停服围栏，后者使格式及安全证明产生两个维护来源。
