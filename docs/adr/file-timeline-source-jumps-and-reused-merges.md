# 文件时间线：有来源的跳转、区段对齐与复用正文合并

状态：候选，C 和 D 分开等待所有者决定；本文件不是实现或验收证明。
下述范围不是已批准的自动保护 A／B，也不接受旧格式、不引入迁移、部署或生产权限。

**C：只读、受权的时间线与树对应。** 扩展现有 FILE 生命周期读取，使用已发表原收据及其验证过的
FILE／history 所属关系，不改任何盘上决定。路径事实公布原事实中的前后正文引用；删除／恢复／导入公布
各自实际冻结记录所列的原分支头；每次实际合并公布严格原操作、合并事实身份、输入分支及节点、选取与
结果节点。原主体只在同一 FILE 的当前历史读取权限内显示；缺证不按名称、哈希、当前 HEAD、相邻时间
或同一个序号猜出处。借用或复制来源在本 FILE 没有可授权的真实对应时保持“不能跳转”，不得越权读取
其他 FILE。删除／恢复事件身份不是正文节点。

仍保留单页最多 64 项和现有总量／字节／取消界限。跨页定位复用现有精确节点锚点与当前身份；
查询和响应分别绑定当前会话、稳定 FILE、获准历史、上下文、位置、历史根及同一观察序号，
返回前再核权限。界面刷新或旧响应不能延续已过期的授权。必要的只读区段响应描述两个实际事件边界和
区间内已验证内容集合、真实父边、分支端点；没有双边界、父集或完整集合证明，或超预算时只显示开放区段，
不得截断后宣称“对齐了整段”。不另外引入写 API 或后台服务账户。

完整区段按[内容树／时间线设计](container-content-timeline.md)布局：每个实际内容节点一次，
按从较旧边界起的最长真实父链计算行，最长分支的最高节点在新事件线下；较短分支不造补位节点。
每行实际卡片高度取含换行及缩放后的最大值。无内容事件只画事件，不造空正文；保留稳定滚动和编辑定位。
点击操作或真实内容关系可查看原记录、定位已准入的内容卡或继续获准的有界加载。

**D：已有正文的合并只记录事件，不改写内容亲缘。** 当前合并接口实际选择已有正文，并不生成新字节。
无论选的是某个输入 HEAD 还是明确选择的旧节点，都以所选真实节点作为 survivor 的结果；
保留原输入／分支、真实所选、结果、存活和退役分支以及原操作／主体／序号的独立合并事实。
不再为同一内容创建 merge 元数据节点，也不向被复用的内容节点追加合并父边。选择某版本仍须真实
选择及读取/归属证明；不以哈希相等代替。真正由未来新正文产生的合并不是这项现有选择 API 的暗门。

D 是持久准入、读写和回放语义变化，不是 CSS。需在 Initial、Current、历史节点合并、目录选择重写、
FILE／DISK／SYSTEM 快照、历史包／复制／备份和冷回放共用原事实约束；对不存在所选、伪造输入、
错误归属、冲突结果、内容父边或旧假节点在首写前拒绝，并保留原介质。一个全新池一种格式；
不承诺把旧决定改写成新决定，不声称 v2 或兼容双轨。

举例：重命名后点击事件跳到当时那版正文是 C；把“选回先前真实版本”从伪造一个合并内容节点改为
只记录选取合并这件事是 D。C 不授权 D；D 不授权新增 HTTP／SMB 写入、初始化池或生产执行。
