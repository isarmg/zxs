# ADR 0003：自维护 CSR 框架

状态：当前维护方向；具体纳管范围由统一源码清单记录。

## 背景与选择

ZXS 在仓库内维护和定制 Web 响应式框架及相关依赖。浏览器 CSR 是产品运行边界；公共生命周期、异步任务与业务 UI 分层管理。源代码来源、版本、许可证和本地改动必须可追溯。

## 代价与替代方案

直接跟随上游加薄封装可以减少维护负担，但不符合当前自主定制方向。自维护需要承担上游安全修复评估、宏与运行时兼容、依赖闭包和浏览器回归成本，须验证实际依赖闭包和行为。现有 G4 连续圆角系统保持不变；当前用户交付范围为 Web 与独立 SMB，内部管理 CLI 保留；浏览器界面不承载原生宿主功能。
