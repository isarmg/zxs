# ADR 0002：全配置成员发布与 SQLite 投影

状态：当前实验实现，发行格式未冻结；不代表任意成员配置或真实设备耐久性已通过验收。

## 背景与选择

权威提交依靠不可变元数据、内容证明及固定 N ≥ 1 个配置成员的日志闭包。决定与恢复门槛为 Q=floor(N/2)+1；正常发布要求全部 N 个成员完成。不能在掉盘后按在线数量缩小集合。N=1 可正常保存但没有冗余，唯一成员永久丢失不具备恢复保证；二、三、四及后续备份级别均可选。所有新初始化盘保留配置锚，缺锚旧盘不兼容且不自动迁移。

SQLite 是可重建的查询投影，不替代文件系统及日志成为权威存储。准备阶段与最终决定分开，允许普通工作区提交在引擎锁外复制和校验正文；决定仍串行执行并复查冻结基线。

## 代价与替代方案

一个成员失效会阻止正常新写入。自动降级写提高可用性，但改变当前保护承诺，未采用。更换权威数据库也是独立架构决策，不由性能优化隐式引入。显式恢复按操作手册执行，不能把一般写入重试当作降级授权。
