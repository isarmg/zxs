# 普通 FILE 容器：同一磁盘保留与原位恢复（首片）

状态：按已确认的[磁盘与保留布局](disk-names-and-retained-layout.md)及
[TASKS 删除与恢复](../../TASKS.md#删除审计包与恢复)实施，本页固定首片，不扩大删除权限。
仅一套全新池原生格式。写好准备、回执或界面之一均不等于已能安全移动。

## 唯一入口范围

- 新鲜普通盘根的顶层 FILE，Born、ManualClean，原主命名空间、稳定 EntryId/FileId、
  所选 FILE 分支、节点、版本、选择代际和挂载身份均已验证。恰有一个在线原始登记和
  一个完整物理容器；每个原版本的可读位置都是该盘本地。只接收已证明没有共享位置、
  其他管理引用、未完计划、备份/复制策略、实例、目录快照/目录仓库管理绑定的对象。
  拒绝不是“未发现”，未知或离线即拒绝。WorkingDraft、Automatic、Unborn、嵌套目录、
  批量、工作树、复制、跨盘、备份树、永久退役和清理不在首片内。
- 隐藏一次只移动 FILE **整个原目录**（同一设备/inode，含所有版本、文件库和必要管理
  材料），从持有的原 common-data 父移到同盘持有的平铺 deleted-data。使用已有
  RetainedDiskRegistry 与 allocate_file 冻结的 16 ASCII 字节前缀、完整原操作时间和
  原名；新普通分配与既有工作树分配共享同一永久登记账本。名称/路径不是权威。
  不复制、不覆盖、不截断名字、不 unlink、不生成 D、版本、FILE 父边或替代容器。
- 生效后原路径空出，随后同名新建必须是不同 FileId/EntryId。显式恢复按**原隐藏
  操作及 FileId**定位保留对象，首片只回原父与原拼写。旧处被占、不在相同登记
  位置或曾被替换：保持保留态，不覆盖、不重采样、不按名字另选对象。
  不把 SMB copy+delete、枚举到目录、空路径或找不到原文件解释为恢复。

## 一个权威位置、一个原决定

登记一个 FILE 的位置及其单调生命周期代际；不是“当前副本”和“删除副本”两份权威。
正常位置依赖原命名空间与副本登记；保留位置还固定原隐藏操作及其 RetainedAllocation。
位置变化与命名空间露出/收回在一个原始候选中共同决定。必须重建并验证以下原事实：

1. 审核主体、操作、来源和恢复所指原隐藏操作；原 pool/disk/slot/binding-generation、
   root、源/目标父和管理分区的稳定身份，以及唯一 FILE 实体；原仓库/主分支、EntryId、
   FileId、完整原路径，原 FILE 选点、原位置/代际、计划的新位置/代际。
2. 根据原许可独立持有 source/destination 根、原容器和原生 FILE/DISK/SYSTEM 材料。
   比较原文件库、所有仍保留分支/节点、版本校验与选点。搬移不产生新的内容/分支头。
   管理分区的当前/保留登记随同一决议推进。原 inode 和同名目录、路径字符串不能互换。
3. 完整预检空间、条目、名称、描述符、原回执及编码上限后，才可持久写本操作的准备
   和固定的旧/新地址。**决定前不搬活动目录**。共同原生 FINALIZE 后，仅用原持有父、
   原子 NOREPLACE rename，依次同步目标父及源父。单次同盘移动不需要可重新发现的临时
   正文；任何使用的意图位置都必须先被同一准备绑定。只在两父屏障及 FILE、DISK、
   SYSTEM 管理索引安装被准确验证后向客户端报告成功。
4. 冷重开、候选回放、独立盘观察和同 operation 的重试均依实际原决定、原主体及同一
   登记/实体；按持有的两个**确切**位置验证。决定后原位仅可完成同一已决定移动，已到
   位仅可检查并完成屏障/安装。两端都有、两端都无、位置被其他实体占用、离线、旧
   generation 或管理材料不符，均拒绝/隔离，绝不遍历、自动采用或重做名字。原返回只
   能来自原回执，不得把可见投影、文件名或后来的健康状态当作它。
5. 当前路径及历史索引不授权保留读写。保留读使用新鲜的、与当前登录和确切生命周期
   绑定的只读选择，仅返回获准的分支和正文，永不露出内部数据库/管理文件，不允许
   新建、写、截断、删除、就地改名或裸 FD 写。原句柄不会因恢复到相同路径/同 inode
   自动重新获得写权。恢复后重新打开才可按正常权限访问。所有其他写者/备份/复制
   在原目标无法证明当前性时停住。实体曾不可读不证明其被物理删除。

## 交付边界

先实现可验证的单盘、双父、同一 FILE 实体准备，再接原决定/安装/冷热重放与只读
选择；公开路由在这些真实证据以及其他生产者的拒绝门槛全部贯通前保持关闭。已有整容器
总拒绝不是放行开关。实现不得以已有旧 D 读路径、同父重命名或工作树占据删除区替代。
应以真临时盘与真实原始入口覆盖同盘原 inode 和字节、两个 fsync 窗口、占名/掉盘/
换父/异物、同名新文件独立、原操作重试、旧会话/旧句柄撤权、权限隔离及原样恢复；
这一页及未执行的源用例不证明运行结果。
