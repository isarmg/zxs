# 0015：显式独立盘日志与可重建系统投影

状态：离线新格式切片，格式未发行；在线 Engine、命名空间、保护任务与恢复准入尚未切换。

## 背景

用户要求每个盘携带自己所需的权威事实，一级不能持有下游清单，备份盘必须能解释自己的真实来源，系统 SQLite 可以丢弃重建。当前池的成员发布协议不能仅因增加逐盘 sidecar 就变成独立盘协议。参见[发布决策](0002-publication.md)、[持有磁盘资源](0007-owned-disk-resources.md)与[系统目录边界](0014-system-directory-ownership.md)。

## 决策

- 显式初始化 `independent-disk-journal` 新格式；来源四元组、incarnation、role 和已知 checkpoint 分别表达逻辑身份、世代、角色与本地已知链约束。不默认补字段，不读取或转换旧格式，不按目录顺序推断角色。
- 本盘永久 operation intent、prepared 闭包与 `publications/<sequence>.json` 组成独立日志，最后的不可变 publication 是唯一业务决定。准备记录、系统缓存、外来审核和旧池 quorum 都不能替代它。已发布写入重放仍同步准确决定文件及目录，查询只作观察。
- 一级记录自己的文件 heads 和父链；二级只绑定核验过的一级 checkpoint，三级只绑定核验过的二级 checkpoint，并保留原一级身份。没有下游反向清单，也没有自动角色转换或跨来源命名空间归属。
- FULL 文件按 commit/version 物理键独立保存，内容摘要只负责验字节。跨历史、文件、后续版本与磁盘不能用同内容去重代替独立完整副本；同一个不可变版本的多处引用不产生新版本。
- 便携逻辑身份与当前主机执行选择分离。待执行操作绑定目标及来源的路径、device/inode 和稳定物理 mount-root；当前持有 FD 的真实祖先身份排除物理重叠。瞬时挂载编号不进入持久身份。已发布盘可迁移读取，未完成操作不能悄然换目标。
- 系统投影只消费完整核验结果。这个有界切片在内存中构建 SQLite，序列化后通过持有目录原子安装；读取从持有 FD 取有界快照再只读反序列化，不把可替换路径交给 SQLite。外部将主文件改成 WAL 布局时明确拒绝，保留 main/WAL 字节并从已验证数据盘重建，不读取 sidecar 或修补 SQLite 头。它不解决旧 Engine 的一般 SYSTEM/WAL VFS 接线。

## 代价与限制

每次完整报告、备份或写入验证遍历有界闭包，逐版本独立正文增加存储成本；不宣称已实现增量大型盘性能。单次独立正文导出仍核验全部元数据，但仅校验所选可达版本正文，不能把部分读取结果作为完整盘能力。显式已知 checkpoint 在对象存活期间继续用于所有权威验证。

原子文件、文件同步与目录屏障保留；首次初始化意图完成前的未知临时残留须人工处理，不能自动清空。操作残留全部计入保留预算，不自动删除或把停止当作释放容量。内存数据库和所有读取有硬界限，但本切片没有并行大型盘持久预约算法。

本机离线操作依赖明确停止相关写者和本地排它锁，不提供跨主机围栏、在线会话授权、原地角色接纳或产品 namespace 发布。缺失历史正文保留暂不可用，损坏正文拒绝完整盘写入和备份审核。三级转二级必须另证当前一级覆盖所声明的全部历史，不能把原来源替换为任意一级。

## 替代方案

继续让旧 pool-wide journal 决定成功并加 sidecar，无法满足每盘独立权威，因此不采用。让 SQLite 成为成功权威或从缓存恢复永久事实，也不采用。为当前有界投影新增全套 SQLite VFS 的成本与风险高于内存构建方案；一般 SYSTEM 的 WAL/SHM、并发锁和延迟打开仍须按 0014 单独完成，不能从本切片外推。

详细调用链、命令、资源上限与验收范围见[离线存储切片](../design/independent-disk-journal.md)。实际验证日志独立保留，不以此决策文档代替故障或实盘验收。
