# Rust 1.100 工具链

2026-11-13 按用户要求，将项目固定工具链提升到正式稳定版 Rust 1.100.0，第一方 workspace 最低版本为 1.100，edition 保持 2024。官方发布公告：https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/ 。

CI、构建和发行入口已经从根 rust-toolchain.toml 读取工具链，因此无需另设版本或改 Docker 基础镜像。保留 Cargo.lock、依赖版本、特性、数据格式与 ABI 约束。基础组件各自的最低 Rust 版本不因宿主编译器升级而被伪造提升。

历史验收记录、来源材料和固定旧提交的 A/B 性能载体继续保留原 1.99.0 版本：它们描述当时实际使用的工具链，不是当前构建默认值。若重做性能实验，须新建可比基线，不把旧数字改称 1.100 结果。

本批 GitHub 定向验证选择原生产品消费者、WASM 编译、SMB 协议单测及工具链配置回归。未本机编译或测试；定向通过也不代表 Clippy、rustfmt、Samba SDK ABI、发行 ELF 或真实浏览器验收完成。
