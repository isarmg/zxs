# ADR 0001：完整版本与固定保护路由

状态：当前设计。

## 背景与选择

存储目标是让每个已写版本拥有独立完整正文，并使用户指定盘位的职责清晰。实际保存只产生 FULL 版本；创建分支可以登记冻结来源而不立即复制正文，后续实际写入才生成独立版本。保护副本沿用户指定分层路由完成，不静默转移到其他盘。

## 代价与替代方案

完整写入和同步保护增加空间、复制量与提交延迟；目标盘满或不可用时会拒绝写入。增量版本、跨版本正文去重和自动均衡能减少部分开销，但会引入恢复依赖或改变用户指定路由，当前不采用。Web 与独立 SMB 入口遵守同一存储和保护规则。
