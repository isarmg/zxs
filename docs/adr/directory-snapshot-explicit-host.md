# 目录快照初始化的显式持有目标

状态：隔离实现检查点，尚未编译或测试。未开放 HTTP／SMB 接口，也未实现 worktree 挂载或可写 worktree 发布。

## 准入与源目标对应

`Engine::prepare_directory_snapshot_target` 接受显式类型化目标及调用者持有的私有目录。可信本地调用者仍须分别授权目标，以及目标与已验证逻辑源之间的对应关系；引擎不从 `source.path` 猜测物理路径。

捕获从原永久准入的 `RootBinding` 开始，核对每层目录实体和调用者实际持有的 host，保留原目录描述符。缺少的 `DirectoryId` 只在内存分配，不写文件。当前仍没有 server 生产入口建立此逻辑到物理映射；源和目标各自有效，并不等于已经授权二者对应。

`initialize_directory_snapshot_at_target` 消费该不透明目标和已验证 FILE 来源。新初始化在永久 intent 或仓库暂存写入前拒绝 dirty FILE。已发布结果的重试重新验证原源和目标，不初始化第二个节点。

## 永久证据与物理安装

新 intent 明确为第 2 版，必填字段包含完整根到 host 的 `DirectoryBinding` 链、最终 `DirectoryId`、原 host 实体及原源／目标。既有登记结果与 Candidate 承诺绑定这些确切字节，不建立平行 ledger。第 1 版 intent 材料拒绝、保留，不重写或迁移。原 bootstrap 收据和池 selector 不变。

冷读及实时物料访问只用该确切 intent 构造结构目录，再分别验证独立根权威和原祖先实体。结构目录不能自行授权。准备及验证期间保留原祖先 FD，不能把替换路径认作原 host。固定 `.zxs` 通过既有不可覆盖安装原语及永久决定发布；host 中其他文件和目录不搬移、不删除、不覆盖，也不要求为空。未知管理材料仍是冲突；暂存仍由原管理存储的 staging 权威持有。

这不宣称原子抵御同 UID 管理员的恶意并发改名。原有名称复验及不可覆盖协议遇到拒绝或未知结果时保留材料，不发明替代身份。

## 尚待验证与实现

新增真实文件系统用例覆盖非空嵌套 host、捕获无写、发布前祖先／host 替换、未知 `.zxs`、dirty 来源保全、原操作冷重试和已决定中断恢复。用例均未执行，原根／源／正文／证明回归保持。语法回归另拒绝缺链、父关系／实体／名称变化及旧 intent；语法正确不能替代物理准入。

旧 reader 审阅须覆盖启动登记重放、pending intent 恢复与普通发布验证。严格 intent／登记解码是拒绝边界，但尚未执行全部旧 reader 无写验证。本片不扩展全池第 4 版格式。
