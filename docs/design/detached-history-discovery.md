# 当前目录之外的保留文件发现

接续[永久节点退役](permanent-node-retirement.md)，提供此前只能靠已知 file_id 访问的历史入口。**本片只写出源码，未审查、编译、格式化、测试、浏览器验收或 CI；没有操作真实盘。** 它不自动断开任何引用、不新增删除语义，也不改变共享图拆分条件。

## 发现范围与边界

管理员可通过 `GET /api/file-manager/detached-history` 查询当前已准入仓库历史域中的保留文件。列表逐个保留稳定 file_id，仅包含至少一个 `AVAILABLE` 或 `PURGED` 版本、没有当前 D、且未出现在任何仓库当前主 namespace 的文件。纯 `RETIRED` / `MIGRATED` 身份不在这个可继续浏览的列表中；不枚举未接纳外来盘、独立旧备份或不属于当前仓库历史域的材料。

目录判断使用与当前文件浏览一致的已准入 namespace 投影，不把旧 commit 行当作当前可见目录。完整当前 namespace/历史根无法读取时整页失败，不把未知当作“已脱离”。每个文件按 `(version_sequence, version_id)` 选择一个真实保留版本，仅用其 `creation_name` 显示记录名称。该名称不是当前物理路径或当前逻辑路径；代表版本不是当前 HEAD，版本数也不是永久删除授权。

**仍可能存在阻碍**：其他 namespace 分支、独立目录/Git、路径上下文、工作区、读取租约和完整独立文件分支前沿。本接口不调用删除、不重写这些记录，也不把列表资格标为“可以永久删除”。真正预览和执行仍在原准确历史根重建完整选择、引用和共同决定。普通软删除继续走 D/撤销入口，绝不把 D 文件当作已脱离孤立文件。

## 当前快照与分页

每页最多 100 个稳定文件，按 file_id 严格排序。第一页无游标；下一页必须同时带 `snapshot` 和 `after_file`。快照摘要绑定当前 State sequence、business_generation、所有本次仓库/历史根及当前主 namespace 文件集合。下一页不匹配时返回 `HistoryChanged`，从第一页重读，不拼接两个时点或静默跳项。

Engine owner 锁内只捕获业务元数据与已准入当前 namespace 观察；有界扫描/排序/编码准备在锁外。响应发送前，锁内重新核当前管理员身份、State sequence/business_generation 与同一个当前 namespace publication。SMB 绑定主体不能使用这个管理员发现接口；只读入口不授予 SMB 永久退役能力。

派生读取没有正文 I/O、没有清理、没有写入或新持久索引。它共享既有业务元数据表，不保存认证、operation principals 或永久操作回执。单次最多 8,192 个当前仓库历史域、65,536 个当前文件身份及 65,536 个候选文件身份，累计扫描最多 1,048,576 步。每次下一页仍重新有界扫描，CPU 随保留版本和当前 namespace 总量增长，不宣称增量或 O(页大小)。身份集合、根目录和摘要编码也有上述记录数上界；HTTP 编码最多 1 MiB，超限整页失败，不截断。

## Web 详情与永久操作

“历史记录”页增加明确展开/读取的发现面板，不后台自动遍历全库。读取支持取消、下一页和回到第一页；错误保留具体状态。会话代数、请求代数及回包所有者隔离，旧会话/旧页面的控件不能打开新会话中的其他对象。

打开结果时，Web 使用 `EntryIdentity::Retained(file_id)`，不是伪造 `entry_id`，也不制造目录位置、选中默认分支或可写盘。详情显示“版本记录名称”与保留历史提示；普通编辑、改名、删除、标签/合并和设为默认仍走只读围栏。历史窗口通过原 file_id 获取新的准确当前根，发现页 root 不是旧根租约。

永久退役是独立准入：仅在当前管理员/存储就绪、无未决写入、准确历史已加载、没有目录/文件分支预览、且新历史窗口确认没有当前 path/node 的保留身份上开放显式选择。显示用代表版本不冒充“当前正文”而永久禁选最后节点；一旦窗口发现当前 namespace 路径，则关闭这条保留文件入口。Engine 最终完整检查不变，独立文件 HEAD 必须由原终止证明归档。结果及刷新后的原操作继续使用[浏览器恢复队列](node-retirement-browser-recovery.md)，不因文件离开发现列表丢失操作入口。
