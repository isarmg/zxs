# 从已发布原收据找回节点退役入口

接续 [浏览器原请求恢复](node-retirement-browser-recovery.md) 与 [保留文件发现](detached-history-discovery.md)。本片补在换浏览器或本机记录丢失后，仍持有原 operation_id 且服务端永久决定仍可读取时的受限恢复。**仅生产源码与六项未运行用例，未审查、编译、格式化、测试、浏览器验收或 CI；未操作真实盘。**

## 只读查询，不凭 ID 重新删除

全局面板提供折叠的“凭原操作 ID 找回已发布的节点退役”。用户输入一个类型化原 ID，明确执行只读 `GET /api/operations/{operation_id}/outcome`。沿用现有服务端当前身份和 operation owner 校验，不增加按账号扫描全部操作、不泄露别人的操作、不修改服务端决定。

Web 接纳必须同时满足：当前回包与输入的 operation_id 一致、完整 outcome wire 合法、确已发布、种类为 `file.nodes.retire`，且原 `retirement.request` 完整严格解析为 history_tree_id、history_root、origin_file_id 与非空有界、已排序唯一 version_ids。它使用服务器原请求，不要求当前 namespace、当前历史窗口或原文件仍可见；不从当前版本推测原选择。

404、未知、拒绝、未发布、其他种类、另一个 ID、畸形收据、账号切换或网络错误均不会创建恢复记录，更不会重发删除或新建 operation_id。错误不证明更早的请求从未执行。没有原 ID、服务器缺少原决定或原 owner 不再可认证时，本入口不能恢复。发布未知但此前另存过完整原意图时，可使用[同源原请求文本恢复](node-retirement-request-transfer.md)；该入口不冒充已发布收据，也不自动执行原请求。

## 显式补存与 resume-only 围栏

准确收据先只在本次查询中显示原文件、历史域、根和全部版本。用户还须明确选择“保存准确原请求并打开恢复入口”。这一步只写本浏览器 localStorage 并读回，然后把当前会话取得的原发布收据交既有操作观察器，打开原操作面板。它不执行 POST，不继续正文清理，不恢复或推测旧清理/缺失结论。后续清理仍由用户明确点击原操作 resume，Engine 原授权与完整守卫不变。

新恢复记录采用明确的 `file-node-retirement-resume-recovery` 模式，保存与普通记录相同的主体、原 op/file/root/versions 和显示标签。标签只用真实 file_id，不伪造已丢失的文件名。该模式是**只允许 resume 的限制**，不是保存“已发布”事实：重新登录/刷新后仍为 Unknown，必须从服务端重新取得与全部原选择一致的发布收据才能续作。即使人为触发未知重发确认，也不允许从这种记录发送最初的退役请求；后来出现拒绝也不能据此丢弃它。

首次发送前保存的 `file-node-retirement-recovery` 仍表示原请求，保留其既有准确未知重发语义。两个模式是当前契约的不同用途，不对缺字段或未知格式兜底，不做迁移。已有同 op 且相同主体/file/root/versions 的记录只复用，保留其原标签和模式；异内容或坏记录拒绝覆盖。不会删除、替换其他未解决操作来腾位置。

## 所有者、取消与预算

- 查询和补存控件绑定会话代数、账号、输入代数与原候选；编辑输入、取消、退出和页面销毁取消旧读取。旧响应或旧补存按钮不能改为打开另一账号或另一操作。
- 每次仅一个手动查询，响应复用客户端既有 8 MiB 上限；完整回执以不可变共享值保留，不在每次渲染复制。补存时沿用准确回执匹配。原请求派生记录仍限 64 KiB，最多 32 条/账号和 4,096 个站点键；无后台全库扫描或新常驻索引。
- 浏览器存储禁用、配额不足、损坏、读取或回写失败时显示原错误，保留已存在记录；不把 localStorage 的读取后写入称为跨标签页原子事务。独立键和服务端原幂等边界继续有效。
- 本机记录、发布收据、原分组与正文清理是不同证据。只有新的原义务/当前路由缺失观察，才能按既有规则关闭已发布的恢复结果。它不证明离线旧盘、外部副本、旧认证记录已擦除，也不允许复活退役 file_id。

六项用例源码覆盖：准确已发布请求、未知/错种类/错 ID 拒绝、严格选择和上限、resume-only 在保存/刷新后仍无发布权威、旧会话/输入控件、同请求标签/模式不覆盖与拒绝冲突。未执行真实 HTTP、localStorage、浏览器或 SMB；D/namespace 共同终止、原副本退出/换代和完整物理擦除仍未完成。
