# FILE 的物理位置、跨盘移动与回收

**状态：目标设计，未启用。** [现行产品与验证范围](../file-only-migration.md)。这一设计只适用新建的池；不读取旧格式作为新格式，不重写、清理或迁移现有磁盘。

## 两处数据，各有责任

| 位置 | 持久保存 | 不能用来证明 |
| --- | --- | --- |
| 物理 FILE 容器 | 同一 `FileId` 的正文、全部保留版本、校验材料和文件本地元数据，包括分支、节点、标签等 | 在某盘找到同名文件、同样字节或一份完好的备份，不证明这是当前可写原件 |
| 系统盘 | 已登记的盘及角色、普通目录和父子关系、FILE 的当前归属、原操作和发布／恢复决定 | 有一条数据库记录不证明目的地已实际写好，也不能替代从原容器核对版本 |

主数据盘与专用回收盘都可以物理承载 FILE，但登记角色不同。备份只从登记主数据盘直接发送到指定备份盘。一个主盘可有多个独立目的盘，但不能由一个备份盘再派生备份。备份盘保存可核验副本；不能成为回收盘、日常写入目标，或因数据盘离线自动接管。系统盘不得被同时登记为这些数据位置。角色不能由目录名、同名挂载点或“第一级盘”推断。普通文件夹不是 FILE，其父目录、空目录和名称冲突由登记命名空间管理。

## 一个移动，只发布一个原件

| 阶段 | 必须持有的证据 | 中断后 |
| --- | --- | --- |
| 准备 | 同一原操作与主体、当前原件及其归属代际、两端实际登记和父目录；目标名称可用、容量足够。冻结实际所有保留版本／文件本地材料，检查工作稿和打开句柄。 | 源仍是唯一可见原件，不改变现有目标。缺材料、掉盘、满盘或被换盘时拒绝。 |
| 核验目的材料 | 在目标盘独占暂存整个容器，保留相同 FILE、分支、节点、版本身份和不可变正文。按真实文件重读核验、同步目标与父目录；跨文件系统的新 inode 不是新 FILE。 | 没有系统盘原决定，就不得把暂存当作当前文件。只按原操作辨认临时材料，不接管同名或同字节对象。 |
| 发布及善后 | 系统盘以同一次决定更新原 FILE 的唯一归属与名称；核对准确的目标容器和原实体后，才能退役源实体。 | 重试返回原结果或继续原事务，绝不重配 FileId。无法核对两端时封锁冲突位置、保留材料；不能靠猜测删除源。 |

显式 **COPY** 才会建立另一份独立 FILE，源仍有归属；MOVE 内部的字节复制不是一次公开 COPY。HTTP 与 SMB 必须使用同一原生移动决定。SMB 只有收到明确代表移动的请求才可走此路径；不能把客户端独立的读、写、删除三件事认作一次移动。已打开的只读句柄不得读错版本；处于未确认写入的句柄不得越过交接继续写新所有者。未证明这些约束的范围先拒绝，不丢弃工作稿。

用户软删除把**原**容器转给明确登记的回收盘，同时撤下原路径；恢复要核对同一未消费的删除决定和有效的普通目标。回收盘未配、离线、已更换或不足以保存完整原件时，无法完成删除，原路径与内容不变。恢复遇到重名不得覆盖。整目录操作先确认本次全体 FILE、空目录与父子关系，不能移动一半就报告全部完成。普通 SMB `rmdir` 的空目录语义不因此成为递归删除。失败的上传、未决定的暂存、无关文件不进用户回收站。本设计不改变单版本保留、单节点退役或永久清除的规则。

## 接入顺序与验证

1. **根登记与启动：**契约和引擎先区分系统、当前 FILE、备份、专用回收角色；第一步仅在内存中检查证据，不更换实际写盘格式。后续在同一格式变更中一起替换 CONFIG、seal、根／FILE 登记、启动及重开。不能只改 `persist/layout.rs` 的目录名；`contract/namespace_root` 与 `contract/file_container` 还保存旧子目录身份。
2. **原件与决定：**FILE 层验证原容器和全部材料，系统盘记录转移前后归属。保留现有 `fresh_layout` 拒绝开关直至原操作、当前登记、不可变历史与物理核验在热发布和冷重开相符。既有 `business/object_move` 的跨根复制分支、或把文件标为已删，不能签发新移动。
3. **备份与入口：**备份规划与归档只接受指定主盘到直接备份盘，拒绝链式任务与档案，不把回收盘或系统盘作为来源、目标或替代盘；HTTP、SMB、Web 按实际请求检查双方权限、来源、原请求和冲突。先在全新临时盘测一个已发布 FILE，再扩至普通目录组、回收与恢复；这些操作没有原生决定前，不得从其他入口替代执行。
4. **逐个断点验收：**验证准备前、半复制、目标已同步、已发布但源未退役、清理后五个中断位置，冷开及重复原请求。另测换盘、重名、余额不足、相同字节但不同 FILE、未确认写入、整目录未齐以及只读备份。核对全部版本和唯一可写归属，而不只是当前文件的散列或服务端返回码。进程内分发、真 HTTP、系统 Samba 分别记录，不能互相代替。
