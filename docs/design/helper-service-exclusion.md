# 当前 ZXS 二进制与辅助工具的生命周期互斥

辅助工具仅在 ZXS 停服时运行。初始化、添加、注销、重新接纳、外来盘处理、检查、导出、恢复及配置均在同一进程生命周期租约内；处理结束并退出后，才可启动 ZXS。源码接入不表示全部功能或部署已经验收。

## 当前可执行程序的强制入口

当前 `zxs` 可执行程序不再只依赖操作人声称“已停服”。它在创建 Tokio runtime、打开管理状态/Engine 或绑定监听端口前，对固定 `/zxs` 目录 inode 取得非阻塞 OS 排他锁。目录必须已存在、root 所有、不可被组或其他用户写，路径拒绝链接；缺少、权限不符、争用或必要内核能力不可用均清楚退出，提示手工运行 helper，不偷偷创建管理状态。

租约 owner 放在同步 `main`，位于 `run_with_runtime` 之外。后者返回意味着 Tokio 已结束并等待阻塞池；启动失败、HTTP 退出或信号结束也不会提前释放租约。不会等待一个超时后强杀持久工作并假称退出成功。退出前重核根路径身份；根目录存在不是“系统已经初始化”的标志。

这是当前产品**单主机单 daemon**的固定入口围栏，不提供通过 CLI 自选另一锁路径绕开它的参数。`platform_io::service_lease::ServiceLease` 是共用的目录 fd/所有权/OS 锁能力。通用 `acquire` 支持明确目录与 owner 政策，但生产二进制使用固定 `host()`；不创建、删除或轮换锁文件。

## 辅助工具全生命周期

`zxs-helper` 在命令业务或 HTTP runtime 启动前取得同一 `/zxs` 排他租约。主线程保有 owner，直到 HTTP 请求、流式读出、阻塞任务和内部维护子进程全部结束。空闲控制台也持有租约；ZXS 已运行时工具不能进入业务，工具尚存活时普通 ZXS 不能启动。帮助和参数解析不打开业务资源。

同一已准入进程复用一个已锁定目录能力，不为每次操作重新竞争自己的锁。只有显式内部维护入口接收继承 FD，普通 daemon 仍独立取得锁，不能靠环境变量选择另一租约。内部子进程共享同一 open-file-description；最后一个持有人关闭后释放锁。固定系统程序不继承它。

显式启动交接先核对离线安装、单元与原请求，可按选项设置开机启用而不启动。成功响应是 `helper_exit_then_service_start`，只表示交接已受理，不表示服务已运行或可用。随后关闭新请求入口，等所有 owner 结束，主线程用固定 `systemctl start` 替换 helper 进程；CLOEXEC 在替换时关闭租约。ZXS 与可选 Samba 在此后启动。工具不再存活等待管理 ready；启动结果由终端/systemd 和启动后的 ZXS 查询。

原请求状态只在离线工具内读取，`offline_ready_for_handoff` 表示当前前提可进入交接，不是在线健康结论。未知结果不自动重复交接。

## `/zxs` 首次根目录准备

独立 Web 增加“准备安装根与运行互斥”，CLI 为 `host preview` / `host prepare --request-digest <摘要> --confirm-host-root-only`。

root 首次启动工具时准备固定目的地、root UID、0755 的互斥根并接管其已持有锁；`host preview/prepare` 保留为幂等核对入口。仅准备该根目录，**不创建 Unix/Samba/管理员账户、不初始化数据库或磁盘、不修改 systemd/SMB、不停止或启动服务**。不存在时在 `/` 的确定 pending 名内创建空目录，核验为空并持有未来 daemon 的 inode 锁，同步后 `RENAME_NOREPLACE` 发布为 `/zxs`，同步父目录后将同一锁移交工具生命周期 owner。非空 pending、链接、不同权限、冲突和不确定发布均保留证据，不强行清理。

已有安全 `/zxs` 仅核验身份/权限并同步，不修改其内容；已有业务数据不会被重置。准确空 pending 可按同一预览摘要重试，包括初始 mkdir 后留下的 root 所有、0700 阶段；在父目录锁、空性、原 inode 和未来 daemon 锁核对后，只将这个未发布 inode 完成到 0755。非空 pending、其他 owner/mode、既有 final 权限不符、目标与 pending 同时存在均保留拒绝。本次中断窗口修正未编译、未执行测试或真实主机操作。

此准备结果保持 `system_initialized=false`、`service_stopped_or_started=false`，租约持续到工具进程退出。历史回执不是永久停服票据，后一次运行仍须重新取得排他租约。

## 仍未涵盖的边界

1. 老二进制、不使用当前可执行入口的库嵌入者、Samba/passdb、独立设备写者和第三方进程没有自动加入此协议。升级与维修前必须明确停止这些写者；本片没有通过 `systemctl is-active` 或进程名扫描推断它们已停。
2. root 管理员可换挂载或重绑目录。租约保持的是 inode，不能阻止 root 绕过协议；活动期间不能重绑 `/zxs`。关键调用点可 `recheck`，不把旧 fd 当新名字永久证明。
3. `/zxs` 准备不是完整首次初始化准入。[普通首启前置门禁](helper-normal-start-prerequisites.md) 已在源码接入：现有根、配置和当前首次激活证明不满足则不启动 runtime。helper 已有管理账户/首批存储及服务身份工作进程，但全路径“已正式纳入且一致”、完整新机安装、SMB passdb 与外部 Samba 写者验收仍待完成；不先删除未迁完的共用恢复入口。
4. 未运行真实 daemon/辅助工具争用、进程信号排空、断电或目标部署验收。本轮补充租约共享/继承和退出交接回归；Rust 编译、真实 daemon/辅助工具互斥与 systemd 交接由准确提交 CI 验证，不以静态检查或前端替身测试代替。
