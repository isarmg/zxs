# 同域文件共享内容与联合图投影

[文件节点与分支](file-merge-tags-backup.md) · [现有窗口协议](../adr/0009-bounded-file-history-windows.md) · [API](../15-api-and-errors.md)

## 本片提供的行为

文件详情可以请求当前历史域的自动联合图，不再需要逐个选中正文节点来查候选。核心从来源文件的**全部保留版本**出发，以非零长度和完整内容摘要相等连接其他文件，再沿新加入文件的全部版本继续扩展，得到包含来源文件的完整连通分量。例如 A 与 B 共享 X，B 与 C 共享 Y，查看 C 同样能看到 A、B、C。空文件不产生共享关系。

联合图不合并稳定 `file_id`，不改分支归属、HEAD、版本、内容父证明或磁盘副本。每个实际正文、改名和合并节点保留原身份；文件分支也保留自己的身份、名称、状态和合并别名。容器标签不属于节点，删除与恢复是独立生命周期事实，不插入内容祖先图。软删除只冻结原文件，新文件和它的保留节点匹配后加入联合图，并不因此失去普通编辑资格。

正文清除、迁出或临时不可达不等于历史节点消失。查询只使用已准入的不可变元数据，不打开正文；`PURGED` 和 `MIGRATED` 版本仍可展示，`AVAILABLE` 不承诺当次健康。删除记录不伪造一个无正文图节点；软删除文件的原内容节点继续保留。新文件与已软删除文件的保留正文相同，也自动进入同一投影。单个正文被清除不会拆开仍有保留关系的文件图。

本片是**自动推导的同域联合投影**，不是永久关系写入协议。没有新增 State 字段、SQL 权威表、磁盘格式、迁移、正文去重或共享副本。永久解除关联、权威节点彻底移除后的结构发布、跨历史域联合、各磁盘退出状态的完整投影和系统盘单独恢复能力仍未闭合，不能从这个只读图宣称它们完成。现有磁盘身份、发布和恢复准入不改变；SQLite 缓存不提升为恢复权威。

[永久节点退役](permanent-node-retirement.md)片新增受限 Engine 真实发布与冷恢复闭包。只有认证 `RETIRED` 才从有效版本/耦合事件域移除并重新计算这里的联合分量；普通 PURGED/MIGRATED 仍保留关联。旧不可变描述保留为认证证据，HTTP/Web 删除动作与全部介质擦除尚未实现；本轮新执行源码未运行。

## 共享关系不是时间祖先

不能直接按摘要折叠历史事件。一个文件可以经历 X → Y → X；不同文件也可能以相反次序出现相同字节。把这些事件变成一个节点会制造循环或丢失真实父边。

协议分别返回：

- `nodes`：真实内容相关节点及同文件祖先边，保留独立节点 ID。每项必须引用其所属文件的 `version_id`；`fdel_` 身份、`deletion` 种类和空／缺失版本被严格拒绝。删除时冻结的分支前沿不是图父边。
- `versions`：真实正文版本和持久内容状态；元数据节点复用这些版本，不伪造新的 FULL。
- `shared_contents`：非零 `(content_hash, logical_size)` 的完整等价组，必须包含至少两个不同文件。每个组列出全部参与版本，不是新的持久节点 ID。
- `files` 和 `branches`：独立身份和命名分支。`creation_name` 仅为版本创建记录名称，不是当前路径；`sequence` 是各类记录原有序号，不作为跨文件时间证明。

浏览器为等价组创建仅属于当前面板的关系 hub。原祖先连线有箭头，指向子节点；共享关系线无箭头，不声称先后或来源。父节点仍在下，子节点在上，复用原正交、圆角连接几何。用户可以选联合视图、本文件或另一关联文件，选择只过滤本面板，不替换文件列表选中项、不变更默认分支或写入草稿。

## 授权、快照与界限

`GET /api/file-manager/files/{file}/shared-history?history_root=...` 只接受准确文件 ID 和当前根。复用历史窗口的对象归属及当前路径上下文捕获，锁外准备，回锁后重新检查当前身份、上下文和 exact root；HTTP admission slot 持有到编码响应释放，取消信号传入各扫描循环。旧根不成为可长期读取的租约。

当前唯一管理员已准入的**同一 history_tree_id** 是本片范围。跨历史域文件即使摘要相同也不进入此响应，不能拿一个域的根证明另一域的授权或新鲜度。普通文件历史窗口不会自动执行这次全域索引，只在打开／刷新联合图时运行。

Web 对响应重新验证来源、根、全部 ID 顺序和唯一性、文件及版本归属、父边端点、无环祖先、分支头、完整等价组和连通性。源文件、路径、根、会话改变或收起／卸载会取消旧请求。当前会话 401 先于旧回调判断处理；同根普通历史翻页不重置联合图自己的过滤选择。

## 资源与失败语义

| 单请求限制 | 上限 |
| --- | ---: |
| 索引的同域正文版本 | 65,536 |
| 扫描计费总记录，含全局头、正文成员、父记录和分支条目 | 1,048,576 |
| 连通分量文件 | 64 |
| 内容相关节点（正文、路径及元数据合计） | 512 |
| 独立文件分支 | 256 |
| 去重的同文件祖先边 | 2,048 |
| 编码 JSON | 1 MiB |

越过工作、索引或图预算返回 `429 RESOURCE_LIMIT_EXCEEDED`，不返回“没有关联”或貌似完整的局部图。编码超限为 `RESPONSE_TOO_LARGE`；未知／重复查询字段为 400，失效身份为 401，归属不存在为 404，根改变为 409。上限只约束这个联合查询，不裁剪永久历史，不限制普通历史窗口或写入规模。

索引和图只属于当前请求，按保留元数据构建，不跨根缓存。每个相关文件和内容等价桶只扩展一次；CPU 包含全局扫描及有界有序索引成本，不能宣称 O(页大小)。新增空间 O(同域索引版本 + 返回节点 + 祖先边 + 分支)，均受上述上限约束。没有新写入、fsync 或正文读取。

## 删除事实与内容图脱钩

删除写入本来不推进内容版本或文件分支 HEAD。普通 Nodes 页只读取版本、路径与元数据，
不接纳 D。本轮移除共享图服务器额外插入的 D 节点和由冻结前沿生成的图边，并收紧共享
契约及通用 `FileNodeId`，不是浏览器静默过滤旧图。Web 投影只消费已准入的必填版本引用。

独立 `FileDeletionId`、现有持久删除事实、完整分支前沿、永久收据、FILE 审计、精确撤销
及生命周期接口保持。`fdel_` 可以标识删除记录及其恢复目标，不能作为内容节点、分支 HEAD
或图父边。未改任何池／备份格式或写入步骤，不为结构命名再次断代，也不自动迁移或删除数据。

真实回归比较删除、冷重开、恢复、再次冷重开之间的版本、分支 HEAD、父关系和共享图事实；
历史根和当前可见性允许随发布改变。软删除冻结、其他同内容文件可继续编辑、取消及授权
仍分别验证。保留删除记录的分页和精确恢复，不将冻结前沿画成指向 D 的内容祖先边。

这是删除的图语义收口，不表示改名／合并非内容节点已退役，也不是完整操作时间线。
本地未编译、测试或运行格式化器。真实 Chrome、完整池恢复与未选的其他图／介质
矩阵不在本次执行证明之内。
