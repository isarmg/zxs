# 指定本机配置替换：只读预览边界

原决策设计：`d1bab7139398fec6d46850ee528c21851b04b7f5:docs/adr/helper-current-configuration-replacement.md`。这份说明只覆盖第一段源码，不表示跨目录交换、撤销、关闭窗口或实际系统验收已经完成。

本机手动运行 `zxs-helper deployment replacement-preview`，指定现有服务用户、组和生成参数；只有同时选择 Samba 用户与 peer UID 才会纳入 Samba 配置。命令没有目标路径、旧正文或 shell 参数，不能从 Web 发起。固定目的地只有 `/etc/systemd/system/zxs.service`，以及本计划选择的 `/etc/samba/zxs.conf`。缺少目标的情况不能通过这个预览补成首装。

- real/effective UID 都必须为 0。只获取已存在的 `/zxs` 生命周期租约；普通 helper 可准备缺失根目录的行为不能用于此命令。
- 持有已核对载荷、账号与组原件、固定父目录锁和两个已选目标的独立只读 FD。文件必须为 root 所有、单链接、0600/0644、最多 64 KiB，文件名不能跨过父挂载点。不把原内容返回、写出、做成备份字节或带到错误中。SHA-256 在原 FD 上以固定小块计算；两端核对身份、权限、长度和时间戳，签发前再核对原名与同一个 inode。
- 只通过持有的 systemctl 查询约定单元的停止状态。观察到有进程、过渡状态、任务、残余控制组、待 reload、覆盖或外部触发器等情况会拒绝；缺少属性、未知输出或失败也不推定停止。不查询启动命令、环境变量或旧配置内容。不能把这些读数当作对其他 root 管理员、外部服务或编排器的排他权。
- 预览包含原件属性／摘要、新生成的非秘密内容／摘要、同版载荷、已保持的固定资源及新操作 ID；不建立活动指针、保存原决定、准备新文件、执行交换或改变服务。固定活动名已有证据时不签发另一份预览。内外管理员必须留意：原计划的保全方式是同一文件系统上的原 inode，并非另一介质的备份；两处交换不具有整组原子性。

输出明确标记 `read_only_preview` 与 `apply_or_undo_available: false`。这个摘要不是“已经替换”或“可以启动”的证明；实际原件、完整资源、保持停止状态、持久决定和分阶段读回仍是后续写路径必须满足的前置条件。
