# SYSTEM 准备镜像的完整只读回验

## 实际缺口与入口

隔离的三范围准备已经能按完整原生来源生成 SYSTEM、盘根和对象库。文件／目录及盘根编码器有完整解码核验；SYSTEM 的 `index::preparation::encode_state` 原来在事务写入、序列化和关闭成功后直接返回字节。它没有从实际序列化镜像重新核对全部投影，不能借其它范围或 SQL 写入成功证明这一份完整。

本片在这个共享准备出口增加一次独立只读内存回验。编码连接先关闭，随后将实际返回镜像送入新内存连接；所有检查成功才交回原调用方。没有打开 `index.sqlite` 路径、修改活动索引、创建临时磁盘文件、安装数据库或新增同步。

来源权限不改变：普通准备仍接原 `AdmittedState`；move 的草稿／未接受 Candidate 仍走原独立入口，回验只比较它们自己的冻结 State，不能将其升级成已接受或已发布状态。备份／外来准备中的来源证明、原身份、全体成员、原操作及最终决定由原调用者负责。没有新 CLI、HTTP 接口或可直接传入任意 State 的公开恢复 API。

## 检查闭环

1. **闭集 schema**：恰好四张既有表及六个既有索引，包含三个 SQLite 主键自动索引。名称、类型、所属表和 DDL 都按当前格式逐项一致；未知表、视图、触发器或索引拒绝。读取 schema 字符串使用有界 BLOB 前缀，不因尾部 NUL 隐藏额外内容。
2. **物理完整性**：复用已有有预算的完整 `integrity_check`，不是省略索引／表对应检查的 `quick_check`。页或索引损坏不能靠有序查询读到的子集蒙混过关。
3. **全局头和版本成员**：`current_state` 必须只有一条准确原序号；完整 `file_history_versions` 的 ID、文件／历史身份和 8 字节版本序号均对应原 State，最终物理表计数也必须一致。完整 u64 不改为 SQLite 有符号整数。
4. **六族历史 scope 成员**：按现有单一成员规则核内容、路径、元数据、命名空间提交的每个原条目位置、文件分支和合并；每个原成员完整匹配，最后核全表计数，不能只靠数量或保留一部分 scope。
5. **39 族全局记录**：按现有统一字段声明和原 State 顺序核 operation、原路径事件、34 族业务 catalog、原 principal、按原数组位置保留的事件及三项 State 代数。逐条比较原序号和规范 JSON 字节，再核整个 `system_changes` 表计数。额外记录、漏项、改写主体、同长度不同正文和相同序号下不同 State 都不能通过。

期望身份和载荷来自调用方冻结的 State，不来自 SQLite 自摘要或完成标记。catalog 的完整族列表由原宏声明派生，新增 State 字段仍须通过原明确投影／排除规则；没有另抄一份 business 字段名单。`control_auth` 的认证秘密仍不进入非秘密 SYSTEM 投影，回验不会补存它或声称仅凭此 SQLite 可恢复全部权限。

完整读回比较的是投影语义，不要求 SQLite 页布局与某次重编码相同。**原消费者对实际持久字节、摘要和物理身份的承诺仍完全保留**；本片没有放宽备份／外来材料的逐字节校验，也没有让另一个布局的文件替代已冻结目标。

## 失败、成本及恢复边界

任一检查或取消失败，编码入口返回具体失败，不交出部分通过的镜像。SQLite 原始错误、校验错误与关闭失败均保留；回验连接关闭后不留下路径、sidecar 或持续读取租约。已有原文件、完成标记及持久意图不由这里删除或修复。

原 State 与镜像的 64 MiB 上限保持；连接复用 64 MiB 值上限、4 KiB SQL、100,000 编译 VM 操作与 16 个参数限制，物理扫描另复用约千万执行步的已有预算。预算失败明确拒绝，不裁剪记录，不代表所有 64 MiB 合法输入都已证明在该执行预算内。取消在各行及物理扫描前后检查，不是墙钟超时或 SQLite 内部所有 CPU 指令的硬上限。

成本新增一次镜像内存副本、一次物理扫描和全部预期行的索引查找；全局顺序还暂存有界键索引，单条载荷按原 State 长度限制后读取。原编码连接已先关闭，没有同时保留两份 SQLite 连接，但 source State、原镜像、只读镜像、键集合和临时规范载荷仍会同时占内存；64 MiB 不是总 RSS 上限。时间约为 O(页数 + 记录数 × log 记录数)，大规模耗时和预算余量未验证。没有增加磁盘 I/O、fsync、后台线程或普通在线查询的全量 scrub。

通过只说明这一份准备 SYSTEM 代表指定 State 的既有非秘密投影。它不证明当前权威、最新 publication、正文可用、其它盘完整、三范围共同原子切换或任意单盘独立系统恢复。尤其未接受 move 状态仍未接受，外来原身份数据库仍不是当前池联合身份数据库。
