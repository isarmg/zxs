## 4.1 支持矩阵

用户通过 Web 或独立 SMB 访问。Web 在受支持浏览器内通过 HTTPS 业务 API 使用文件及高级功能；SMB 客户端独立连接 Samba，访问主分支基础文件。二者的连接与工作状态分别管理。`zxs` 直接启动服务；首次初始化及日常管理使用受保护 Web/API。`zxs-rescue` 仅提供离线救援、历史包和配置草稿操作，不提供远程客户端或普通文件上传下载。

| 平台或入口 | 访问实现 | 功能范围 | 保存规则 |
| --- | --- | --- | --- |
| Web（桌面及移动浏览器） | 本项目实现的 Rust/WASM 界面，经 HTTPS 业务 API 连接 | 文件浏览、元数据、版本树及获授权管理；无文件上传、下载、预览 | 元数据事务发布至明确选定范围；正文写入由 SMB 或受控 HTTP API 完成 |
| SMB（桌面及移动端） | 独立 SMB 协议连接至 Samba | 浏览、打开、新建、编辑、复制、移动、改名及删除当前文件 | 共享绑定稳定主命名空间，按用户选择的默认目录组成和文件引用保存 |
| 本机救援工具 | `zxs-rescue`，打开本地池前须停服 | 离线恢复、证明核验、单版本导出、历史包与未初始化配置草稿 | 遵守本机信任、核心业务约束及恢复证据规则；不提供日常管理、账号重置或远程客户端 |

Web 仅支持满足[现代浏览器能力契约](components/interface.md#modern-browser-contract)的浏览器，不承诺旧版本兼容；缺少必需 API／CSS 能力时明确拒绝启动，而非静默降级。

浏览器验收记录具体浏览器版本、操作系统、视口、文件浏览、元数据编辑、版本树、会话及网络结果。SMB 验收记录具体客户端、操作系统及 Samba 版本。Linux、Windows、macOS、Android、iOS、iPadOS 等操作系统只作为实际浏览器或 SMB 客户端组合的测试环境，不形成原生应用、SDK、安装包或后台服务交付承诺。

<a id="s04-02"></a>

## 4.2 SMB 只提供基础文件能力

SMB 提供浏览、打开、读取、新建、编辑、复制、移动、重命名、删除当前文件，以及必要锁与错误返回。通过 SMB 保存进入共享主命名空间所选的默认目录组成，按该文件的继承意图或明确分支写入，后台按全量版本和指定备份路由处理。

SMB 协议不提供分支选择、历史图、版本比较、历史内容清除、合并、树拆分或硬盘分配。Web 显式改变共享默认目录组合或其文件引用时，后续 SMB 操作使用新组成，但不更换共享绑定，既有句柄仍受原读取版本或写入基线约束。旧 `MergeLink` 只标记关系；文件分支合并 `FileBranchMerge` 可采用已有正文并推进参与目录引用，随后 SMB 读取相应新组成，见[合并规则](design/file-merge-tags-backup.md)。

SMB 删除仅删除主分支当前目录项，不能解释为清除其历史内容。SMB 不发布可写历史快照目录，也不以特殊文件名开放高级管理。

<a id="s04-03"></a>

## 4.3 Web 与 SMB 的职责

当前 Web 页面提供文件浏览、元数据管理、版本树与历史查看、分支创建、文件分支合并，以及已实现的备份配置和账户/状态入口。旧 `MergeLink` 关系标记、历史内容清除和树拆分已有获授权管理表单，后两者要求审查预览并按摘要明确提交；提交比较仍通过受控 API 提供。操作是否可执行受核心支持范围约束，不能因为表单存在就认为所有历史域都能拆分。逐项表单与端点映射见[日常管理覆盖](components/daily-management-coverage.md)。目录分支合并尚未实现，也不能把旧关系标记解释为整树内容合并。当前页面范围以[Web 组件说明](components/web.md)及对应源码为准，不能将核心 API 存在等同于 Web 已交付。

Web 工作区明确绑定历史树和分支。SMB 通过独立协议入口访问共享主命名空间。工作区自身的分支绑定与共享默认选择分别管理；显式修改共享目录或文件引用可以影响后续 SMB 视图。两个入口分别管理连接和工作状态，服务端统一仲裁并发访问。本机救援工具遵守本机信任、核心业务约束及恢复证据规则；打开本地池的维护操作须先停服。

Web 不提供文件上传、下载或正文预览，也无传输任务页。文件浏览、元数据编辑、页面关闭、会话过期及网络中断分别验收；元数据操作明确展示服务器发布结果。SMB 客户端的编辑器保存模式与断连恢复按实际组合单独验收。

<a id="s04-04"></a>

## 4.4 按需打开与断网处理

SMB 基础读取及受控 HTTPS 内容接口支持按范围请求；服务端协议保持不变，但 Web 产品不调用正文接口提供文件预览或下载。

文件正文通过 SMB 客户端读取与保存，受控 HTTP API 保留正文传输能力；CLI 不再提供普通正文传输。SMB 关联应用可能需要完整本地内容，按其实际机制读取。系统不能保证所有文件类型或客户端均支持流式打开。

Web 断网时展示请求失败或结果未知；重连后先查询原操作状态和基础版本，避免重复提交。页面内状态或浏览器缓存不构成离线写回承诺。SMB 服务端保留已接收但未确认完成的工作数据。两个入口都以服务器结果判断保存是否完成。
