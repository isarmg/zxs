Web 是统一的浏览器用户界面，文件操作及获授权的高级功能均通过 HTTPS 业务 API 提供，布局适配桌面和移动浏览器。独立 SMB 入口由 Samba 和服务端桥接提供。本机命令行只提供 `zxs` 守护进程启动及 `zxs-rescue` 离线救援、未初始化配置草稿；首次初始化与日常管理通过受保护 Web 完成，初始化所需盘位白名单和引导授权仍由本机操作员预置。项目不提供远程管理 CLI。

## 16.1 用户界面

文件根目录以已登记磁盘根路径的最后一级目录名展示独立磁盘，例如 `/abc/a`、`/abc/b` 显示为 `a/`、`b/`。Web 列表的 `name` 是经过 PortableName 校验的展示名，HTTP 操作仍使用稳定 `slot_id`；SMB 默认共享以同一目录名寻址，仍仅公开一级盘。Web 保留备份盘只读语义。目录名不合法、非 UTF-8 或按固定 Unicode 查找规则冲突时明确报错，不截断、改写或回退到槽位名。此投影不登记磁盘、不初始化目录、不更改副本关系或持久化身份。

首次激活和新增磁盘在保存新意图、初始化数据目录前，对目标配置的全部磁盘根使用同一名称解析与冲突检查，包含备份盘。例如同批 `Disk/` 与 `disk/`，或新目录与已登记根的查找键相同，均先拒绝，保留原目录与已有池。只读发现和单目录身份检查不代表整组名称已可公开；已有来源仍可进入另行确认的转换流程。读取既有配置时继续明确报告非法或冲突名称，不自动重命名或迁移。

| 区域 | 展示内容 | 必要约束 |
| --- | --- | --- |
| 连接与磁盘入口 | 服务器身份、在线状态、各独立磁盘目录 | 未认证不泄露私有内容；磁盘不作为分支选择器 |
| 文件列表 | 当前磁盘、面包屑、文件夹、文件、大小、搜索和常用动作 | 新建文件夹、重命名、删除及元数据管理围绕当前目录；不提供文件上传、下载、正文预览；副本盘明确只读 |
| 文件详情 | 所选文件容器、备注、分支、节点历史、标签、文件分支合并和保存状态 | 分支绑定该文件；合并显式确认参与head、结果与归属，规则见[补充说明](design/file-merge-tags-backup.md)；版本树与正文状态仍可查看，正文读写不通过 Web |
| 目录分支 | 稳定命名分支和不可变子树 | 创建引用共享文件分支，修改/子项选择先持久化暂存；用户填写说明显式提交目录及子目录后才增加目录历史；默认根组合可由已认证的唯一管理员选择并供 SMB 读取 |
| 状态 | 简单 CPU 使用率、内存用量和各磁盘容量/在线状态 | 只显示真实采样；未知值显示不可用，不伪造零值或趋势 |
| 历史记录 | 文件路径、动作、作者、顺序和可用时间 | 不拿传输任务或硬盘列表代替文件操作历史；旧记录无时间时明确未知 |
| 高级历史工具 | 历史域、旧MergeLink关系线、拆分来源、PURGED节点 | 不在默认文件页面展示低层仓库/计划表单；旧关系标记与文件详情的FileBranchMerge分别处理，目录分支合并待用户确认 |
| 提交历史 | 版本父节点、合并关系、作者、时间、操作摘要、目录差异 | 内容已删仍显示节点；时间不代替日志顺序 |
| 管理与清除 | 来源映射树、盘位/换盘、容量来源占比、清除和拆分 | 用户审查固定目标及迁移范围；均衡只建议不自行改路由 |
| 恢复 | 文件/目录恢复预览、容量和名称冲突 | 历史保存登记新分支，仅实际写入产生 FULL，其余继承父版本，不覆盖主分支 |
| 错误中心 | 原操作、错误码、可恢复状态和请求 ID | 不只弹一次短暂通知后丢失错误 |

## 16.2 文档打开方式

Web 打开文件详情只展示元数据、分支与版本树，不读取或预览正文，不提供上传、下载或“写入当前分支”入口。SMB 按标准协议提供文件读写，关联编辑器与文件交接由 SMB 客户端处理，并按实际客户端组合验收。

文件正文通过 SMB 或受控 HTTP API 读写；这些接口不因 Web 入口移除而改变。不能绕过认证及业务约束或改成从物理盘直接共享路径。项目不提供原生 App。

<a id="s16-03"></a>

## 16.3 本机维护入口

正常入口直接运行 `zxs`，日常管理和首次初始化使用 Web。离线工具以[救援说明](components/rescue.md)及 `zxs-rescue --help` 为准，保留系统恢复、单盘核验/隔离导出、受限降级恢复、历史包和未初始化拓扑草稿，不提供远程客户端或普通文件传输命令。

高级自定义配置文件只可由本机预置给服务，再由受保护 Web 引导选择。不接受浏览器任意路径或任意配置 JSON。线上换盘和拓扑迁移不因有草稿编辑器而视为已经实现。内容清除、树拆分及其他维护计划必须先审查预览，再携带摘要和明确确认执行。数据引擎失败不取消管理面认证，也不阻止系统盘上的 Web 管理服务运行。
