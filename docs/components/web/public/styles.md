# zxs 公共样式

`src/web/styles.css` 是浏览器样式入口；构建后为 `/zxs.css`，只负责令牌、字体、产品排版和组件导入。`components/index.css` 明确按「共享几何 → 组件行为 → 外观 → 登录 → 页面布局」导入，所有路径相对 CSS 文件，不依赖 CDN。已移除没有运行引用的旧侧栏、磁盘卡片、时间线、ESM 页面与日期表单样式。

发布构建将上述本地无条件导入按原顺序折叠进 `/zxs.css`，源文件和 public 中的独立 CSS 仍保留。相对资源 URL 按原 CSS 的发布位置重定位；不裁剪样式或字体，也不改变 G4／CSP／主题契约。`styles/startup.css` 继续独立提前加载。支持的导入语法、拒绝边界和收据规则见[Web 构建工具](../../../tools/web-build.md#css-release-bundling)。

- `tokens/`：字体别名、间距、明暗主题、作用域 reset、标签隐藏、键盘焦点和减弱动态效果规则。应用根使用 `data-zxs-scope`，主题写入 `html[data-zxs-theme]`。
- `components/geometry.css`：唯一业务几何层，集中尺寸令牌和可组合布局角色；页面不重新声明行高、字体比例、灰框、G4 角范围或首字内缩。
- `components/base.css`：共享壳、表单、表格、对话框、通知的基础行为；`content-blocks.css` 仅负责主题配色及 hover、选中、禁用等视觉状态。
- `components/auth.css`：登录与首次建账在同一外卡内切换，都是账户名、输入、密码、输入、信息、操作六行。行高直接复用 `--zxs-compact-row-height`，外卡宽九行，六个网格轨道提供至少六行高度，正常桌面空闲态为 3:2；窄屏可以收窄；外卡存在 `.zxs-error` 时显式解除首选比例，使用 `aspect-ratio: auto`，让必要长错误、请求标识和换行操作自然撑高外卡，不裁切或覆盖。外卡保留初版 48px G4 圆角，不改登录后共享内容框。内部没有字段组边框、按钮框或提示框，文本输入平时无下划线，输入与按钮键盘焦点均为 3px 实线下边。主题和语言控件仍在外卡外的独立顶部行。未设置账户的提示行仅显示“请设置账户名和密码”／“Set a name and password.”，正常桌面信息行保持共享行高；必要错误与未知结果提示在同一行替换。“设置账户”提交即表达创建意图，不另设确认复选框。状态重查、清除输入和未知结果下尝试登录位于操作行，既有账户正常只显示登录动作。
- `components/file-manager.css`：磁盘目录入口、可换行面包屑、工具栏、文件列表、文件详情和文件分支历史。磁盘不作为分支选择器。
- `components/history.css`：已提交文件操作的紧凑列表、硬盘筛选及正常窄屏下的分行。
- `components/system-status.css`：CPU、内存、磁盘容量及可用功耗采样的实时信息与历史折线图；状态卡统一为 3:2，桌面固定四列，最后一行不足四个仍占单列尺寸，手机每行一个。
- `components/transfers.css`：本次登录的传输任务、状态筛选和可展开操作详情；复用公共 row/frame/stack，长文件名与路径自然换行，手机属性单列，页面壳保留设备安全区。
- `startup.css`：资源加载失败时的可读错误视图，使用 `data-zxs-startup="failed"` 和 `#zxs-startup-error`。

连续轮廓统一使用 `--zxs-contour-*`、`data-zxs-contour-*` 和 `.zxs-contour-*`。CSS 声明轮廓范围，Rust 控制器负责实际绘制及裁切；没有控制器时保留可用的方形表面，不用普通 `border-radius` 模拟连续轮廓。`Select` 使用复制的触发器、箭头、选项及弹层样式；弹层在顶层显示并等待轮廓绘制，避免被文件详情容器裁切。

页面保留业务类名供行为和浏览器定位使用，几何由以下共享角色决定：

| 角色 | 作用 |
| --- | --- |
| `.zxs-stack` / `.zxs-stack--flush` | 单列内容栈，默认不增加外部间距；flush 保留为连续内容的兼容角色 |
| `.zxs-flow` | 允许换行的操作行，默认不增加横向或换行间距；文字距离由行高与内缩形成；inline/start/end/stretch 为排列变体 |
| `.zxs-row` | 同一紧凑行、字体和首字内缩；center 用于标签居中，flush 用于已有内缩的卡片，option 用于单行菜单 |
| `.zxs-frame` | 统一无边框背景与 G4 裁切；不重复扣减文字内缩；inset 用于图表卡片内层 |
| `.zxs-surface-start` / `.zxs-surface-end` / `.zxs-surface` | 透明包装的起点、终点或两端紧贴可见装饰框；只在相邻表面原本直接接触时补半行距离，中间已有文字行或标签行时不重复添加 |
| `.zxs-input--compact` | 只选择紧凑尺寸；普通原生文本输入静止时无底边，键盘焦点使用实线；文件搜索由外围轮廓表示焦点 |
| `.zxs-control-group--comfortable` | 顶部图标按钮使用普通 44px 控件基准 |

例如详情中的内容组使用 `class="zxs-entry-section zxs-stack zxs-stack--flush"`，外层使用 `class="zxs-content-panel zxs-entry-content zxs-frame zxs-stack"`。新页面直接组合这些角色；修改业务行高只改 `geometry.css` 的 `--zxs-compact-row-height`，字体、间距、首字内缩和 G4 范围随之计算。业务原语只作用于 `.zxs-app-shell`，登录尺寸保持独立。

当前轮廓 `zxs-g4` 采用[《给矩形倒圆角 (1)》](https://zhuanlan.zhihu.com/p/709019955)和[《给矩形倒圆角 (2)》](https://zhuanlan.zhihu.com/p/713026877)中的 iOS G4 拟合构造：缓和曲线、中央圆弧、镜像缓和曲线。中央圆弧比例 0.4 是本项目选定的参数，原文未给出固定默认值；这不是 Apple 官方 API。

业务单行高度为 36px：两端圆角在竖边上各占 18px，中间没有直线段；字号为行高的 2/5，即 14.4px。普通 44px 输入框对应圆角范围 22px、字号 17.6px；顶部图标按钮保留 44px 点击区和 22px 角范围，但图标按相邻菜单字号 14.4px（1em）绘制，不随点击区放大。字号比例统一由 `--zxs-row-font-ratio` 控制，正文、标题、时间、说明、预览、提示和下拉选项不再另设旧字号。多行输入按其 44px 基准文本行计算字号；多行列表、弹层、面板和提示沿用单行的 18px 角范围，不随整块内容高度放大。首个字盒或前导图标中心与行中心按等距规则对齐，留白通过 `(行高 - 内容盒大小) / 2` 计算。根 `rem` 基准仍为 14px，避免尺寸比例调整连带改变全部布局；登录六行复用同一业务行高与面板 G4 圆角，正常外卡宽高为九行与六行。数学构造和误差界见 [基础层说明](../../interface.md)。

菜单、面包屑、文件操作和目录分支说明按隐藏外框的 36px 列表行排布，文字内缩复用 `--zxs-list-content-inset`（当前 10.8px），同行控件靠自身内缩保持距离，不使用 `space-between` 将操作铺满整行。无框行自身已有足够留白，公共 stack/flow 不额外添加固定间距。`--zxs-block-gap: calc(var(--zxs-compact-row-height) / 2)`（当前 18px）只用于分开原本直接接触的可见装饰框：状态范围触发器与卡片、相邻状态卡、版本节点，以及桌面目录分支触发器与紧接的列表。手机上目录分支说明另占一行，或只读说明插在列表前时，已有自然距离，不再补 18px。列表自身和卡片内部内容行保持原行高与内缩。备注、命名和分支输入使用无常驻底线的原位编辑，字节计数、提示和错误同样按 36px 行排布；过长的已有备注允许自然换行，输入宽度受容器约束。历史 SVG 根据实际绘图区尺寸使用像素坐标，坐标标签保持正文大小。

详情的 `.zxs-entry-section` 只负责内容分组，组间不额外加距；标题、说明、备注与分支控件按 36px 行排列，清除默认 margin；表面无边框及额外 padding，文字使用一份共享内缩。属性 `dl` 共享标签和值两列，使用 `display: contents` 保留每条属性的语义分组，长值换行时标签和值居中。历史页使用独立 `history.css` 和语义 `ul/li`，无框字段换行不额外增加间隔，列表背景使用无边框 G4 18px 轮廓。状态卡标题和说明各占 36px，取消卡片上下额外 padding，底部采样时间为同一紧凑行；图表仍填充 3:2 卡片剩余空间。

账户和管理文本字段共用 `.zxs-form-grid` 与 `.zxs-form-field`：左标签、右输入共享弹性列比例，同组起始边对齐，长标签可以换行。字段组无边框，字段仅保留一份横向内缩；带 `.zxs-row` 的标签不再重复增加内缩，字段组也不在控件高度之外增加上下 padding。所有原生文本、密码与多行输入静止时无边框或虚线；键盘聚焦保留 3px 实线底边，禁用语义与文字淡化不变。实际 input/textarea 的 G4 资格仍为零。文件搜索继续使用可点击的外围 label 与占满内容区的原生 search input，焦点使用外围 G4 2px 环及 3px 间隔；强制颜色模式改用系统 outline，避免阴影被系统隐藏后丢失焦点。原生清空只编辑草稿，Enter 才提交搜索。

文件版本历史使用 `.zxs-version-tree-scroll` 内的反向拓扑分层树：最新分支叶子在上，旧父版本在下，各分支长度不一致时仍把全部最新叶子置于顶层。层内依较新日期及相邻子节点位置稳定分组；连线仍表示旧父到新子的真实关系，因此箭头向上。每个 `.zxs-version-node` 保留日期、备注和操作三个内容行，基准高度均为 36px、字号 14.4px；备注、原位输入的计数与错误允许第二行区域自然增高。节点采用 18px G4 角范围与无边框背景，宽度不超过 294px，也不超过树实际可见宽度扣除两侧各 18px 连线通道后的空间。分叉增加的宽度只在树容器内滚动，页面本身不随树横向溢出；单路历史无需横向滚动。SVG 箭头位于节点下层并忽略指针事件，连线按实际节点边界绘制；18px 层间距内的出入口各留 6px，跨层连接经过外侧通道避开中间节点，备注编辑引起的高度变化同样参与测量。

字体 CSS 别名统一为 `ZxsUI`，实际文件继续使用 `/fonts/interface-regular.woff2` 和 `/fonts/interface-bold.woff2`。字体来源和许可见 [字体版权与许可](../../../../compliance/licenses/fonts/UPSTREAM-NOTICES.md)。构建工具应递归复制 `src/web/public/`，保留目录层级，并将这些 CSS 纳入资源清单、缓存和完整性检查。

本目录从项目所有者提供的设计令牌、管理界面样式与启动样式复用并按 ZXS DOM 契约定制。内容块外观原先参考 `union-rust` 的 Apache-2.0 设计；仅复制 CSS 声明，没有引入其脚本、认证逻辑或构建工具。第三方字体的许可和来源继续保留在字体 README 中。

文件工具栏及面包屑来自所有者提供的文件浏览样式，属性列表来自主机管理样式；在本项目中改为统一命名、局部作用域、窄屏布局和简洁文件详情/资源卡。主机监测采集源码提供采集层，不含另一套可直接复制的浏览器样式；其采集逻辑由服务端按需复用。原作者私有工作区路径不是构建依赖。

文件表头、数据行与分页之间不再绘制装饰分隔线，列表自身不绘制边框。横向滚动只更新容器上的一个水平偏移变量，`100cqw` 持续跟随可见宽度，因此滚动起点、终点及窗口缩放都保留行背景四角；所有内容列仍按原生表格滚动。每个数据行首单元格内的独立 `aria-hidden` 背景层覆盖整行的可见宽度，复用同一 G4 角范围；默认透明，hover 或勾选时显示四角连续圆角。该层不参与表格排版、不接收指针事件；独立包装仅裁切装饰，不包含真实控件，因此旧水平偏移不会扩大 scrollWidth，也不裁切控件与焦点。偏移读取 CSSOM 的原生小数值，避免高 DPI 或缩放时被整数绑定截断。原生 table、行点击及复选框保持原逻辑。浏览器验收覆盖真实横向滚动两端、右滚后扩宽及翻页／搜索使原生表格实际变窄后的自然钳制（不手动归零），分别读取几何和 Chrome 页面截图像素，检查首／中／末行及文件夹的悬停、选中四角和键盘焦点；源码与像素观察器模型测试不能替代这些实际浏览器结果。文件列表的 `aria-selected` 与批量复选框共用同一选择信号；曾打开详情的条目单独留给详情页，不再触发文件行底色。默认行透明，勾选行保留选中底色；hover 底色只在可悬停的精细指针设备上生效，键盘继续使用真实控件的 `:focus-visible` 外环。右侧菜单不显示账户名，账户图标按钮保留“账号设置”可访问名称与入口；刷新图标为右上约 45° 留有缺口的圆环，不带箭头。实际读取期间旋转，成功或失败结束后回到原位；系统管理覆盖列表及逐盘读取。减少动态效果时不旋转，保留 `aria-busy`。

系统管理的硬盘列表刷新统一由菜单栏刷新按钮触发，仍使用原管理读取与会话、列表请求、备注保存准入；页面不再保留重复“刷新硬盘列表”入口。文件、详情、历史记录、状态和管理磁盘的刷新保留数据与错误反馈，不再创建“正在加载”行；图表未取得历史时也不输出加载文案，完成后仍保留无历史提示。保留读取状态控制请求准入、空结果判定和 `aria-busy`，移除仅供旧加载行使用的状态（如监控首次加载标记）。菜单旋转覆盖状态页的实时样本、历史、容量及巡检四条读取链。 文件页的忙状态也包含所选文件历史读取，但不会因此禁用刷新：列表和磁盘列表空闲时，仍可刷新并替换旧历史请求；详情页继续在相关读取期间禁用重复刷新。

主导航的源定义顺序是文件、详情、状态、历史记录、系统管理；不再提供独立管理健康菜单，不依赖 CSS 重排。全局存储与认证恢复保留在系统管理；逐目录的实际设备健康在对应目录卡中显示。详情页删除独立“返回文件列表”行及仅供该行使用的处理器、返回图标和样式，仍通过主导航“文件”进入列表，保留选中文件与位置属性。

历史记录硬盘筛选使用 `Select` 的无可见标签模式：不创建独立 label 行，组合框和列表框直接保留双语 `aria-label`；默认模式仍为其他筛选器输出原标签行。筛选状态、键盘选择、焦点与菜单行为保持共用实现。

空文件夹提示的唯一渲染节点位于分页导航中，与上一页、本页/总数及下一页共享同一 flow；采用行内礼貌状态语义，窄屏按同一栏自然换行。仍只有已加载、无条目且无搜索条件时才显示，搜索无匹配的逻辑保持独立。

文件分页栏与表格连续排列，不保留绘制分隔线用的透明边框或伪元素。历史活动列表与标签 chip 同样不绘制边框。详情属性的 `dd` 去掉浏览器默认 40px 左外边距，标签和值仍由显式网格分列，语义层级和版本树缩进不变。状态页巡检、容量信息及版本树继续复用原有行高与文字内缩。

共享 Select 仅展开列表保留一圈 `#000` 边框，折叠触发器没有边框。G4 直接消费列表的真实作者边色，明暗主题不改变这圈黑边；禁用触发器仍只淡化文字与箭头。键盘焦点继续使用可见外环，强制颜色模式保留系统 outline。系统管理磁盘身份标签为 `zxs ID`，字段仍是 disk_id，与文件系统 UUID 分开。

共享 Select 展开列表的 border-box 宽度直接跟随触发框，不再强制最小 180px；因此状态页 8rem 时间范围控件展开后也保持等宽。仍保留视口内缩、越界收窄和纵向空间限制，选项文本按原规则省略，键盘及无障碍行为不变。

根 `html` 与应用作用域不设置固定 320px 最小宽度：320px 外视口出现非覆盖竖滚动条时，布局按扣除滚动条后的内容宽度自然收窄，不靠隐藏横向溢出掩盖裁切。登录卡按内容与可用空间收窄，控件保留共享 36px 最小行高及原 G4 圆角，顶部语言和主题控件另保持 44px 点击高度。

共享内容行、字段整行和 `.zxs-hover-row` 在支持悬停的精细指针设备上使用无边框 G4 圆角矩形高亮；整行中的子标签与按钮不重复绘制高亮。文件表格继续使用独立背景层，不能让原生 table-row 直接变成裁切容器；Select 活动选项复用相同背景色。触屏不保留模拟 hover，键盘焦点不依赖 hover。登录的两个原生输入各由透明行包装承载 hover，原有 id/for、六轨和输入焦点不变。包含完整高度按钮的 flow/row 不再叠加纵向 padding，保留长文自然换行与既定 36px／44px 控件高度。
