# ZXS 界面字体

字体来自 Maple Mono 与完整字形合成所用的第三方字体资源，当前文件统一命名为 `src/web/public/fonts/interface-regular.woff2` 与 `interface-bold.woff2`，字体数据保持既有内容。CSS 通过 `ZxsUI` 引用它们；加载与失败处理见[浏览器基础层](../../interface.md)。

原始字体版权、保留名称及三组 SIL Open Font License 1.1 全文统一保存在 [compliance/licenses/fonts/UPSTREAM-NOTICES.md](../../../../compliance/licenses/fonts/UPSTREAM-NOTICES.md)。未确认的来源版本或发布归档不作推断。
