# 外来 ZXS 离线迁入包

`foreign_import::migration` 实现离线材料准备、按原一级来源分组、完整校验、非覆盖发布与显式恢复。它复用当前格式的 `ForeignImportPreview`，不兼容旧格式，不修改源盘，不改写历史哈希或旧 seal，也不把系统盘 SQLite 当作权威。

**这不是已经接入运行池的磁盘向导。** `ForeignMigrationReceipt` 仅证明迁入包的本地落盘与验证结果，不是 Engine 的成员激活、目录提交或全部成员保护回执。当前没有 HTTP、CLI、Web 接线，也没有向现有一级目录发布逻辑文件。正式接入仍须实现新的成员／命名空间事务和对应证明，不能将这个离线回执直接交给现有 registry 当作注册成功。

## 已实现的角色计划

| 来源角色 | 允许的计划 | 当前产物 |
| --- | --- | --- |
| 一级 | `ForeignMigrationPlan::primary` | 保留原结构和完整证据的一级迁入包 |
| 二级 | `primary` 或 `rebuild` | 升一级的迁入包，或绑定已接纳一级的空目录及完整来源映射 |
| 三级 | `primary` 或 `secondary` | 升一级，或绑定已接纳一级身份后转二级的迁入包 |

`secondary` 只能由三级来源构造；一级目标必须来自当前 `Engine::registered_disks` 的 Enabled 一级注册，且没有上游。计划绑定完整 pool/disk/slot/binding_generation 和源序号，不接受调用方提供的“已接纳”布尔值或裸盘位作为授权。

`rebuild` 要求明确指定存在且为空的逻辑目录；每个可证明的原一级以 `(pool_id, disk_id, slot_id, binding_generation)` 为键，各自映射一个不同名称。一个原一级的多棵历史归入同一来源目录，多个同名／同盘位来源不合并。检查大小写／Unicode 名称碰撞和实际组合路径长度。发布前再次验证注册、Engine 序号和空目录。模块把这份映射存成描述符，尚不创建对应的活动命名空间。

## 文件格式和权威边界

调用方独立保存计划摘要和 operation_id。目标为一个尚不存在的目录，其父目录必须已经是安全的 0700 私有目录。模块不会修改父目录权限。

```text
parent/
  .zxs-foreign-<operation>.json        # 持久意图；先于暂存目录创建
  .zxs-foreign-<operation>/            # 发布前的独占暂存目录
  chosen-capsule/                     # 非覆盖 rename 后的最终目录
    intent.json                      # 包内完整意图；可离开原父目录
    binding.json                     # 原暂存目录身份与意图摘要
    source/                          # 源盘所有普通文件和目录的独立副本
    origins/<origin-name>/origin.json
    origins/<origin-name>/<history>.json
    sealed.json                      # 完整复制、证明验证和同步完成
    ready.json                       # 目标准入检查完成后才生成
    residue/                         # 崩溃留下的临时文件；不是证明或正文
```

`source/` 保留原始 seal、journal、元数据对象、版本证明、校验清单和正文。原始配置中的其他磁盘路径不被打开。复制后的 `ForeignImportPreview::inspect` 必须得到原审阅摘要，所有正文可用性状态也必须一致。原证明对象、分支、提交、祖先和历史 ID 不改写。

计划另存每个文件的长度和完整 BLAKE3、所有目录，以及原预览摘要。原预览摘要并不覆盖 journal 的所有原始字节；逐文件清单补足这层约束。来源描述符只引用原 history-manifest，并列出 `verified_local`、`temporarily_unavailable`、`recorded_purged`、`recorded_migrated`，不伪造新的 directory_commit。

缺失正文保留历史并显示暂不可用；本地损坏正文、证明损坏、缺失证明、链接和特殊文件拒绝。只有完整通过原预览证明链的来源才能进入计划。来源数据不是密码学身份认证：与既有协议一致，本模块不抵御能重新伪造全部元数据的同权限管理员。

## 持久化与恢复

1. 只读重新验证来源并冻结有界清单。
2. 对父目录持有跨进程排他锁，确认目标、操作保留文件和暂存名不存在，先同步父目录中的不可变意图。
3. 独占创建暂存目录并同步目录及父目录，再写身份绑定。第一步 mkdir 之前／之后崩溃时，可依据外部持久意图恢复保留名；没有对应意图的目录不会被接管。未绑定目录中存在非原子写临时残留的内容时拒绝。
4. 经持有目录 FD、受限相对路径、普通单链接文件读取；逐文件完整复制和校验，不用硬链接、reflink 或去重。已有精确字节只校验和同步，冲突文件保留且报错；不可变 marker 的读取与同步使用同一打开对象，不在校验后重开名称代替已核验句柄。
5. 复制中断的临时文件只在本事务持有的复制树内识别；原源清单包含的同名文件绝不跳过。额外临时文件非覆盖移动到 `residue/`，不删除，也不把它们解释为完整正文。其他额外文件／目录拒绝。
6. 完整清单、复制后的历史证明和来源分组一致后，同步文件和所有目录，写 `intent.json`、来源描述符及 `sealed.json`。再次检查目标准入，写单独的 `ready.json`。
7. 在同一父目录用 `RENAME_NOREPLACE` 发布整个目录并同步父目录，发布前后检查持有与命名目录身份。rename 或后续同步失败保留材料，按原操作恢复查明结果，不声称回滚。
8. `resume(destination, operation_id, digest)` 检查暂存名与最终名。两者同时存在或内容不符时拒绝；最终名存在仍须完整 ready/sealed 证据，不能把用户目录或手动改名的半成品当成功。成功回执丢失时验证并重新同步最终包，再返回原摘要。

已发布包不能再 `copy_source` 或 `seal`。它的历史回执在目标后续变更后仍可查询，但不表示旧目标预条件当前仍成立。未发布计划的目标变更会产生 `PLAN_STALE`，即使材料复制已经完成。

`ForeignMigrationReceipt::verify_capsule(path, expected_digest)` 只读验证完整包。它不依赖原父目录保留文件、源盘、Engine 或 SQLite；复制到新位置后，旧 physical binding 仅作为原始证据，不当作新位置准入。断点继续写仍要求原父目录和本地身份不变。

## 预算与适用范围

这是保守的全量复制模块。清单最多 100,000 个文件／目录、路径最多 64 层和 4096 UTF-8 字节；单次持久意图最多 64 MiB，计划构造上限为其一半。副本总字节受预览 metadata + journal + payload 预算限制，未知文件也计入。所有源数据只读，源与目标相交或目标父目录别名指向源子目录时拒绝。复制阶段也必须匹配计划固定的源绝对路径、device 和 inode，不能拿另一个逻辑摘要相同的副本替代用户审阅的物理选择。

时间开销包括全量字节读取和既有历史证明遍历，清单组织为 O(条目数 × log 条目数)，清单／计划内存 O(条目数 + 路径字节)，单次流式哈希缓冲 64 KiB。规划、复制后封存、发布复核和恢复会重复遍历，未做性能优化。同步保留平台的文件同步、原子发布和目录同步：每个复制文件有独立屏障，封存／恢复还会全量重复文件及目录同步。没有声称减少 fsync 或提升吞吐。

当前预览仍拒绝非元数据成员盘、撕裂 journal、空历史、缺原始 workspace.commit 出生证据，以及同一连接历史跨多个原一级的情况。全量副本还可能因无关工作区、残留文件或资源预算而拒绝；这些拒绝保持原盘不变。迁入包包含源盘的完整普通文件，可能包括配置和恢复材料，应按原数据保护权限保管。

尚未实现：跨池活动 registry 激活、源盘角色原地切换、活动目录树重建、目录提交重签发、跨盘新的权威提交、旧写者隔离、数据盘设备热拔插验证、非元数据盘的独立完整证明，以及真实设备掉电验证。这些不能由本模块的离线成功回执替代。

## 验证入口

根 `test/engine/unit/foreign_import/migration_tests.rs` 接入现有 storage-engine libtest；未把测试放进 src。使用本仓库固定 1.99.0 工具链及离线本地依赖：

```text
cargo test --locked --offline -p storage-engine --lib foreign_import:: -- --test-threads=1
cargo clippy --locked --offline -p storage-engine --lib --tests
```

测试覆盖角色矩阵、一个来源多棵历史、完整来源映射、目录碰撞、暂不可用正文、损坏／链接拒绝、原目标不覆盖、目标失效、持久意图前后窗口、部分复制冲突、临时文件保留、错误摘要、替换目录、手动改名半成品拒绝、可移植离线核验及回执幂等。子进程测试在准备、真实复制 reader 内、复制完成、封存完成、rename 后退出，不运行析构后再恢复；rename 后场景直接调用相同平台原语以控制父目录同步前的窗口。

子进程退出和构造残留文件不等于真实断电；尚未进行所有 write/fsync 系统调用错误注入、挂载替换、硬件缓存刷新或整套 workspace 回归。本轮集成验证见[验证记录](../../../validation/foreign-migration-integration-20261105.md)。
