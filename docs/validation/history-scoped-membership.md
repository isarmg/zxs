# 历史节点／版本页：范围成员流，而非全池候选扫描

本阶段只改可重建查询投影和有界选页，不改变永久历史、原 ID、FULL、公开排序、游标、当前根、权限或发布／恢复依据。SQLite 不是业务权威，没有新增持久业务格式、兼容双读或迁移；启动仍从已验证 State 重建 disposable index。

## 完整性与范围

`engine/index/scope.rs` 为版本、路径节点、元数据节点及提交中的具体条目位置登记 `(file, history, kind, id, entry_position)` 成员。提交位置保留同文件在同提交的多个条目，规范顺序保持原提交 ID 的同序号裁决。可信计数只从 State 建立并随同一成功投影事务更新，按文件／历史／种类保存四个计数，不缓存所有节点或正文。已知写集只处理变更键；冷重建及未知谱系保留完整比较边界。

每个流以复合键续读，单批至多 64 行；复用现有只读连接单值 64 KiB、SQL 16 KiB、VM 操作 10,000、绑定参数 16 的限额，坏 TEXT 不形成无界批次；每行都核 State 中准确 ID、归属和提交条目位置，键严格递增。只有全部耗尽且各类行数等于可信计数后，才接受本次有限选择。数据库自己返回的 COUNT、sequence 或 LIMIT 不证明页范围没有漏项；本实现不采用这种捷径。缺中间项、伪造替补、错归属、坏 schema／marker、错误位置、未消费完整流或吞掉流错误均不能变成成功页。

索引错误保留具体原因，关闭该代 accelerator 并回到原 State 扫描；请求非法游标和取消属于业务错误，不使健康索引失效。重建后通过独立读代身份隔离旧快照的延迟错误，不能把已经恢复的索引再次误标损坏。认证与当前根复核仍由原调用边界完成。

## 锁、WAL 与复杂度

捕获保留当前归属验证，健康路径完整读取目标文件版本，而不是遍历无关版本；此成本仍为 O(目标版本数)，不是常数。节点／版本页另捕获同序号 SQLite 读事务，只查询 schema／marker并拷贝四个可信计数。实际范围数据验证、64 正文一批的首提交选择，以及后续 DTO 投影在原 Engine 锁外执行。

只读事务固定数据库快照，但不保留 State；数据逐行对同次业务观察验证。连接一次性消费，成功、失败和取消都会显式关闭；未调用 page 而直接释放读取对象也关闭连接。重复 page 使用有限选页结果，不重复保留 WAL 读者。连接关闭错误不伪称成功。请求取消仍逐候选／条目检查，SQLite 原 busy timeout 与现有 backend 槽、HTTP 超时不放宽；不为此提高磁盘或内存预算。

令目标内容版本 N、目标路径／元数据节点 R、目标提交条目 C，批上限 B=64。选页成员访问是 O(N+R+ceil(N/B)×C)，加版本所有权完整核验；BTree/SQLite 搜索比较另计。无关文件数不进入这些成员流，但 **这不是整个历史页 O(L)**：分支/merge/head 投影、祖先路径/标签、选中提交中的路径查找和其他历史集合仍有原扫描；失败回退也仍全池扫描。不能把此阶段称为全仓扫描或所有驻留问题全部解决。

## 定向验证

- `history_window_indexed_tests.rs`：节点和版本 `limit=1/2/7/64`，正／反游标和所有 anchor 与原完整页 oracle 逐字段比较；旧观察在新 publication 后仍保持相同有限结果。
- `index/scope_tests.rs`：范围完整性反例、同文件多提交位置、更新／跨历史归属、64 行边界、取消/业务错误、只读快照 `Send + Sync`、旧 WAL 观察跨发布／重建以及未消费 Drop 释放检查点。
- 结构计数分别记录目标 scope 增长、无关历史增长、捕获成员访问和锁外选择访问。小夹具计时仅诊断锁边界，不作为性能门槛或真实设备吞吐承诺。

一次助手云 debug 定向结果（不是生产延迟基准）：

| 目标版本 / 无关历史 | 捕获归属版本访问 | 快照捕获成员访问 | 锁外选择：版本 / 路径 / 元数据 / 提交条目 | 最大行批 |
| --- | ---: | ---: | --- | ---: |
| 17 / 0 | 本组未单测 | 本组未单测 | 34 / 1 / 1 / 17 | 19 |
| 17 / 257 | 18（含同文件另一历史 1 条） | 0 | 34 / 1 / 1 / 17 | 19 |
| 67 / 257 | 68 | 0 | 134 / 1 / 1 / 134 | 64 |

17／67 两组小样中，捕获归属约 3.4–3.6 ms，只读快照捕获约 1.0–1.3 ms，锁外选择约 1.6／4.1 ms。它们包含共享机器调度与 SQLite 开关成本，不设通过阈值；结构结论来自逐成员访问计数。计数不包含后续分支／merge 投影与 State 映射查找次数。回退完整 oracle 仍独立执行，不能用该表声称其他集合、所有页或所有历史规模的端到端性能已改善。

旧 1k–5k 回执增长 workload 和旧 AB/BA 不是该目标的直接证明，本阶段不重复执行；三个已撤销的启动／RSS／保存延迟工程门槛也未恢复。真实故障域、设备耐久性和办公客户端验收仍与此软件索引验证分开。

## 已选版本字段的首提交复用

Versions 页在同一个锁外快照中，对已选至多 64 个版本完整读取一次现有提交条目流，保存有限的首提交 ID。按最小 sequence、同序号最小 commit ID 选择；没有提交也是完整计数认证后的事实。`version_summary` 的作者／说明字段长度复用该事实，不再为每个已选版本重新遍历全池提交；其他独立字段和 branch／merge／祖先路径不由此冒领优化。

定向回归添加无提交版本和两个同序号提交，并在无关历史 0／257 下逐字段对照原完整页。生产 `first_commit` 提交头访问计数为 0；参考路径仍实际访问提交。漏掉一个数据库提交成员会使计划作废并完整回退，不能伪装成作者／说明为空。

## Content 分支投影的目标范围

`history_scope_members` 的 Branch 成员按 `file_id=Some(file)` 与
`history_tree_id` 归属构建；不按 `branch_kind` 或状态额外过滤。可信计数来自
State，读取仍须严格唯一 ID 顺序、逐项 State 身份/归属验证及完整耗尽。
Nodes 页在同一锁外快照里完整读取目标分支，只保留已选最多 64 个 Content
节点的首个有效分支 ID；原 branch-ID 顺序、branch/commit pending 排除和
head-entry 匹配语义不变。确定没有分支与索引不可用明确区分，损坏或缺项
走原完整扫描，不生成遗漏分支的页面。

这消除 `content_branch` 对每个已选 Content 节点的无关全池分支扫描；
仍遍历目标分支及其 head commit 的 entries，不是 O(page)。Merge 投影和
祖先链处理保持原实现；本项不宣称消除全部投影扫描。连接、取消、旧快照
及 rebuild epoch 生命周期沿用本文件前述机制，无持久历史格式变化。

`Engine::open_mode` 在恢复后无条件重建 disposable index，重新投影 Branch
成员及可信计数；旧四类成员表即使 schema/sequence marker 未变化也不会被
沿用。定向 reopen 回归保留真实池，只删去索引 kind=4 后重开，与原 State
分支集合计数比较。0/257 个无关分支的整页 oracle 回归实际均访问
`[34, 1, 1, 17, 21]` 个五类成员，最大批次 21；新页面投影的全池 branch
header 访问为零。130 个目标分支另覆盖跨 64 行批次及 tracked 更新。

## Nodes 父边预览的 Merge 范围

第六类成员是按 file/history 归属的 `FileBranchMerge`。逐行验证 merge ID、
归属及空 entry key，按可信计数完整耗尽；`reused_node` 不被过滤，它同样
可贡献额外父边。捕获后的锁外阶段复用原父边遍历与 Selector，在原节点
顺序中为后续每个节点保留一个 preview 名额，总共最多保存 256 个父 ID
及原 `has_after`，不保存所有 merge 或祖先链。投影继续生成相同字典序边、
窗口内/外端点和 More cursor。

健康路径每个所选节点仍完整读目标 Merge 范围，成本随目标范围增长，
不随无关池 Merge 增长；损坏成员触发完整旧路径 fallback。Metadata 路径
追溯和独立 NodeParents 查询此批仍用原实现，不能据父边预览优化声称
所有 Merge 扫描已消除。旧快照、取消、错误关闭和重建 epoch 机制不变。

父边定向回归在 0/257 个无关 Merge 下均访问
`[34, 1, 1, 17, 21, 57]` 个六类成员（19 个节点各耗尽 3 个目标 Merge），
最大批次 21，父边投影全池 Merge header 访问为零；300 个含重复和自指输入
的父边候选仍精确输出 256 个 preview 及原 More cursor，与完整页 oracle
相等。另有 130 条目标 Merge 跨 64 行批次、增量移动删除及错 scope 同数
替补拒绝测试。
