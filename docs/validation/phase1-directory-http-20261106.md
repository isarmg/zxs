## 新增三项

- 显式初始化之前的读取不产生仓库；旧命名空间基线和非字符串暂存代数被拒绝。初始化准确重放；暂存后保存的新内容不进入本次目录提交，历史预览保持只读，工作内容保留。冷重开后状态和两份正文不变，准确提交重放返回原结果，之后显式暂存可提交后续内容。
- 仅有未暂存工作时提交不推进 HEAD，创建分支和切换分支拒绝丢弃工作。历史预览不改动工作正文；显式暂存、提交之后可通过准确分支／树／命名空间基线切换。冷重开及准确切换重放保留选择和历史正文，作用域外文件保持不变。
- 父仓库固定已明确暂存的孩子提交，不跟随孩子后续提交。只暂存孩子新引用不包含父自己的后续工作内容；父提交、父工作内容、孩子 HEAD 和正文在冷重开后各自保持准确身份与状态。

实现位于 `test/server/integration/phase1_save_tags/directory_git.rs`，通过 `phase1_save_tags.rs` 接入已有 Cargo 集成目标，复用真实 `AuthStore`、`EngineBackend` 和生产 HTTP `Router`。冷重开会销毁旧 Router、重新打开同一临时 SYSTEM 与鉴权存储；仅对仍在收尾的真实 writer lock 做有截止时间的重试。

- 新增目录测试 **3/3 通过**；同一新二进制复跑原来的保存／标签三项、真实 Engine 拒绝两项，总计 **8/8 通过**，无忽略。
- `rustc -D warnings` 小型集成目标链接通过，耗时约 1.82 秒；八项串行运行约 19.75 秒。

- 所有步骤限制单 CPU、2 GiB 地址空间；每步开始检查工作盘空闲大于 4 GiB，测试临时库位于独立工作盘目录，编译输出位于 `/tmp`。运行过程峰值子进程 RSS 约 763 MiB（累计观测的最大值，不是每步独立峰值）。
- 原始命令、输入摘要、库摘要、完整输出及退出状态另行封存于交付证据目录，不写入产品状态。

## 未验证边界

这些是生产 HTTP Router 的 `oneshot` 请求链，未经外部 TCP、TLS、浏览器、Samba 或 VFS。初始化 Engine 的临时一级盘夹具不是管理界面的发现／激活测试，也不修改真实用户磁盘。

本次没有执行全 Server libtest、全 Engine 测试、全仓 CI、故障注入或断电恢复。构建使用开发模式的空内嵌 Web 资源，不构成正式部署包。原来的目录 Engine 十项验证是独立证据，不能与本次八项混称一个完整套件。

目录内 SQLite 数据库、三处耐久安装、来源捕获、真实 publication 绑定，以及外来盘接纳／恢复执行仍属于未接入的二期工作。本次不提供或开放这些能力；文件节点标签测试也不表示存在独立的目录标签接口。
