# 一期磁盘文件浏览的读取状态

一期整合基线为 `82b61c272ba762c7ca146f568c49672d069f8c0a`，tree `09da61f7f690c1b60dfc2be691459eb7c072c763`。它仅在 2d983a9f 上按正式工具修正 Engine Cargo manifest 的来源摘要，生产源码没有改变。它包含 c17 管理 GET 队列、f966 目录暂存状态修复、71fb 目录回归和 6d 管理槽取消回归。c17 与公开 `02910bdd3cdc6f617936e49a6c82faf30b553228` 同 tree，但 02910 的 CI 不包含一期后续整合或本批提示。

## 范围与修复

已有文件管理入口以真实登记盘列表打开磁盘目录，提供目录导航、分页、搜索、文件/目录详情和元数据操作。这里补上一级盘浏览时的读取状态缺口：`complete_disk_load` 在失败时正确保留缓存并取消当前就绪标记，但此前磁盘根列表没有说明展示的是旧结果；首次未取得列表时也只显示空表。

新增展示投影明确区分五种状态：当前列表、首次读取中、带缓存刷新中、尚未取得列表、带缓存但未取得当前列表。未确认时可以显式“重新读取”，仍调用原有 `load_disks`。原函数继续阻止重叠读取，并在回执处核验会话和列表代次；当前会话 401 的撤权语义不变。提示只描述整次列表读取，不推断某个磁盘物理离线。成功空列表仅由已完成的有效响应确定。

本批不改 API、传输队列、磁盘解析、写入权限、SMB、任何存储格式或后端限额。未带入多级备份盘层级显示、虚拟树、共享文件树焦点或新的 SQLite 模型。现有 Web 仍为元数据管理界面，文件正文保存通过现有 SMB/API 链路处理；不新增或声称 Web 上传/正文编辑能力。

提示投影为 O(1)，只读取既有加载状态和缓存是否为空。既有磁盘行投影、原生表格、错误中心和管理轮询保持原样；不新增缓存、请求周期或依赖。

## 验证记录

Rust 1.99.0，Linux x86_64，独立工作树。新增文案/重试状态的真实生产模块原生测试 **5/5 通过**，聚焦 Clippy `-D warnings -D clippy::all` 通过；完整原生 Web 生产源码 metadata、完整 Web 测试源码 metadata 和完整测试 Clippy metadata 均通过。测试源码检查包含新投影的全部八种状态组合，但该完整测试二进制没有链接/运行，不将它们计入已执行五项。

准确复核脚本为独立证据包中的 `verify.py`，依次运行 `disk-read`、`disk-read-clippy`、`production`、`test-metadata`、`full-clippy` 五种受限入口。它只允许这些检查，不启用完整产品二进制构建。编译输出在 `/tmp`，单进程地址空间上限 2 GiB、CPU 上限 180 秒；启动前要求工作盘至少 4 GiB、tmpfs 至少 1 GiB、可用内存至少 2 GiB。五次检查合计约 58 秒，无 Engine/Server 重编或真实磁盘操作。

Web 明确使用准确 2d983a9f 生产源码新编译的 contract 与 name-policy 小库，而非 c17 的旧 contract。每个检查开始前重新核对 67 个相关源码/manifest/lock 输入及两库 SHA-256；当前 82b 只修来源摘要，因此这些输入与共享产物完全相同，且包含新的 DirectoryGitStatus.unstaged 契约。精确参数、依赖哈希、返回码及原始日志均保留。

2d 基线曾因 Engine Cargo manifest 的来源摘要未刷新而使正式 static 失败，该原始日志保留。82b 用正式工具修复后，本批正式 `.github/scripts/check.sh static` 全部通过；rustfmt、Git diff 空白和最终维护文档检查也通过。没有改写不可变来源收据。生产 WASM/Chrome、完整 Web 测试二进制及真实页面失败后重试未运行，不以源码接线或原生元数据检查替代浏览器验收。

正式回归包括 `test/web/unit/files/view/disk_read_tests.rs` 的五项文案/重试状态测试，以及 `view/tests.rs` 对加载、确认、缓存三项输入全部八种组合的投影检查。现有 browse 测试继续覆盖失败保留缓存、恢复使旧代失效、旧会话回执和当前 401。

真实浏览器验收还应在相同候选产物上检查：首次读取期间有明确状态；已登记一级盘仍按原顺序打开；读失败后保留原行且标记旧结果；“重新读取”只触发原有有界读取，成功后状态消失；错误中心诊断仍保留到显式关闭。随后复核一级盘目录进入/返回、搜索/分页、文件详情及既有会话取消场景。不能拿旧 02910 产物的通过结果冒充本批浏览器通过。
