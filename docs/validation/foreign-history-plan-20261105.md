# 外来历史持久审核计划（2026-11-05）

范围：在[只读历史检查](foreign-history-preview-20261105.md)之上，提供类型化目标
映射、不可覆盖保存、原主体查询及完整重验。不是外来盘接纳、数据库剪裁、级别
转换或逐盘可移植写协议；执行入口固定拒绝，不发布成功收据。

## 实现与边界

- 共享协议位于 `src/contract/src/storage_foreign_plan.rs`；管理编排、持久记录和
  引擎适配分别位于 `management/foreign_plan.rs`、其 `persist.rs` 及
  `engine_backend/foreign_plan.rs`。HTTP、Schema、OpenAPI 与固定向量同步接线。
- 已有一级盘的空根或现存空目录是唯一目标范围。每份来源历史须显式映射到
  独立子目录名，完整覆盖且拒绝命名冲突；不借当前备份槽推测原一级来源。
- 审核摘要绑定原发现的物理目录观察、完整逻辑来源检查、目标身份与业务基线、
  全部映射路径。可移植逻辑摘要不能代替已获准选择的路径/device/inode。
- 新保存先完整重验，再在系统管理目录独占创建不可变审计副本。原数据盘不写入，
  不创建命名空间或工作区。相同编号仅可重放相同预览，损坏记录不覆盖修复。
- 查询及相同保存重试返回 `validation=required`，不打开源盘或目标盘。显式复核
  完全一致才返回 `matched_at_observation`，且不持久化这份暂时有效性。目标不被
  预留，后来的读请求不能把历史匹配当作当前匹配。
- 所有响应的执行能力仍为 `unavailable`；保存确认只授权系统盘审核记录。
  `/execute` 核对主体、编号和摘要后返回 `FORMAT_UNSUPPORTED`，不能通过篡改
  DTO 或保存记录构造写入能力。正文暂不可用的版本及来源历史完整保留。
- 当前管理会话、同源/CSRF、生命周期选择门与源读取预算保持。完整预览上限
  1 MiB，请求和持久记录上限 2 MiB，超限整份拒绝。审核文件不属于引擎权威，
  未来写者必须重新证明来源、目标基线及实际复制正文。

API 与恢复细节见[在线目录成员管理](../design/online-disk-management.md)。

## 本轮真实验证

共用一次 `cargo test --locked --offline -p storage-server --lib --test http_engine
--no-run` 生成的 Linux libtest，使用仓库外持久文件系统 `TMPDIR=/workspace/shared`。
随后直接运行相应过滤器，没有为每个测试组重复构建。

`management::foreign_plan::tests` 新增 6/6 通过：

1. 只读预览、未确认拒绝、不可覆盖保存与重放、冷重开查询/重验；检查源/目标字节
   及业务序号不变，复核匹配仍不能执行。
2. 目标 checkpoint 推进使保存过期，后来非空使复核拒绝；审计重放不改写原记录。
3. 完整来源分组、名称冲突、缺映射、错 inode、错来源摘要、缺目标父目录及额外
   级别字段的拒绝。
4. 未知操作、截断记录、错误摘要与撤销会话拒绝，坏记录保持原样。
5. 仅映射指定空目录并保留其他本地内容；不同原一级身份继续分开。
6. 保存后来源改名使复核失败，相同审计重放不访问旧来源；跨主体查询/重放拒绝。

同一 binary 的受影响回归 44/44 通过：外盘只读检查 4、普通转换/停止恢复 12、
固定父目录发现 27，以及包含新增计划路由的会话/同源/CSRF 边界 1。合计 50 项，
不是服务端全部 1213 项运行结果。Rust 文件定向 rustfmt 与 `git diff --check` 通过。

本轮 Schema/固定向量新增 6 条接受与 4 条拒绝样例；完整 contract-check 与最终
严格 Clippy 在统一验证节点执行，不能用前一轮通过替代本批检查。

未执行或未实现：浏览器中的计划编辑流程、真实跨主机搬盘、物理掉电、外来盘
接纳与级别转换、正文复制/暂缺恢复、剪裁执行、新逐盘发布协议及性能压力验证。
现有界面继续只展示来源只读检查，不提供迁入执行按钮。
