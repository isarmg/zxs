# 磁盘来源组合名只读预览

## 本次可用边界

新增 Engine 只读接口 `Engine::preview_disk_source_names(DiskId, &Name)`，返回专域 `DiskSourceNameError`，保留底层原因和原错误码。已有 API 和所有永久备份请求、capture、摘要、收据保持不变。此片未接 HTTP / Web，也未提供写入、改名、初始化普通目录或布局切换入口。

返回明确标注 `source=configured_root_observation` 和 `execution=preview_only`。当前注册表还没有已认证的独立名称记录，因此“原名称”仅在 pool / disk / slot / binding / level / upstream 全部匹配时取配置根 basename。它不是名称权威，不代表实际来源目录存在；before / after 都是目标设计的组合路径投影，不是可提交的 from / to locator。

所有当前注册盘，包括 Disabled，均保留在结果和名称占用检查中；Detached 不参与当前登记。离线、句柄缺失、换绑或名称不可用时明确列 blocker，不按同名路径重新开盘，也不删除该盘及其来源切片。metadata_member 是当前投票资格，不作为永久身份字段借用。

## 来源链与预算

每个目标列出全部直接及间接来源身份，组合名严格为“名称--现有 disk_id 的完整32位小写十六进制UUID”。C 同时列出 B 和 B/A；更深后继及扇出均参与。改中间盘名会影响包含该身份的每条来源链，每目标只列一次最外围受影响根，避免把嵌套目录误算为独立搬移。

名称唯一性按现有固定 Unicode / casefold 规则检查，包含 Disabled 占名。原拼写完全相同无改名影响；本盘大小写变化仍列出影响；与其他盘等价产生冲突。此检查不预留名称，也不建立并发改名承诺。

组件预算从已持有目标根取得实际 NAME_MAX，扣除16字节余量，另计“--”与完整UUID共34字节，不静默回退255。4096字节 / 64组件仅是本预览对“来源链＋固定三目录子路径”的产品预算，不是完整对象后缀或文件系统 PATH_MAX 的可执行保证。固定目录名集中于独立的 prospective layout 模块，未改活动物理格式。

结果上限为256个配置/注册盘、4096个切片、8192个累计链身份、512KiB完整编码。整体越界返回明确资源错误，不返回截断的“完整”结果。未来外部入口还须独立限制请求、响应和并发。

## 定向验证及剩余工作

14个 Engine 候选测试覆盖四级链及扇出、中间盘改名、最外根、Unicode冲突、Disabled、换绑、不重开缺失句柄、多字节组件预算、产品路径预算、全状态和全临时目录文件字节不变，以及显式非执行字段。保护 HTTP 接线及其会话/查询测试留待独立片。没有在本地编译或执行测试；结果只按准确GitHub提交的执行证据报告。

本片不完成磁盘改名。仍须实现名称记录和名称代际的认证权威、永久备份/三范围数据库重建与独立盘恢复闭包、名称线性化预留、链接替换/完整对象预算、逐盘意图及共同决定、布局安装/冷恢复、最终用户写入口。旧配置basename和旧路径文本不能被本预览自动升级为这些授权。新 common-data / deleted-data / zxs-data 布局仍未接通。
